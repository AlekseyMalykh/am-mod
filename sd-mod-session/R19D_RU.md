# r19d — маршрут запуска Sample и имя результата

Проверочная сборка для MPC Sample 1.3.0.12. В r19c пользователь подтвердил
слышимую работу EQ. Ресэмплинг source1 → target0 завершился, но прочитанный
WAV PCM24/stereo44100 содержал только нули: peak0 при полном просмотре
195942 байт. Вызов SAMPLE_TRIGGER достигался, то есть установка адаптера
и определение исходного пэда уже работали.

## Изменено в r19d

- Одиночный экспорт передаёт ноту прямо проверенной дорожке AC50 Sample
  (CurrentThings+140, принадлежность тому же Program). Список получателей
  обычного аппаратного ввода больше не нужен. MIDI-номер уже сформирован
  экспортёром и не переназначается повторно.
- В журнал добавлены различие переданной/выбранной дорожек, velocity и флаг
  блокировки входа. Штатный источник экспорта Seq не меняется.
- Имя Sample-результата формируется из исходного имени с добавлением
  «Resample». Штатная система сама подбирает свободный суффикс. Имя Seq
  сохраняет штатное поведение. Вызов изменён только в RAM клона, только
  внутри одиночного ресэмплинга; имя секвенции не меняется.

## Что доказано и чего тест не доказывает

Локальная ARM/QEMU-проверка исполняет настоящие фабрику ноты,
18b9a50 → 211aa30 → 2115070 → 2119d00. Она воспроизводит потерю ноты через
пустой список аппаратного ввода и проверяет, что новый адаптер доводит её
до правильной дорожки с MIDI60 и velocity1. Неверная/отсутствующая дорожка
отклоняется. Конечная обработка дорожки и запись звука в этом тесте
подставлены: работоспособность готового WAV на MPC ещё НЕ подтверждена.

Отдельно исполняется настоящий вызов формирования имени со штатными
String-конструктором/деструктором. Проверены имя источника для Sample и
неизменный Seq вне этой операции. Обычные проверки и UBSan выполнены.

## Проба на устройстве

1. Безопасно извлеки карту в Windows. Вставляй после полной загрузки MPC.
2. Запусти r19d. Выбери короткий явно звучащий сэмпл, сначала без FX/EQ.
3. Shift+пэд11 → B3 Sample → свободный пэд → B3 Render.
4. После завершения проиграй результат. Проверь имя исходника + Resample.
5. Если тишина осталась, верни журнал через Mod Off → Eject; многократно
   повторять один и тот же рендер не требуется.

Рабочая версия EQ, настройки и интерфейс r19c сохранены. Новых настроек
питания в этой сборке нет; согласованы только Standard и Low Battery,
аппаратное управление зарядкой пока исследуется.

## EQ: третья страница B3

В Sample последовательно нажимай B3: **Filter → Filter Env → EQ**.
Штатные настройки фильтра и огибающей сохранены. Следующее B3 возвращает
на первую штатную страницу; B1/B2 переходят к своим страницам.

В EQ одна точка выбранного типа:

| Управление | Функция |
|---|---|
| K1 | Частота |
| K2 | Gain: усиление или вырезание, ±18dB |
| Shift+K2 | Q: ширина полосы/добротность |
| K3 | Bypass, Bell, Low Pass, High Pass, Notch, Low Shelf, High Shelf |
| Shift+K3 | Не назначен |
| Нажатие энкодера | Выбрать параметр; Shift — в обратном порядке |
| Вращение энкодера | Изменить выбранный параметр |

Для Low Pass, High Pass и Notch Gain показывает «--»: эти типы используют
частоту и Q. Low Pass/High Pass в этой первой версии имеют спад12dB/oct.
Выбери Bypass на K3, чтобы обойти EQ. Настройки точки сохраняются.
График показывает рассчитанную АЧХ, а не спектр записанного звука.

EQ хранится отдельно для каждого пэда, даже если два пэда используют один
WAV. Он действует после штатной обработки инструмента и до дальнейшего
микширования. Сохраняется в расширении проекта. В Batch Copy/Extract
копируется вместе с исходным пэдом; Undo возвращает прежнюю настройку.

## Ресэмплинг

1. Настрой исходный пэд обычными B1/B2/B3 и FX Select.
2. Выбери исходный пэд **до входа** и нажми **Shift+пэд11**.
3. B1 Cancel, B2 **Seq** (текущая секвенция), B3 **Sample** (один пэд).
4. Нажми пэд назначения. Это только выбор цели, без прослушивания.
   K1 выбирает банк; энкодер выбирает цель; +/− листают банки.
5. Нажми B3 **Render**. Если цель занята, отдельным нажатием B3 **Replace**
   подтверди замену. Можно выбрать исходный пэд.
6. После передачи задания открывается штатная работа с фоновым рендером.
   Дождись её завершения. После успешного назначения результат уже на цели.

Используется штатный путь экспорта, загрузки Sample, сброса обработки цели
и Undo. Отдельная цепочка FX и старый конструктор PCM Sample из r18a в
библиотеку не включены. EQ результата сбрасывается, чтобы не применить
запечённую обработку второй раз; Undo штатного сброса восстанавливает EQ.
Play/Stop и Main Volume сохраняют обычную маршрутизацию.

## Дополнительная проверка EQ

1. Открой EQ, выбери High Pass и подними Freq: сравни звук пэда с Bypass.
2. Переключись с EQ на другую вкладку: это сохраняет счётчики в журнал.
3. Выполни Sample Resample короткого звука на свободный пэд и послушай результат.
4. Если ошибка или тишина остались, не повторяй многократно — верни журнал.

## Остальные функции

В Sample Select и результатах поиска K3 подписан **Volume** и показывает
число и шкалу. Начальная громкость превью — **75%**. Регулятор виден
при выборе аудиофайла; Main Volume продолжает управлять общей громкостью.

Сначала используй короткий сэмпл и свободную цель. Проверь Sample без FX,
проигрывание результата и Undo. Затем повтори с заметным Pitch/Trim и
назначенным FX, затем с Bell и отрицательным Gain. Отдельно проверь Seq.
После сохранения проекта проверь восстановление EQ при повторном открытии.

Если вернулся обычный интерфейс после сбоя, штатно извлеки карту и верни её
в ПК: журнал теперь сохраняет содержимое native crashinfo перед очисткой RAM.
При обычном завершении — Project → Mod Off → подтверждение, затем Eject.

На дату сборки не подтверждены на устройстве: полный состав запечённой
обработки/хвост FX, рабочий выход Sample/Seq и повторная загрузка EQ. Это
цель аппаратной пробы, а не вывод из локального теста с подставным генератором.

## Питание

Согласованы только два будущих режима: Standard (штатное поведение) и
Low Battery (зарядка от USB только при низком заряде/красном индикаторе).
Пункт отключения USB-питания при USB-аудио исключён по просьбе пользователя.
Управление зарядкой в r19c не добавлено: подтверждённого аппаратного API
в исследованных файлах прошивки пока нет. Подробнее — POWER_CONFIG_RESEARCH_RU.md.
