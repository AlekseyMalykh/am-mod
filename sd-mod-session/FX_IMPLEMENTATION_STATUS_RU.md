## Уточнение25.10.2026 — два входа EQ

В r14c EQ по-прежнему не подключён. Следующая реализация должна включить:

1. Sample → Filter → **третью вкладку EQ** для выбранного пэда, с независимостью пэдов даже при общем исходном сэмпле.
2. **EQ как эффект FX Select** с назначением на несколько выбранных пэдов; пэды вне назначения не обрабатываются.
3. Общий графический редактор с раздельными состояниями индивидуального EQ, FX EQ и временного EQ ресэмплинга. Случайное удвоение одного экземпляра при открытии другого входа запрещено.

Прежнее упоминание категории Filter внутри FX Select не заменяет новую вкладку Sample → Filter. На встроенной вкладке сохранить верхние кнопки навигации; привязку Bypass проверить отдельно. Полный контракт: PARAMETRIC_EQ_DESIGN_RU.md.

## Готовый код

- src/fx_eq.c: стереоэквалайзер до четырёх точек, Bell, Low/High Shelf, HP/LP, включение отдельных полос, Output Gain и Bypass. Коэффициенты сглаживаются за 5 мс; кривая рассчитывается из тех же коэффициентов. Обработчик не обращается к UI, не выделяет память и не берёт блокировки. Пока не подключён к аудиотракту приложения.
- src/fx_chain.c: подготовка независимой цепочки, предел пять занятых слотов, замена/удаление/перестановка. Bypass не освобождает слот. Шестой эффект и неверные параметры отклоняются без изменения черновика. Ошибка создания промежуточного native FX освобождает уже подготовленные экземпляры.
- Передача целой подготовленной цепочки между одним управляющим и одним аудиопотоком: ограниченная очередь pending/retired, 5 мс перекрёстного затухания, освобождение экземпляров только вне аудиопотока. Переполненная очередь откладывает смену, не блокируя воспроизведение. Перед остановкой обмена аудиоколбэк должен быть остановлен и присоединён.

## Фактически выполненные проверки

verify_fx.py запускается в существующем WSL с ARM GCC/QEMU и закреплённым rootfs. Проверки обрабатывают реальные массивы звука: стереонезависимость, усиление синусоиды против рассчитанной кривой, точный Bypass после сглаживания, типы фильтров, крайние настройки, отказ на шестой слот, порядок пяти стадий, очистка при ошибке, 2000 конкурентных смен цепочки и отсутствие освобождения объектов в аудиопотоке.

check_fx_native.c исполняет фабрику 0x24c8290 с ID 81 закреплённого ELF. Она создаёт старый Parametric EQ с двумя полосами; native prepare/process/set/get и изменение звука подтверждены под QEMU. Этот процессор сам по себе не является новым пунктом обычного AC50 FX Select.

inspect_fx_catalog_native.c исполняет настоящий конструктор AC50KnobFxInserts 0x15581d0 до регистрации зависимостей движка. Получено 28 реальных описаний обычного FX Select; EQ среди них отсутствует. Описания имеют размер 0x158, список находится по +0x180/+0x188, категория Filter равна 3. Подмена в этом исследовательском тесте только останавливает исполнение после создания каталога; это не тест GUI/маршрутизации.

Статическая регистрация полного каталога содержит PEQ 4-Band с ID 0x41435666 и PEQ 2-Band, 2-Shelf с ID 0x41435667. В полном четырёхполосном редакторе видны группы параметров: Frequency 0/4/8/12, Q 1/5/9/13 и Gain 2/6/10/14. Реальное создание этого современного эффекта через обычную фабрику вставок и его звуковой тракт пока не проверены; не путать его с legacy ID 81.

## До аппаратной сборки

1. Подтвердить подключение зарегистрированного современного EQ к обычной фабрике вставок и его параметрам; проверить добавление описания в FX Select без повреждения существующих индексов/сохранений.
2. Подключить графический редактор, третью вкладку Sample → Filter → EQ и EQ в FX Select с назначением на несколько пэдов, Bypass, сохранение/Undo и независимость двух состояний. Выбрать один реальный DSP на экземпляр: не накладывать новый процессор поверх native EQ с той же обработкой.
3. Подключить независимую цепочку к Resample Pad, подстановку в миксе, Render/Apply/Cancel и сохранение полученного аудио. Не создавать ложный успешный рендер или пустой пункт UI.
4. Подтвердить точку копирования аудио и подключить фактический спектр входа/выхода. Пока измеренного спектра устройства нет.
5. Собрать отдельную пробную версию после этих проверок и выполнить аппаратную проверку ресурсов. Четыре слота — верхний предел, не гарантия любой комбинации FX в проекте.
