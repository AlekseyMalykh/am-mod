# r16d — прослушивание выбранного чопа C

На MPC подтверждено прослушивание L в r16c. При выборе C звук отсутствовал; журнал показывает завершение обработки нажатий без зависания. Точная причина тишины по прежнему журналу не определяется.

Для C подготовлен отдельный маршрут: полная копия выбранного события с номером Slice15 передаётся непосредственно обычному получателю Sample input (`211b090`) на той же штатной очереди. Промежуточное преобразование нажатия через MIDI не используется. Native `211aa30/2115070` преобразует исходный индекс пэда в MIDI-ноту. Рабочий маршрут L через `1e27360` сохранён.

Исходное событие отмечено янтарным и временно молчит в секвенции, последний выбор отмечен голубым. Пэд прослушивает выбор, отпускание останавливает его штатным механизмом `1e270d0`. B3 Apply сохраняет выбор, B1/B2 Cancel отменяют его. Данные исходного звука, чопы и события при прослушивании не изменяются. Play/Stop и Main Volume остаются штатными. Режим записи проверяется до постановки в очередь и на worker.

## Проверка на устройстве

Безопасно извлечь SD в Windows. MPC загрузить без карты; вставить карту после появления штатного интерфейса и подтвердить **Start r16d**.

1. Открыть C из Events при Stop, нажать исходный и другой чоп. Проверить звук, отпускание, Cancel и Apply.
2. Повторить из Steps и при воспроизведении секвенции. Исходное событие в открытом редакторе молчит; остальные продолжают играть.
3. Кратко повторить проверку L, чтобы подтвердить сохранность рабочего прослушивания.

При зависании не повторять нажатия, дождаться восстановления около минуты и вернуть карту с журналом. Для нормального выхода Project → Mod Off → подтверждение B3 → штатный Eject.

ARM/QEMU проверяет настоящие очередь, Sample input/release и для C цепочку `211b090 → 211aa30 → 2115070`, 16 номеров срезов, исходный звук из другого банка, сохранность параметров, отмену отложенного старта и режим записи. Регистрация дорожки, политики MIDI/записи и конечный sampler в стенде заменены адаптерами. Реальный звук C на MPC ещё требует проверки. Встроенная прошивка не записывается; сэмплы и проекты на SD сохраняются.
