# r16b — проверка выбора события БЕЗ прослушивания

**Звук в редакторе события Chop / 16 Levels временно отключён. Это диагностика, а не завершённое исправление.** r16a на устройстве снова зависла при нажатии пэда. После экстренного выключения обычная прошивка загрузилась. Полученный журнал подтверждает r16a, но не содержит места блокировки.

Удалён новый worker-hook r16a. Sample больше не создаёт запасной EventAudition при отрисовке. В редакторе пэды только выбирают значение; строка **SILENT TEST** показывает диагностический режим. На компьютере проверяется, что ни запуск/остановка EventAudition, ни sampler, ни очередь/её mutex при этом не вызываются. Обычные Sample, Chop, 16 Levels и Play/Stop секвенции сохраняют штатный маршрут.

Исходный вариант отмечен янтарным, последний выбранный — голубым; совпадение чередует два цвета. До первого выбора нового голубого маркера нет. Целевой сценарий после устранения сбоя — обычная игра 16 Levels/Chop через штатный Sample input, независимо от Stop/Play, с записью результата в выбранное событие по Apply. При воспроизведении секвенции редактируемое исходное событие должно временно молчать, остальные играют. **Это подавление в r16a не было реализовано; в диагностической r16b его также нет.** Сейчас разделяем проверку выбора и запуск звука; полное прослушивание и временный фильтр исходного события остаются открытыми задачами.

Этапы PAD_BUSY → PAD_SELECTED → PAD_DONE пишутся в RAM; существующий supervisor переносит снимок в журнал SD. Если обработчик пэда остаётся незавершённым 15 проверок supervisor, он запрашивает штатное восстановление. Это относится только к нажатому пэду редактора, не ограничивает время работы мода и не проверяет сохранение/загрузку проектов. Возврат после зависания на аппаратуре ещё не проверен.

## Одна короткая проверка

1. Безопасно извлечь SD в Windows; вставить после полной загрузки MPC, подтвердить **Start r16b SILENT diagnostic**.
2. Открыть Events → строку L → 16 Levels. Должна быть надпись **SILENT TEST**. Нажать несколько пэдов: **звука не будет**, но выбранное значение должно меняться, экран и кнопки — отвечать. Сначала Cancel; затем повторно выбрать значение и Apply.
3. Если это работает, повторить выбор L/C из Steps. Проверить обычное воспроизведение секвенции уже после выхода из редактора.
4. Mod Off → подтвердить B3 → штатный Eject → вернуть карту в ПК. Если снова зависнет на пэде, дать автоматическому восстановлению около минуты; если не вернулось, сообщить об этом. Не повторять зависающий тест.

Результат нужен для следующего исправления: работает ли выбор и Apply без прослушивания. Сэмплы и проекты не очищаются. Реальное исправление прослушивания остаётся открытой задачей. Локальные проверки не подтверждают работу на устройстве.
