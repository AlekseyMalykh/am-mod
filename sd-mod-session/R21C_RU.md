# r21c — разделение подсветки и повтор диагностики питания

Исправлена регрессия r21: включённая лампа Mute больше не переключает
отображение 16 Levels в обычный банк. Внутри Tune/Chop подсвечиваются
события выбранного звука и их ноты/чопы. Одновременные события показываются
несколькими пэдами. На обычном экране Seq мод больше не накладывает эти вспышки.
В Sample при удержании Shift над B3 отображается Stereo > Mono.

Потеря второй ноты при живой записи Poly подтверждена пользователем:
в списке Events остаётся одна строка. Причина ещё не установлена, баг
не объявляется исправленным. В Events отдельные ноты
хранятся отдельными строками; редактор 16 Levels пока открывает одну выбранную
строку. Предложение общего редактора аккорда с индивидуальной velocity —
следующий этап, оно ещё не внедрено.

В r21b отчёт питания не появился: на устройстве нет утилиты timeout.
Теперь ограничение времени выполняет собственный небольшой ARM-помощник:
до 1 секунды на чтение свойства, до 20 секунд на весь отчёт. Он открывает
только разрешённые пути /sys и /proc с O_RDONLY. Переключатель зарядки в
Input Config пока отсутствует, зарядка остаётся штатной.

Безопасно извлеки карту Windows, загрузи MPC без карты, подключи обычное
USB-питание, вставь SD и подтверди Start r21c. Проверь подсветку 16 Levels
при воспроизведении мелодии выбранного звука и отсутствие чужих пэдов.
Для Poly запиши две высоты в одной позиции и проверь количество отдельных
строк одного пэда в Events. Если строка одна, сохрани тестовый проект на
External под новым именем polycheck, чтобы можно было проверить данные.

После пробы: Mod Off → дождаться штатного интерфейса → Eject → карта в ПК.
Для диагностики питания нужен файл MPC_POWER_AUDIT.txt в корне SD.

Локально проверены реальные контейнеры событий и фильтрация подсветки,
переходы режимов, подпись Shift+B3, загрузка библиотеки, прежние EQ/браузер/
Steps/ввод текста; сбор отчёта проверен на ARM с тестовой файловой системой.
Аппаратная проверка новой сборки ещё не выполнена.
