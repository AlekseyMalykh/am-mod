# r20g — загрузка фактически записанного WAV

Пробная сборка MPC Sample 1.3.0.12. Исправлено подтверждённое расхождение
между файлом записи Sample и файлом, который штатный callback загружает пэду.
28 октября пользователь подтвердил успешный ресемплинг Sample со звуком
на целевом пэде. Проверка остальных сценариев продолжается.

## Доказательство из сравнения r20f

Seq: файл записи и импорта совпадают, PCM24 WAV имеет пик0,999999881,
штатное назначение целевому пэду выполнено.

Sample: аудио доходит до основного накопителя записи (пики0,3025 и0,3182
для двух разных звуков). Но writer использует имя
«имя Resample 1-Track-001-Drum 001.wav», а callback импорта открывает
«имя Resample 1.wav». Второй файл полностью нулевой. Поэтому прежние
проверки сигнала проходили, а защита перед импортом отклоняла результат.
Обработка действительно запускается; проблема обнаружена в выборе файла.

## Исправление

Для частного Sample запоминается реальный путь writer до его закрытия.
После рендера проверяется фактически созданный WAV: формат, частота,
минимальная длительность и ненулевые данные. Сохраняется открытый файловый
дескриптор, поэтому штатная последующая очистка имени файла не теряет звук.

Когда штатная задача полностью завершилась, перед её callback импорта,
проверенный WAV копируется через временный файл в ожидаемое имя результата
и атомарно заменяет пустой файл. Загружать пэд, создавать Undo и назначать
результат продолжает штатный callback. Если ожидаемый WAV уже содержит звук,
он сохраняется. Ошибка копирования оставляет прежний файл и целевой пэд.

Принимается только WAV этой же задачи: совпадающая папка и точный префикс
её собственного имени с суффиксом -Track-. Посторонние пути и ссылки
отклоняются. Работа идёт с временными файлами проекта внутри RAM-слоя мода;
внутренняя прошивка не перезаписывается. Отдельный повторный DSP-рендер и
запись в реальном времени не добавлялись.

## Проверки

Локально воспроизведена пара: ненулевой файл дорожки и нулевой запрошенный
WAV. Рабочая функция завершения переносит побайтно тот же PCM и запускается
до проверки/назначения в production callback. Проверены обычный запуск и
UBSan, удаление имени дорожки штатной очисткой, неверный путь/задача,
частота/длина, тихий источник, ссылки, изменённый размер исходного файла,
отказ операции и сохранение уже звучащего штатного WAV.

Также проходят прежние проверки ARM-цикла, native WAV-кодировщика,
Loop/отмены/ошибок, штатного Seq и полной сборки. Полный DSP устройства
локально не воспроизводится; аппаратная проба остаётся необходимой.

## Одна проба

1. Безопасно извлеки карту в Windows. Загрузи MPC без карты, вставь SD
   и подтверди Start r20g.
2. Выбери короткий звучащий сэмпл без FX, EQ — Bypass.
3. Shift+пэд11 → B3 Sample → свободный пэд → B3 Render.
4. Проверь звук на целевом пэде; при ошибке одной попытки достаточно.
5. Project → Mod Off → подтверждение → дождаться штатного интерфейса.
   Затем штатный Eject → карта в ПК, чтобы сохранился полный журнал.

Повторять Seq или Sample Record для этой пробы не требуется. Проекты и
сэмплы на SD сохраняются.
