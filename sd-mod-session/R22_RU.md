# r22 — автокопия проекта перед выходом и запуск с картой

Сборка для проверки в виртуальной лаборатории. Аппаратная проверка не завершена.

- Project → Mod Off → B3 сначала сохраняет отдельный проект на SD:
  `MPC-Sample/Projects/Mod-Exit-<уникальный код>/Project.xpj`.
  Используется штатное сохранение проекта со сэмплами. Старые файлы не заменяются.
  После подтверждённой записи настроек мода и сброса данных на SD выполняется выход.
  Ошибка сохранения оставляет мод включённым; доступны Back и Retry.
  Проверяется завершение штатной очереди записи, включая ошибку её future,
  затем файл повторно открывается и выполняется syncfs. Одной сериализации
  проекта недостаточно: штатная запись завершается асинхронно.
  Ссылки на задания удерживаются до завершения; ожидание начинается только
  после возврата штатного SaveProject, когда его блокировки освобождены.
- Исправлен путь ввода для Shift+K1 в Seq. Цвет секвенции теперь получает
  обработчик мода, а не штатная настройка тактового размера.
  Доступны пять ранее согласованных цветов; настройки независимы для секвенций.
- Исправление окна Stereo → Mono из r21d сохранено: Sample → Shift+B3,
  целевой пэд, B1 Cancel / B2 Left / B3 Right, подтверждение замены занятого пэда.
- Для проверки загрузки со вставленной картой autorun запускается без
  предварительного штатного вопроса, как в загрузчике сообщества. Это также означает
  автоматический запуск при вставке карты в уже включённый MPC.
- Исправлена гонка защитного загрузчика: появление `clone-verified` между
  проверками больше не вызывает ошибочное восстановление штатного приложения.
- Добавлена пробная заставка в паузе между остановкой штатного приложения
  и запуском клона: привычный белый квадрат из 16 пэдов, затем отдельные
  цветные квадратики по краям и переход к рисунку Steps с бегущим курсором.
  Заставка работает через штатную службу отображения, завершается перед
  запуском клона и не управляет звуком или подсветкой физических пэдов.
  Она не увеличивает ожидание запуска; на быстром переключении последние
  кадры могут быть пропущены. Если служба недоступна, загрузка продолжается.
  На настоящем MPC анимация ещё не проверена; виртуальная машина эту службу
  не эмулирует. Кадры и безопасный пропуск службы проверены отдельно.

Orig Note из Tune → Shift+K1, общая тональность, настройки Lights и цвета
секвенций входят в расширение штатного проекта. Переоткрывать проект с модом;
штатная прошивка не показывает добавленные модом настройки.

Внутренняя прошивка не переписывается. Internal мода остаётся временным.
После Mod Off копия доступна через обычный Load Project; автоматическая загрузка
этой копии в штатном приложении не добавлена.

## Известные незавершённые пункты

- Живая запись двух одновременных нот одного звука в 16 Levels Tune / Poly
  сохраняет одно событие. Ошибка подтверждена в виртуальной машине по данным
  проекта; эта сборка пока её не исправляет.
- Режимы зарядки Standard / Low Battery ещё не реализованы: доступного средства
  переключения зарядки на устройстве пока не найдено. Есть только отчёт чтения.
- Виртуальная ARM-машина на x86 медленнее MPC. Её увеличенные таймауты
  настройки стенда не меняют таймауты пакета для настоящего устройства.

Лаборатория и команды запуска описаны в `lab/README_RU.md`.

## Проверено 29 октября в лаборатории

На проекте с четырьмя сэмплами создана и повторно загружена штатным приложением
отдельная копия: Orig Note = F#, Key = F# Dorian и Seq Colour = Violet восстановлены.
Все четыре WAV содержат звуковые данные; проверены обычный PCM и float WAV.
После исправления ожидания очереди отдельно сохранён и повторно загружен проект
со 127 сэмплами: получены 127 WAV и Project.xpj. Виртуальная SD — отдельный
образ 2 ГБ. Это не проверка карты настоящего MPC. Тест Stereo → Mono проверил диалог,
выбор целевого пэда, преобразование и штатный Undo.
В дополнительной копии большого проекта отдельно подтверждены Orig Note = F#,
Key = F# Dorian и Seq Colour = Violet в штатном XPJ.

В `lab/verification.json` перечислены пройденные и незавершённые проверки.
Результаты временных опытов с аккордами не включены в библиотеку мода.
