# r15b — общий уровень Preview и вход в Chop Batch

Сборка для аппаратной проверки. Установленная прошивка не изменяется. Результаты ARM/QEMU пока не подтверждают реальный уровень на выходах MPC.

## Preview Volume

Main Volume — общий регулятор, включая предпрослушивание. K3 Preview Vol дополнительно ослабляет Preview относительно этого уровня. Начальное значение K3 в новой сессии мода — 25%; диапазон 0–100%. Изменения K3 не меняют громкость обычных пэдов.

Исправлен перехват событий физического Main Volume: поиск и Batch больше не поглощают их. Они сразу передаются штатному обработчику, без очереди модального окна. Общий уровень применяется штатным выходным микшером; повторно умножать его внутри Preview не нужно.

Связь с предпрослушиванием берётся из реально установленного штатного обработчика браузера, без предварительного входа в Copy. Общий уровень читается из штатного параметра, связанного с физическим Main Volume. Его родная кривая сохраняется. Текущий Preview следует за изменениями общего уровня через UI-таймер мода.

Если нельзя проверить регулятор, инструмент предпросмотра или его кривую, выводится красное **Not ready**, а запрос Preview блокируется. Запуска на прежней полной громкости при этом быть не должно. Причина записывается в журнал.

Первая проверка:

1. Включить MPC без SD, дождаться обычного интерфейса. Вставить карту, подтвердить **Start r15b**.
2. Поставить **Main Volume в ноль**. В Sample Select нажать Preview, затем проверить Preview найденного сэмпла. Звука быть не должно, в том числе при K3 = 100%.
3. С K3 = 25% понемногу поднять Main Volume. Во время длинного Preview уменьшить Main Volume до нуля: звук должен затихнуть. Проверить K3 = 0% отдельно.
4. Если написано Not ready, не пытаться обходить блокировку: вернуть карту после Mod Off и штатного Eject для чтения журнала.

## Chop Batch

В обычном **Chop** с волной и срезами удерживать Shift:

- B1 — штатный одиночный Extract.
- B2 — Batch: отдельный менеджер выбора нескольких срезов.
- B3 — Split.

В Sources нажимать нужные чопы: выбранные зелёные. **Next / Targets** открывает таблицу «чоп → целевой пэд». Можно выбрать банк и свободные места автоматически либо назначать вручную. Свободные пэды фиолетовые, занятые красные, назначенные цели голубые, текущее назначение янтарное. Исходный звук защищён от перезаписи; занятая цель требует отдельного подтверждения. Предел — 16 выбранных чопов. Извлечение последовательное, с прогрессом и общей Undo-командой.

Исправлена проверка входа: отдельные обёртки CurrentThings допустимы, если они указывают на один Program. Источник берётся из закреплённого инструмента Chop. Видимый штатный Chop больше не отклоняется только из-за другого идентификатора режима. Отказы входа пишутся в журнал.

Первая проба — **два коротких чопа на два свободных пэда**. После окончания закрыть результат, прослушать пэды, проверить Undo/Redo. Результат сохранить на External и затем открыть в штатном приложении. Полный процесс PCM/SamplePool/сохранения требует этой аппаратной проверки.

## Остальное

Поиск и управление сохраняются: пэд выбирает цель без звука; клик энкодера загружает сэмпл, оставаясь в поиске; Shift+клик открывает его папку с выделением файла; B3 — Preview. Открытие проекта требует подтверждения.

Выход: **Project → Mod Off → штатный Eject**. В Windows перед переносом карты выбирать **«Извлечь»**. Загрузка устройства с заранее вставленной активной autorun-картой ещё не исправлена; использовать вставку после загрузки. Internal мода остаётся временным в RAM.

На компьютере проверены штатный обработчик Preview, блокировка без Main Volume, зависимость реального нативного усиления от физического регулятора и K3, ноль Main при K3 = 100%, вход в менеджер с разными обёртками одного проекта, выбор 16 чопов и таблица целей. Реальные аудиовыходы, пэды и жизненный цикл приложения проверяются на MPC.
