# r15a — Chop Batch, прослушивание событий и поиск

Исправления после аппаратной пробы r15. Новая сборка требует проверки на MPC; результаты ARM/QEMU не являются проверкой реального звука устройства.

## Обычный Chop: одиночный и групповой Extract

Открыть сэмпл в обычном режиме **Chop**, где видны волна и срезы. Удерживать Shift:

- **B1 Extract** — штатное извлечение одного среза.
- **B2 Batch** — выбор от 1 до 16 срезов и таблица назначений на пэды.
- **B3 Split** — штатное разделение среза; Merge заменён на Batch.

Вход больше не зависит от режима Slice внутри 16 Levels. Исправлены адреса GlobalControls и CurrentThings у SampleModeScreen. Временное окно выбора события Chop из Events/Steps не используется для Extract.

Первый тест Batch: два коротких чопа на два свободных пэда. Проверить результат на слух, затем Undo/Redo. Сохранение — External под новым именем. После Mod Off открыть результат в штатном приложении.

## Прослушивание Chop / Levels из Events и Steps

Нажатие пэда во временном окне выбирает и прослушивает вариант события; отпускание останавливает пробу. B3 Apply сохраняет выбор, B1/B2 отменяют.

Убрана ошибочная проверка равенства объектов CurrentThings. Если приложение Sample не создало необязательный сервис EventAudition, мод создаёт один экземпляр штатным конструктором и связывает его с существующей очередью, CurrentThings и получателем Sequencer. Экземпляр живёт всю сессию, включая выполнение отложенных команд. Используется штатный путь EventAudition через очередь; изменение события до Apply не выполняется.

## Поиск

Sample Select / Open Project → **Shift+B3 Search**. При вводе в Sample Select **Shift+K3** выбирает Folder / Subfolders / Library; обычный K3 управляет Preview Volume. В поиске проектов K3 выбирает область. Library ищет от папки Samples или Projects, содержащей текущую папку; если такой папки в пути нет, от текущей папки.

Исправлена основная ошибка r15: типы браузера были перепутаны. Штатный тип 0 — сэмплы, тип 1 — проекты. Теперь поиск сэмплов в подпапках отбирает аудиофайлы, поиск проектов — XPJ; загрузка и Preview вызывают соответствующие штатные обработчики.

Текущий каталог берётся непосредственно из BrowserLogic, а не из кеша списка. Чтение подпапок включает скрытые и связанные каталоги; повторный обход одного каталога исключён по устройству/номеру inode, сохранены ограничения глубины и количества. Ошибка открытия корня показывает ошибку, вместо незаметного поиска только в одной папке. В журнал добавлены корень, количество найденных файлов и ошибки чтения.

Лимит 4096 относится к найденным результатам, а не к первым файлам библиотеки. Новый запрос перезапускает незавершённый/ограниченный обход и отбирает совпадения по ходу чтения. Проверен случай библиотеки из более 4100 файлов. Ограничения обхода: 512 каталогов, глубина 16, до 50 000 записей каталогов; при достижении предела видна соответствующая отметка.

В результатах:

- Энкодер и +/− выбирают найденный файл.
- Пэд бесшумно выбирает место загрузки; банк переключается штатной кнопкой. Выбранная цель указана внизу слева.
- **Клик энкодера — загрузить сэмпл на выбранный пэд, оставаясь в поиске.** Затем можно выбрать другой пэд/результат и повторить загрузку.
- **B3 Preview** прослушивает найденный сэмпл, не загружая его на пэд.
- **Shift+клик энкодера — Show in folder**: закрывает поиск, открывает родительскую папку в штатном браузере и выделяет найденный файл. Например, поиск от корня может перейти прямо в MPC-Sample/Samples/User. Выделение выполняется после обновления штатного списка; переход ничего не загружает.
- В поиске проектов клик энкодера или B3 сначала открывает **подтверждение с именем проекта**. B3 Open подтверждает открытие, B1 Cancel оставляет список результатов. Штатная защита несохранённого проекта сохраняется. Shift+клик только показывает XPJ в его папке, без подтверждения и открытия проекта.
- B2 возвращает к запросу; B1 закрывает поиск.

Preview вызывает штатный onSamplePreview. Загрузка сэмпла вызывает onSampleSelected, загрузка проекта после подтверждения — onProjectSelected. Эти три действия разделены и проверены по штатным RTTI-именам и обработчикам.

## Громкость Preview

**K3 Preview Vol, 0–100%** доступен и в обычном Sample Select, и в поиске сэмплов. Значение общее для этих окон на время сессии мода. В обычном браузере Shift+K3 передаётся штатному обработчику; в окне ввода поиска это выбор области.

Меняется штатный параметр SampleFileAudition: его собственная очередь направляет громкость только инструменту предпросмотра. Громкость музыкальных пэдов, проекта и общего выхода не изменяется. Проверки выполняют настоящий float-property setter и штатную очередь изменения громкости с тестовым получателем; реальный звук и поведение загрузки на MPC ещё предстоит подтвердить.

## Запуск и ограничения

Включить MPC без карты, дождаться штатного интерфейса, вставить карту и подтвердить **Start r15a**. Холодная загрузка с активной autorun-картой ещё не исправлена. Выход: Project → Mod Off → штатный Eject. Internal мода временный; постоянные результаты сохранять на External. После ПК использовать Windows «Извлечь».

Исправление Mute из r15 сохранено; подтверждение его звучания на устройстве остаётся отдельной проверкой. При ошибке Batch или погасшем экране повторять операцию до чтения журнала не нужно.
