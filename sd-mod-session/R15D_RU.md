# r15d — блокировка аварийного прослушивания Chop Batch

Пользователь сообщил: в r15c после нажатия энкодера в Batch экран погас и вернулось штатное приложение. Точный вид Batch и журнал этой пробы пока ожидаются. Успех ARM/QEMU с тестовым конечным звуковым обработчиком не подтвердил работу прослушивания на устройстве.

В r15d новый вызов EventAudition **из Chop Batch отключён**. Нажатие энкодера показывает `Chop audition disabled after r15c crash` и не отправляет звуковую команду. Вращение энкодера, выбор чопов и целей, сам Batch Extract сохранены. Прослушивание чопов в Batch не считается завершённой функцией; для его восстановления нужна проверка реального звукового маршрута.

Остальные изменения r15c сохранены: поддержка Preview Volume с кривой №3, K3 только на аудиофайле, Erase → штатный Delete с родным подтверждением в User, отсутствие Shift+B2 Eject в браузере мода. Их аппаратные результаты в этой пробе не получены.

Перед записью обновления необходимо сохранить журнал r15c с возвращённой SD. Устройство уже восстановило штатный интерфейс: извлечь карту его штатным Eject и подключить к компьютеру. Повторять аварийное нажатие не нужно.

Запуск — вставить SD после полной загрузки MPC без карты. Возврат — Mod Off, затем штатный Eject. Internal мода остаётся временным в RAM.
