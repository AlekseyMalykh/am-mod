# r22c — подсветка секвенций

В Seq цвет текущей секвенции выбирается через Shift + K1. Доступны 12 цветов:
Cyan, Green, Amber, Violet, Magenta, Red, Orange, Yellow, Blue, Lime, Mint, White.
Первые пять цветов сохраняют прежние номера. Подсветка стала ярче;
при удержании Shift выбранные цвета сохраняются.

Пустой считается секвенция без событий. Изменение имени или длины не делает
её заполненной. Выбранная пустая секвенция видна; остальные пустые погашены.
Первое событие включает цвет; удаление последнего снова гасит пэд,
если секвенция не выбрана. Заглушённое событие тоже считается событием.

Воспроизводимая секвенция мигает быстрее. Темп штатного мигания выбранной
и ожидающей секвенций сохранён. Mute, Erase и выбор банка сохраняют свои
штатные обозначения.

Настройки цветов сохраняются в проекте. При выборе одного из новых семи
цветов расширение настроек мода использует MPCS16. Для таких проектов
нужна r22c или новее, чтобы восстановить настройки мода; само музыкальное
содержимое XPJ остаётся штатным. Со старыми пятью цветами сохраняется MPCS15.

Исправления записи аккордов r22b сохранены. Новая заставка отключена.
Автосохранение отдельной SD-копии проекта при Mod Off сохранено.

## Проверка на устройстве

1. В Seq выбрать пустую секвенцию: её пэд должен быть виден, остальные
   пустые — погашены.
2. Через Shift + K1 выбрать цвет. При Shift цвет не должен заменяться зелёным.
3. Записать событие, выбрать другую секвенцию: заполненный пэд остаётся виден.
4. Проверить более быстрое мигание воспроизводимой секвенции.
5. Сохранить проект и открыть его снова: цвета должны восстановиться.

Изменения проверены на ARM/QEMU и автоматическими проверками; первая проба
на настоящем устройстве ещё нужна. Управление зарядкой и штатное окно
выключения коротким нажатием питания в моде пока не добавлены.

Выключение: Project → Mod Off → подтвердить, дождаться сохранения SD-копии
и возврата штатного интерфейса, затем выключить обычной кнопкой питания.
Для переноса карты в ПК после Mod Off выполнить штатный Eject.
Из Windows карту тоже извлекать безопасно. При запуске MPC сначала дождаться
загрузки без карты, затем вставить SD.
