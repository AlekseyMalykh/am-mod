# Выключение из мода: кандидат r23

На 29.10.2026 код подготовлен для проверки. На физическую SD этот кандидат
пока не записан. Последняя установленная версия — r22c.

## Предусмотренный порядок

1. Короткое нажатие питания открывает штатный вопрос выключения.
2. Отказ оставляет приложение работающим.
3. Подтверждение останавливает секвенцию и сохраняет отдельную копию проекта
   вместе с сэмплами в `MPC-Sample/Projects/Mod-Exit-…/Project.xpj` на SD.
4. Приложение ждёт завершения штатных задач записи и `syncfs`.
5. Внешний supervisor завершает клон, сбрасывает записи SD, закрывает временный
   слой данных и только затем передаёт ОС команду выключения.

Если SD недоступна, сохранение не завершено или идёт Copy/Resample,
выключение не разрешается. При ошибке сохранения предусмотрены возврат и
повторная попытка. Обычный Mod Off и сбой приложения не выключают устройство.
Долгое аварийное удержание питания эта функция не изменяет.

## Как возвращается событие кнопки

В этой прошивке короткое нажатие приходит как Linux `KEY_POWER`, а не как
команда пэда от панели. Для распознавания libinput клону нужна база udev.
В sandbox добавлен доступ только на чтение к `/run/udev/data`.
Системная шина и команды выключения остаются за пределами клона.

## Что проверено

`verify_power_button.py` исполняет ARM-вход штатного вопроса с перемещёнными
инструкциями и проверяет PAC/стек, отказ, подтверждение, повторное нажатие,
ошибку сохранения, повтор, запрет выключения во время обработки и запрос
только после готовности SD-копии. Проверка повторяется с UBSan.
Отдельно проверяется порядок сброса SD и выключения в production-ветке
launcher; последняя команда ОС заменена тестовым приёмником.

Полный constructor собранной библиотеки проверен со всеми прежними патчами
RAM-копии. Эти проверки не исполняют основной цикл приложения и не заменяют
проверку короткого нажатия в полном эмуляторе или на MPC.

Полная проверка QEMU пока не завершена: запуск sandbox остановился на
`PROXY_SOCKET_MISSING`; сокет появился позднее установленного таймаута.
Это результат стенда, а не подтверждённая ошибка на устройстве. Таймаут
production-пакета ради эмулятора не увеличивался.
При продолжении лабораторного запуска проверка отказала из-за изменившейся
идентичности сокета proxy (`wrong_socket`). Защита не обходилась; основной
цикл клона не был запущен. Исходный проект эмулятора с 127 файлами сэмплов
восстановлен, временные изменения загрузки стенда отменены.

## Сопутствующие изменения кандидата

- Seq сохраняет пользовательские цвета при Shift и Erase.
- Seq → Mute показывает вспышки исходных звучащих звуков; обычный Seq
  продолжает показывать секвенции. Штатные цвета Mute сохранены.
- В Copy/Extract/Resample/Stereo → Mono свободные места погашены.
  Источники зелёные, назначенные цели голубые, текущая цель янтарная,
  занятые места для замены — приглушённые красные.

Orig Note C найдена в нескольких Mod-Exit-копиях на SD. Проект с именем
2710slow на прочитанной карте не найден, поэтому причина пропажи ноты при
повторном открытии ещё не установлена. Это не отмечено как исправленный баг.

Режимы зарядки Standard / Low Battery ещё не реализованы: подтверждённого
интерфейса управления зарядкой AC50 нет. Исследование описано в
[POWER_CONFIG_RESEARCH_RU.md](POWER_CONFIG_RESEARCH_RU.md).

До установки и проверки новой версии: Project → Mod Off, дождаться SD-копии
и возврата штатного интерфейса, затем выключить обычной кнопкой. Для переноса
карты в ПК после Mod Off выполнить штатный Eject.
