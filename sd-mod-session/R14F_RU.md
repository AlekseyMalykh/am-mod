# r14f — Steps, Mute, прослушивание событий и Knob FX

Сборка для аппаратной пробы. В предыдущей r14e пользователь подтвердил хорошую работу Batch Copy. Этот результат сохраняется отдельно от новых изменений.

## Что изменено

- В Steps кнопки Chop / 16 Levels подсвечиваются по событиям выбранного звука под курсором. Обычная нота не включает эти кнопки; смешанный шаг может включать обе. Follow при воспроизведении не подменяет выбранный шаг другой страницей. Открытие редактора использует тот же курсор.
- Mute теперь подавляет запуск заглушённой ноты в моде. Причина прежней ошибки воспроизведена: штатный отправитель событий пропускает флаг IsMuted. Новый короткий ARM-фильтр пропускает обычные ноты и Note Off, блокируя только muted Note On. Флаг, velocity и остальные данные события не переписываются при воспроизведении.
- Shift+Mute размючивает все события выбранного Sound по всей секвенции, одной Undo-командой. Другие звуки не меняются.
- Shift+энкодер переносит события выбранного звука на текущем шаге по сетке, с переходом через границы секвенции по кругу. При нескольких событиях двигается вся группа с сохранением относительного времени и параметров. Пустой шаг перемещает только курсор.
- Удержание Shift сохраняет шаговую RGB-подсветку. Штатные Shift+пэд команды остаются доступны. Выбранный заглушённый шаг янтарный, проигрываемый — голубой; статус Muted остаётся в окне.
- В редакторе события Chop / Levels из Events или Steps нажатие пэда прослушивает выбранный вариант через штатный EventAudition. Отпускание останавливает пробу. B3 Apply меняет запись; B1/B2 отменяет. Само прослушивание не применяет изменения к событию.
- В Knob FX возвращён непрозрачный янтарный фон над K1–K3 с чёрными подписями, значениями и доступной S. Нижний блок закрывает скобку фокуса родительского окна; остальные окна сохраняют чёрный фон.

## Короткая проверка

1. Безопасно извлечь SD в Windows. Включить MPC **без карты**, дождаться обычного интерфейса, вставить SD и подтвердить Start r14f. Проверить Project → Mod Off.
2. В тестовом проекте открыть Steps. Выбрать шаг с Chop, затем с Levels и обычной нотой: проверить соответствующую подсветку кнопок и вход в редактор. При включённом Follow повторить, когда воспроизведение на другой странице.
3. Заглушить один повторяющийся шаг, нажать Stop → Play и послушать несколько кругов. Нота должна остаться в секвенции, но перестать запускаться. Проверить повторное включение, Shift+Mute выбранного звука и Undo.
4. На заполненном шаге Shift+энкодером передвинуть событие; проверить переход через конец секвенции и Undo. Удержать Shift и проверить, что RGB не возвращается к обычным пэдам.
5. Из Events и Steps открыть Chop / Levels: пэд должен прослушивать вариант, отпускание — останавливать. Cancel сохраняет исходное событие, Apply применяет выбор.
6. Открыть Knob FX из окна с выбранным K3, затем из окна с другим фокусом. Проверить янтарный фон, читаемые подписи/шкалы и отсутствие чужой скобки.

На компьютерном ARM-стенде выполнены настоящие native команды Mute/Unmute/переноса с Undo, отправитель событий до и после фильтра, EventAudition и его рабочая очередь. Получатель звука, физические LED и графическая поверхность в этих проверках заменены тестовыми адаптерами. Реальные звук, цвета и жизненный цикл на MPC требуют этой пробы. Подавление muted Note On относится к запущенному моду; воспроизведение этого флага в штатном приложении отдельно не подтверждено.

## Что ещё не включено

Chop Batch Extract остаётся отдельным прототипом, не доступным в r14f. Проверен настоящий поток обрезки стерео PCM на тестовом источнике: начало/конец, полный и однокадровый срез, seek/EOF и освобождение ресурсов. Настоящий успешный SamplePool/сохранение/повторное открытие результата ещё не проверены. Новые подписи Shift+B2 Batch / Shift+B3 Split в эту сборку не включены.

Холодная загрузка с активной autorun-картой всё ещё может зависать на 0%; вставлять карту после штатной загрузки. Для возврата: Project → Mod Off → штатный Eject. Сохранения Internal мода временные; для переноса нужен External.
