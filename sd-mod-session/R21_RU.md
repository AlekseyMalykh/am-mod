# r21 — выбор нот и исправления управления

Пробная сборка для MPC Sample 1.3.0.12. Сохраняет быстрый ресемплинг r20g,
для которого пользователь подтвердил звук. Внутренняя прошивка не изменяется.
Новые изменения r21 ещё требуют проверки на MPC.

## Ноты в Events / Step Edit и Steps

Открой событие L кнопкой 16 Levels. В типе Tune пэды выбираются по одному:
нажатие добавляет ноту в набор, повторное нажатие убирает её. Можно выбрать
до 16 разных высот, в том числе через переключение диапазона. Старое событие
отмечено янтарным, выбранные ноты — голубым. Исходная и выбранная одновременно
нота чередует эти цвета. Пэды позволяют прослушивать выбранную высоту.

B3 Apply заменяет исходное событие отдельными событиями для каждой выбранной
ноты, в той же позиции, с сохранением длительности и прочих свойств. Это одна
команда Undo. B1/B2 Cancel не меняют события. Если снять весь выбор, Apply
просит выбрать хотя бы одну ноту; случайно удалить исходное событие нельзя.
Другие типы 16 Levels и Chop сохраняют одиночный выбор.

На пустом шаге Steps включи Seq Record, выбери шаг и нажми 16 Levels:
откроется новый Tune без временного события в секвенции. Набери ноты и нажми
Apply. При Write Off новые события этим способом не создаются. Если шаг
успел заполниться до Apply, запись отклоняется; чужие события не заменяются.
Уже заполненный обычным событием шаг автоматически в L не превращается.

В обычном Sample пэды продолжают играть и передаваться штатной записи,
без переключения «выбрана / снята». Проверка маршрута подтверждает передачу
нескольких одновременно удерживаемых пэдов, отпусканий и повторных нажатий.
Штатный контейнер хранит разные высоты в одной позиции отдельно; сканер
подсветки показывает все такие ноты. Полная живая запись Poly на аппаратуре
локально не воспроизводится и пока не объявляется исправленной.

## Mute, Note Repeat, цвет секвенции

- В обычных Sample/Seq при Mute звучащий пэд кратко загорается голубым поверх
  штатной палитры. Заглушённый пэд сохраняет красный цвет: проверяется штатный
  флаг инструмента, а не цвет светодиода. Это показывает начало события,
  а не измеряет фактическую громкость аудио.
- В Steps при Mute события жёлтые, заглушённые красные; бегунок на событии
  белый, на заглушённом чередует голубой/красный. Выбор шага также остаётся
  различимым. При Erase доступные для удаления события оранжевые.
- Удержание Note Repeat исключает управление скрытой вкладкой Lights.
  Подложка окна закрывает рамку K3 нижележащего экрана.
- На обычном экране Seq: Shift+K1 — пять цветов секвенции. Цвет виден меткой
  справа от заголовка. Настройка независима для каждой секвенции и сохраняется
  с проектом. Раскраска пэдов выбора секвенций этой сборкой не добавлена.
  Без Shift K1 сохраняет штатную функцию Length.

## Остановка перед ресемплингом

Если воспроизведение идёт, собственный диалог предлагает Stop playback?
B1 OK отправляет штатный Stop. Рендер передаётся штатному обработчику только
после подтверждённой остановки транспорта. B3 Cancel возвращает выбор цели
и не запускает рендер. При неизвестном состоянии транспорта запуск также
откладывается. Повторная проверка в обработчике защищает от нового Play
между подтверждением и исполнением. Если остановка не подтверждена за 3 сек,
задача не отправляется. Причина прежнего зависания на MPC ещё не доказана;
эта сборка устраняет вход в синхронный штатный диалог из очереди рендера.

Поведение Erase в обычном Sample в этой сборке отдельно не переписано:
при остановленном транспорте удаление звука остаётся штатным, обработчик
удаления выбранной строки мода принадлежит Events. Если описанный сбой
сохраняется, нужен отдельный пример после проверки r21.

## Локальные проверки и аппаратная проба

ARM-проверки выполняют настоящие контейнеры и сравнение событий прошивки,
применяют набор высот как отдельные события, проверяют повторный выбор,
Cancel, пустой шаг и подсветку нескольких нот. Дополнительно проверены
сохранение 128 цветов, чтение прежних проектов, Repeat и Seq vtable,
подтверждение остановки/отмена/отпускание кнопок. Прежние проверки быстрого
рендера, EQ, поиска и ввода текста также проходят, включая UBSan.
GUI-получатели и аудиотракт в стендах частично заменены; это не аппаратная
проверка и не обещание отсутствия зависаний.

1. Безопасно извлеки SD в Windows. Загрузи MPC без карты, затем вставь её
   и подтверди Start r21. С картой в выключенном устройстве мод не запускай:
   ранний autorun ранее приводил к зависанию загрузки.
2. На тестовом проекте с Poly проверь L → Tune: выбрать три ноты, снять
   одну повторным нажатием, Apply. В Events должны остаться две отдельные
   строки в одной позиции; при воспроизведении обе высоты подсвечиваются.
3. Затем проверь набор на пустом шаге Steps с включённой Seq Record.
   В Sample отдельно проверь обычную запись двух одновременно нажатых нот.
4. Проверь Note Repeat+B2 и Mute во время воспроизведения. Для пробы
   ресемплинга сначала используй свободный целевой пэд, затем отдельный
   тест замены. При ошибке достаточно одной попытки.
5. Заверши через Project → Mod Off → подтверждение, дождись обычного
   интерфейса, выполни штатный Eject и верни SD в ПК для полного журнала.

При обновлении проекты и сэмплы на карте сохраняются и проверяются по SHA256.
