# Цвета секвенций: применение к физическим пэдам

Причина: r22 сохраняла выбор Shift+K1 и рисовала цветную метку на экране,
но её отправка на RGB-пэды не была подключена.

Кандидат с MPC_SEQUENCE_COLOURS добавляет палитру в существующий UI tick и
общий RGB sender. Цвет зависит от банка и номера секвенции. Сохраняются
штатная яркость и выключенные пэды. При Shift, Erase, удержании Pad Bank,
активном Mute и выходе из Seq возвращается штатная палитра. Другие модальные
окна, Steps и клавиатура сохраняют приоритет.

`check_sequence_rgb.c` выполняет production sender и проверяет обновление
без штатного RGB-события, смещение банка, выключенные пэды, Shift, Erase,
Mute и возврат из Seq. Тест пройден под ARM/QEMU.

В полной виртуальной машине для библиотеки
610a83bdc12cf03b69f2946905c495cd29f96758091ad683c56556304d615ff4
подтверждено: пэд текущей A01 изменился с [0,63,81] на [81,10,56] после
выбора Magenta через Shift+K1; затем изменялся на Green. Данные HTTP API
и снимки экрана сохранены в work/lab-tests/seq-colour-*.
Проверка другого банка в виртуальном проекте не завершена: штатная кнопка
Pad Bank оставляла активным A. Смещение банка отдельно проверено в тесте
sender, но полной аппаратной проверкой это не является.

После этой VM-пробы добавлены исключения Mute/Erase/Pad Bank, проверенные
в check_sequence_rgb. Полная VM-проба именно окончательной библиотеки ещё
предстоит. Нет нового пакета для физической SD, карта не изменялась.

Сборка лабораторного кандидата:
`python3 build_poly_candidate.py --sequence-only` в настроенной WSL Ubuntu.
Этот вариант не устанавливает экспериментальный hook записи аккордов.

## Итоговая библиотека r22b

VM-проба окончательной библиотеки

подтверждает изменение RGB при Shift+K1 без переключения экранов:
Magenta [81,10,56], Cyan [0,90,116], Green [20,83,53].
В этой библиотеке уже включены исключения Mute/Erase/Pad Bank.
Ответы панели сохранены в work/lab-tests/seq-colour-final.json.
Повторный тест production sender также прошёл. Аппаратная проверка всех
банков остаётся отдельной частью пробы на MPC.
