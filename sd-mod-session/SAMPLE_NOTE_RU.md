# Исходная нота: r12 и подтверждённая r11

Пользователь подтвердил работу Orig Note и названия ноты у Semi Tune в r11. В r12 исходная нота привязана к имени сэмпла внутри текущего проекта и записывается при сохранении XPJ вместе с параметрами Lights. Между сэмплами больше не должна сбрасываться. Новое сохранение ещё не подтверждено на MPC. Подробности и ограничения: [MUSIC_LIGHTS_RU.md](MUSIC_LIGHTS_RU.md).

Ниже оставлено описание **исторической r11**, у которой сохранения ещё не было.

## r11 — первая проба исходной ноты в Tune

Это сборка для проверки нового управления и отображения. Музыкальные режимы RGB, новая вкладка Lights, Project Key / Scale и Transpose 16 Levels в неё ещё не включены.

## Что попробовать

1. Полностью выключить MPC без карты, включить штатный интерфейс, вставить карту и подтвердить **Start r11 sample note trial**. Подготовка запуска остаётся прежней; наличие **Project → Mod Off** подтверждает мод.
2. Выбрать один сэмпл, открыть Sample → Tune.
3. Удерживая Shift, повернуть K1. Вместо Semi Tune должен появиться **Orig Note** со значениями `--`, C, C#, D, D#, E, F, F#, G, G#, A, A#, B. `--` означает неизвестную исходную ноту. Служебная метка S белая без Shift и красная при удержании.
4. Установить A и отпустить Shift. При Semi Tune 0 должно отображаться `+0 A`.
5. Изменить обычный Semi Tune до +3: ожидается `+3 C`; до −2: `−2 G`. Звук меняет обычный Semi Tune. Выбор Orig Note сам высоту не меняет.
6. Выбрать `--`: название ноты исчезает, числовое значение Semi Tune остаётся. Fine Tune работает штатно и показывает отклонение в центах.
7. Проверить, что ввод имени с пэдов по-прежнему работает. Для выхода выбрать Project → Mod Off, затем штатный Eject.

## Ограничения именно первой пробы

- Исходная нота хранится только в RAM для текущего выбора: при смене пэда или имени сэмпла она сбрасывается. Переключение вкладок само её не сбрасывает.
- Настройка Orig Note пока не записывается в проект или WAV и пропадает при Mod Off / выключении. Связь с устойчивым идентификатором сэмпла ещё не разобрана. Отдельная запись файлов настроек не добавлена.
- Нота у Semi Tune — результат ручного указания исходной ноты и целых полутонов. Ненулевой Fine Tune нужно учитывать по его отдельному показанию. Автоопределения высоты нет.
- Изменения сохранения SD, штатного питания и задержки запуска в эту сборку не входят. Короткая кнопка питания в моде остаётся известной нерешённой проблемой; штатный выход — Mod Off.
- Эта сборка пока не проверена на устройстве. Исходная прошивка не перепрошивается: патч применяется к копии приложения в RAM.

## Подготовка карты

Архив содержит каталог `autorun`. Перед заменой сохраняются предыдущий пакет и журналы. Музыку в `MPC-Sample` не удалять. После записи карты в Windows обязательно выбрать «Извлечь» и дождаться подтверждения.
