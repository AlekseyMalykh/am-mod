Свежий журнал r11 получен 24.10.2026: запуск, изменение Orig Note и возврат штатного приложения через Mod Off подтверждены.

Статус: собрана **r11-sample-original-note-ui** — первая проба Tune / Shift+K1 и названия ноты рядом с Semi Tune. Нота временная, сбрасывается при смене выбранного пэда/сэмпла; сохранение в проект не реализовано. Пользователь подтвердил 24.10.2026, что указание ноты и её отображение работают на MPC и удобны. Свежий журнал r11 ещё не получен. Новое меню Project, третья вкладка Lights, музыкальные RGB-режимы и Transpose 16 Levels пока в сборку не входят. Рабочая основа клавиатуры — r10a, подтверждённая пользователем; r10b добавила обратную связь подсветки.

## Подтверждённые пожелания

- Вход в общие настройки — **Shift + физический пэд16 → Project**, новый самостоятельный пункт **Key / Scale**. Это не сочетание с кнопкой16 Levels. Существующий Mod Off остаётся отдельным пунктом.
- Общие параметры проекта: **тоника + лад**.
- Sample, кнопка B2: **Tune → Play → Lights → Tune**. Lights — третья вкладка той же группы, а не замена Tune или Play.
- Исходная нота каждого сэмпла задаётся в существующей **Tune → Shift + K1**, со значением «пусто», если нота не известна. Это последнее уточнение пользователя: исходная нота переносится из Lights ближе к штатному питчу.
- Semi Tune сохраняет числовые полутона и дополнительно показывает вычисленное название текущей ноты, если исходная нота задана.
- В Lights для каждого сэмпла: **сдвиг раскладки 16 Levels, цвет тоники, цвет нот лада, цвет остальных нот**.
- Подсветка действует в **16 Levels → Tune**; пользователь также согласовал отдельное транспонирование этой раскладки. Исключение полутонов, квантование высоты и автоопределение ноты не запрошены.

## Предлагаемое управление тремя ручками

### Project → Key / Scale

| Ручка | Параметр |
|---|---|
| K1 | Tonic: C…B |
| K2 | Scale: выбранный лад |
| K3 | Свободна |

Список ладов и начальные значения ещё не согласованы. Для первого интерфейса нужны как минимум Major и Minor; остальные лады можно добавить в ту же модель интервалов.

### Sample → B2 → Tune

| Управление | Параметр |
|---|---|
| K1 | Штатный Semi Tune: числовой сдвиг и текущая нота, если она известна |
| Shift + K1 | Original note: пусто / C / C# / … / B |

Original note описывает исходное аудио до штатного Semi/Fine Tune. Выбор ноты не меняет звук. Пустое значение означает неизвестную ноту и сохраняет прежнее числовое отображение Semi Tune; предполагаемая C автоматически не подставляется. При известной исходной A и Semi Tune +3 отображение можно сделать `+3 · C`. При нулевом сдвиге — `0 · A`. K1 получает ту же метку доступного Shift, что другие параметры мода: белую без Shift, красную при удержании.

При ненулевом Fine Tune название означает нотную основу, а не обещание точного совпадения с темперацией: смещение в центах должно оставаться явно видимым в штатном Fine Tune. Отдельное транспонирование 16 Levels не входит в показание обычного Sample Semi Tune.

### Sample → B2 → Lights

| Ручка | Параметр |
|---|---|
| K1 | Transpose: сдвиг только раскладки 16 Levels в полутонах |
| K2 | Role: Tonic / Scale / Other |
| K3 | Colour: цвет выбранной роли |

Пользователь подтвердил область транспонирования: **только раскладка 16 Levels**. После переноса Original note в Tune предлагается занять освободившуюся K1 транспонированием и оставить K2/K3 для выбора роли и её цвета. Раскладка Lights является предложением, не уже реализованной функцией. Яркость и отдельный выключатель пока не назначены.

Названия и значения сохраняют действующий дизайн мода: чёрный фон, центрирование, янтарное выделение выбранного параметра. При наличии Shift-функции используется существующая локальная метка S.

## Уточнение: привязка подсветки и транспонирование

Пользователь хочет как совместить цветовые роли с реальными нотами, так и перемещать звучащую раскладку с корректным обновлением цветов. Это две разные операции.

### Original note — указание известной исходной ноты

- Это описание исходного аудио до Sample Pitch/Tune, а не изменение высоты звука.
- Например, пользователь указывает A, а Sample Tune уже равен +3 полутонам: текущая опорная нота — C. Подсветка сразу учитывает это сочетание.
- Последующие изменения Sample Pitch автоматически меняют расчёт нот и цвета; Original note остаётся A. Повторно вручную сдвигать цвета после каждого изменения Pitch не нужно.
- Для ручного подбора пользователь может слушать опорный пэд и менять Original note до совпадения с известной реальной нотой. Отдельный произвольный сдвиг RGB не вводится: он скрыл бы неверное соответствие цвета и звука.
- В Tune текущая нота показывается рядом с числовым Semi Tune; в Lights может дублироваться справочная строка вида `A +3 = C`, отдельно от тоники проекта. Для точной подстройки с центами нужна отдельная индикация отклонения; нельзя изображать дробную высоту как точно настроенную ноту.

### Transpose — изменение реально звучащих нот

- Меняет реальную высоту/раскладку, после чего цвета пересчитываются из полученных нот. Одной перестановки RGB недостаточно.
- Тоника проекта при этом остаётся выбранной пользователем. Поэтому цвет тоники следует за реальной нотой тоники на пэдах. Одинаковый цвет не обязан оставаться на том же физическом пэде после транспонирования.
- Пользователь подтвердил: Transpose действует **только на раскладку 16 Levels / Tune**, обычное воспроизведение сэмпла не меняется.
- Нужен отдельный явно видимый сдвиг этой раскладки. Обычный пэд сохраняет свой Pitch; штатный Tune всё равно участвует в расчёте слышимой ноты.
- Сдвиг индивидуален для выбранного сэмпла, как его Original note и палитра. Он не должен менять проектную тонику или штатные режимы Velocity/Filter.
- Числовой диапазон необходимо выбрать после разбора допустимого диапазона native питча, без переполнения и обхода штатных ограничений. Сброс к 0 возвращает исходную раскладку.
- Реализация и новый пакет ещё не созданы; на карту ничего не записывалось.

Расчёт класса ноты для полутоновой раскладки: `Original note + Sample Tune + смещение пэда от native originalPad + Transpose16`, затем modulo 12. `Transpose16` используется только если согласован отдельный сдвиг 16 Levels; общий Sample Tune нельзя прибавлять дважды.

## Как вычислять цвет

1. Определить исходную ноту сэмпла и действующее смещение его высоты. Root не должен автоматически считаться C и не должен сам менять звук.
2. Получить реальный опорный пэд16 Levels и смещение каждого физического пэда относительно него. В штатной раскладке опорный пэд первоначально Pad4, но поле опорного пэда нужно читать из native состояния.
3. Привести полученную ноту к классу высоты0…11 и сравнить с тоникой проекта и набором интервалов лада.
4. Совпадение с тоникой имеет приоритет над обычным попаданием в лад. Прочие ноты получают цвет Other.
5. Если исходная нота не установлена, не изображать произвольную тональность как известную: сохранить штатную подсветку до ручного указания Root.

Индивидуальные цвета принадлежат настройкам сэмпла; настройка тоники и лада относится к проекту. Нужно учесть текущий Tune, замену/переименование сэмпла, переключение банков и одинаковые файлы в разных назначениях. Достоверность настройки Root зависит от ручного ввода пользователя; анализа аудио на этом этапе нет.

## Приоритеты RGB

Подтверждены четыре режима Lights:

| Режим | Подсветка |
|---|---|
| Monochrome | Текущее штатное одноцветное поведение 16 Levels |
| Piano | Две группы по реальным нотам: C/D/E/F/G/A/B и C#/D#/F#/G#/A# |
| Tonic | Тоника проекта выделена, остальные ноты — фоновая группа |
| Scale | Три группы: тоника / остальные ноты лада / ноты вне лада |

Пользователь подтвердил три группы в Scale; индивидуальные цвета для каждой ступени не нужны. Piano не зависит от выбранного лада; Tonic и Scale используют тонику проекта, Scale также выбранный лад. Root и Sample Tune учитываются во всех музыкальных режимах. Режим выбирается индивидуально для сэмпла. Раскладку ручек Lights нужно адаптировать к добавленному Mode; это ещё не реализовано в r11 UI trial.

- В открытом окне имени с Pads активна телефонная клавиатура и её цвета/вспышки.
- Музыкальные цвета включаются только в подходящем контексте16 Levels / Tune и при известном Root.
- Velocity и Filter сохраняют действующее поведение.
- Служебные режимы Mute, Step Edit, выбор банков и их штатная обратная связь должны сохранять приоритеты native цепочки подсветки.
- Выход из16 Levels, смена назначения и Mod Off должны восстанавливать подходящую штатную раскладку. Действующую обработку нажатий и отпусканий музыкальных пэдов для смены цвета перехватывать не требуется.

## Найденные точки интеграции в1.3.0.12

- Общий финальный отправитель цвета **0x23b0ec0**, преобразование PadLight **0x23b00c0**. Этот путь уже используется рабочей клавиатурой r10a. Для музыки предпочтительнее переопределять именно native слой16 Levels, чтобы другие режимы сохраняли приоритет.
- **SixteenLevelLighting::RefreshPad0x1545930**: this+0xe8 → properties; enabled bit по properties+0x2f8, type по properties+0x88. Type1 — Tune по сопоставлению с DSP. Native метод передаёт PadLight через0x1a3ffb0 с light object по this+0x38.
- **DSP16 Levels0x21472f0**: ветка Tune использует localPad и originalPad по properties+0x228. Цвет должен следовать этому же смещению. DSP и параметры голоса для одной подсветки менять не требуется.
- SampleModeScreen vptr **0x6e212a0**, конструктор возле **0x16735c0**. Native группа B2 содержит заголовки Tune/Play; массив заголовков устанавливается в **0x1674f8c…0x1674fc4**, group component — SampleModeScreen+0x7f0, связанная вспомогательная часть — +0x988.
- Одного добавления строки Lights в массив заголовков недостаточно: нужно отдельно разобрать переключатель страниц и привязки ручек, чтобы индекс третьей вкладки не попал в native обработчики с диапазоном0…1.
- Project: существующий мод добавляет Mod Off через src/project.S. Native выбранная строка читается по0x16438c0; новая строка Key / Scale потребует расширения модели меню и отдельного обработчика с сохранением Mod Off.

## Порядок внедрения

1. Модель тональности/лада и трёх ролей цвета, вычисление класса ноты с тем же опорным пэдом, что использует DSP.
2. Отдельная страница Key / Scale из Project; корректное возвращение в Project и сохранение Mod Off.
3. Original note на Tune / Shift+K1, вычисленная нота рядом с Semi Tune; затем третья вкладка Lights в B2 с Transpose и палитрой выбранного сэмпла.
4. Включение цвета через native слой16 Levels, с сохранением приоритета клавиатуры и других режимов.
5. Сохранение общих и индивидуальных настроек при сохранении проекта, восстановление при загрузке. Сначала установить стабильные идентификаторы проекта/сэмпла и формат дополнительных данных. Нельзя объявлять это реализованным, используя только RAM-указатель или одно имя файла.

Сохранение настроек должно учитывать совместимость со штатным приложением. Формат дополнительных данных ещё не выбран; произвольные новые поля в XPJ без разбора штатного сериализатора не добавляются. Если понадобятся отдельные файлы настроек, они должны оставаться в уже разрешённой области сохранения SD и сопровождать Save As/копирование проекта.
