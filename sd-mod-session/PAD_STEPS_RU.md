# r13g — контекстные Chop / Levels в Events и Steps

После пробы r13f1: исправлена доступность редакторов непомеченных событий и добавлено открытие из Steps. Новая r13g требует аппаратной проверки.

- Доступность совпадает с отметками строки: C → Chop, L → 16 Levels, CL → обе кнопки. У непомеченной ноты обе выключены. Срезы у исходного сэмпла сами по себе не делают событие чопом.
- В Steps выбрать шаг и нужный Sound. Одно подходящее событие открывается сразу; несколько открывают список только событий выбранного звука и типа на этом шаге.
- В списке показаны позиция, тип/значение и velocity; M означает muted. Энкодер, +/− или K2 выбирают строку; B3/клик энкодера открывает редактор. B1/B2 отменяет. При более64 подходящих событиях нужно выбрать конкретную строку в Events; молчаливого обрезания нет.
- В редакторе пэды выбирают вариант, B3 Apply изменяет только выбранное событие одной штатной командой Undo, B1/B2 отменяет. Возврат в исходный вид Steps/Events; в Steps сохраняются Sound и выбранный шаг. Удалённый/изменившийся источник не подменяется другой строкой.
- Недоступные Chop/Levels не переключают штатный performance-режим из Step Edit. Shift-сочетания сохраняются. Чистый Velocity остаётся без L, поскольку исходный режим ввода не записан; обычная velocity по-прежнему редактируется K3.

Сохранённые возможности r13f1:

- В обычном Sample событие подсвечивает исходный пэд видимого банка: обычная нота, Chop или 16 Levels.
- Внутри активного Chop / 16 Levels подсвечивается соответствующий срез или значение выбранного звука. Это предусмотрено при повторном входе и каждом круге секвенции; временный выбор события в Events использует ту же логику. Muted-события пропускаются.
- Исправлена кнопка Chop: штатная CC4b. Прежняя CC24 оказалась Sample Save и больше не перехватывается для чопа. Добавлен отдельный штатный refresh Chop.
- Убрана зависимость Sample от первого открытия Step Edit и сохранённого скрытого Steps. Для Levels используется закреплённый инструмент режима.
- Компактные отметки C, L, CL без пустой позиции перед L. Они отражают сохранённые параметры события; чистый Velocity не хранит признак исходного режима ввода.
- Steps на чёрном фоне: звук/имя сэмпла; страница/число шагов и две позиции EDIT/PLAY; шаг/Follow и режим WRITE/MUTE/ERASE. Блоки разделены тонкими линиями. Внизу Sound / Grid / Velocity и одна меняющаяся подсказка. Штатная полоса прогресса сохранена.

## Steps

Вход: Shift+SEQ → B2 Steps. B2 возвращает Events. Shift+пэд сохраняет штатные меню, включая Project. Note Repeat и Pad Bank не сбрасывают выбранный вид; после штатного окна Steps восстанавливается.

- SEQ RECORD включает/выключает локальный WRITE. При входе WRITE OFF. Это разрешение программировать шаги, а не живая запись транспорта.
- WRITE OFF: пэд только выбирает шаг. WRITE ON: пустой шаг получает ноту, занятый только выбирается. Работает при Stop и при Play. LED SEQ REC показывает WRITE.
- Erase+пэд удаляет все музыкальные события выбранного звука в этом шаге. Другие звуки и соседние шаги остаются. Группа передаётся одной штатной команде Undo. Ноты со смещением относятся к тому же округлённому слоту, который виден на пэдах. Пустой шаг не меняется.
- Время идёт 13–14–15–16 → 9–10–11–12 → 5–6–7–8 → 1–2–3–4.
- Зелёный — события, янтарный — выбранный шаг, ярко-голубой — воспроизведение. При удержании Erase события красные. Несколько нот тоже зелёные.
- B1 удерживать + пэд — бесшумный выбор звука текущего просматриваемого банка. Pad Bank / Shift+Pad Bank и Shift+K1 листают банк, сохраняя выбранный звук. Только B1+пэд или K1 выбирают другой звук. При удержании B1 заголовок показывает просматриваемый банк.
- K1 Sound, K2 Grid, K3 Velocity. Shift+K2 — триоли; пять делений от 1/4 до 1/64. K3 — непрерывная шкала. Grid не квантует записанные ноты.
- Энкодер только выбирает шаги. Shift+энкодер — навигация по тактам. +/− — страницы, Shift+/− — штатные Undo/Redo. Shift+B2 — Follow/Hold.
- B3 Edit: Copy / Paste / Paste to Pad / Note Length. Длительность меняется K3. B1 Back закрывает меню.

LCD показывает страницу/число шагов, звук и имя сэмпла либо Empty, позиции Edit/Play и WRITE. Сетка шагов на LCD не дублируется. Верхняя штатная полоса секвенции сохранена.

## Обычный Step Edit / Events

- Erase без пэда удаляет выбранную строку при отпускании кнопки. Нажатие до отпускания ничего не удаляет: остаётся время для сочетания Erase+пэд. Если выбор/окно изменилось, удаление строки отменяется.
- Erase+пэд передаётся штатному механизму удаления событий данного звука по всей секвенции, с подтверждением. Его ответы рисует штатное окно; внутренние Answer1 / Answer2 больше не перекрывают подписи.
- B3 в основном Events освобождена от удаления и пока без новой команды. Shift+B3 сохраняет Copy/Paste.
- Энкодер циклически листает Q всей секвенции. Shift+энкодер перемещает выбранную ноту по Q с сохранением её остальных данных и микросмещения. Нота и просмотр переходят по кругу. +/− выбирают строки списка.
- Shift+K3 выбирает один из 16 вариантов параметра выбранного события напрямую. Для точного выбора с подтверждением использовать подсвеченную кнопку режима.

## Временный выбор события на пэдах

У выбранной строки подсвечивается 16 Levels либо Chop. Кнопка открывает отдельное временное окно выбора с раскладкой физических пэдов. Контекст Step Edit остаётся активным, поэтому SEQ сохраняет штатную красную индикацию.

Пэды выбирают значение; B3 Apply применяет его к первоначальной строке и возвращает в Events. B1 Cancel или B2 отменяют выбор. До Apply проект не меняется. K1–K3 относятся к типу/выбору/диапазону этого окна; исходный сэмпл ими не редактируется. Для Tune +/− листают диапазон по октавам, для Slice — по 16 срезов. Энкодер выбирает вариант текущей страницы. Границы срезов и настройки сэмпла здесь не редактируются.

16 Levels не ограничен Tune: используется штатный преобразователь режимов Velocity, Tune, Filter, Layer, Attack, Decay, Probability, Ratchet, Slice и Articulation. Он работает с копией события. Активный записанный модификатор и последние изменённые данные помогают выбрать режим. Отдельного признака «эта нота была записана через 16 Levels» в событии нет: для неоднозначной обычной ноты используется Velocity; для неотличимых значений Probability/Ratchet/Articulation учитывается текущий режим 16 Levels.

Chop/Slice — записанный модификатор среза, не articulation. Если звук уже разрезан на отдельные сэмплы разных пэдов, такая строка является обычной нотой своего пэда, а не событием Slice.

В r13f1 предусмотрена подсветка исходных пэдов в Sample, а во временном выборе и активных 16 Levels/Chop — значений: подходящие события выбранного звука кратко загораются голубым, затем возвращаются прежние цвета. Одновременные события могут подсветить несколько пэдов. Это визуализация событий по штатным часам с обновлением UI раз в 50 мс; не измерение фактического аудиовыхода. Очень быстрые повторения могут визуально сливаться. При выборе другой страницы вне диапазона соответствующий пэд не подсвечивается.

## Lights

Без Shift: Mode / Tonic / Scale. С Shift: Transpose16 / Role / Colour. Унаследованные значения показаны как C (P), Major (P) и т.п.; (P) означает настройку проекта. Локальные значения показываются без (P).

## Проверка на MPC

1. В Windows выбрать «Извлечь», вставить SD в MPC, подтвердить Start r13g. Проверить Project → Mod Off. Использовать копию проекта.
2. Steps: при WRITE OFF пэды не добавляют ноты; SEQ REC включает WRITE и его LED. Проверить добавление при Stop и Play. При обычном Play без SEQ REC должны появиться Play и голубой курсор.
3. Erase+шаг с несколькими нотами удаляет только группу выбранного звука; Undo возвращает группу. Проверить соседние шаги/другой звук.
4. Events: короткий Erase удаляет строку, Undo возвращает; Erase+пэд открывает штатное подтверждение с правильными подписями. Проверить отмену.
5. Выбрать Tune, Slice, Velocity и другие доступные события: подсветка кнопки, вход, выбор на пэдах, Cancel, Apply, Undo и Shift+K3. Проверить SEQ и отсутствие изменений исходного сэмпла.
6. Проверить голубые вспышки при Play во временном выборе и обычных 16 Levels/Chop, разные банки и возврат цветов после Stop. Проверить клавиатуру именования.
7. Lights: унаследованная тоника/гамма с (P), локальная без (P). В конце Project → Mod Off, штатный Eject, карта в ПК. Карту не вынимать при работающем моде.

Реальный звук, графика устройства, Undo replay, аппаратные LED/отпускания кнопок и сохранение/повторное открытие требуют пробы на MPC. Компьютерный стенд исполняет закреплённые ARM getter/фабрики/контейнеры/преобразователь 16 Levels и патчер; исполнитель команд и GUI заменены стендом.
