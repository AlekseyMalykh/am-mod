# r18 — графический EQ и цепочка штатных FX для ресемплинга

Ресемплинг: режим Sample → Shift + пэд11 → B3 Sample → B2 FX.
До пяти эффектов, включая несколько экземпляров одного эффекта. Изменение
черновика не меняет обработку исходного пэда. Обработка записывается в новый
аудиорезультат только при Render; назначение на пэд — отдельный Apply.

## Цепочка

- K1 выбирает слот. B3 Add открывает список эффектов: K1/энкодер — выбор,
  B2 — следующая категория, B3/клик энкодера — добавить.
- В занятом слоте B3 Edit открывает параметры. B2 включает/выключает Bypass.
- Shift+B2/B3 перемещают выбранный эффект вверх/вниз вместе с настройками.
- Erase удаляет выбранный эффект после подтверждения B3; B1 отменяет.
- Shift+клик энкодера открывает замену эффекта в выбранном слоте.
- В редакторе штатного эффекта K1/K2/K3 меняют три показанных параметра.
  Энкодер переключает страницы остальных параметров. B1 — назад,
  B2 Change — другой эффект, B3 Bypass/Enable — обход.
- Значения штатных параметров в этой пробе показаны нормированными процентами.
  Это рабочие параметры процессора; форматирование собственных единиц Akai
  ещё предстоит подключить к этому окну.

Включены 25 штатных процессоров: Delay, Diff Delay, Tape Delay, Sample Delay,
Reverb, Spring Reverb, HP/LP/BP Filter, Bus Compressor, Limiter, Pumper,
Transient, Noise Gate, Amp Sim, Tube Drive, Soft Clipper, Ensemble,
Multi Chorus, Phaser, Flanger, Auto Wah, Auto Pan, Vinyl и Tape.
Reverb представлен одним процессором со всеми18 параметрами.

Vintage пока исключён: его штатная обёртка меняет общий банк обработчиков.
Для ACVX-процессоров частота исходника должна совпадать с частотой движка:
их таблицы общие для устройства. При несовпадении Render отказывает,
не меняя общие таблицы или исходный звук. AIR EQ/Delay/Reverb/Drive и наш
графический EQ подготавливаются с собственной частотой.

## Графический EQ

Выбрать Graphic EQ в списке эффектов. На чёрном фоне — частотная сетка,
общая кривая и нумерованные точки. Частота расположена логарифмически.

- Энкодер выбирает точку; K1 — частота, K2 — усиление, K3 — Q.
- B2 Points открывает список точек. В нём B2 Add point добавляет,
  B3 Delete удаляет выбранную точку. До восьми точек; B1/клик — график.
- Shift+K1 — тип точки: Bell, Low Shelf, High Shelf, HP12dB, LP12dB.
- Shift+K2 — включение точки; Shift+K3 — общий выходной уровень EQ.
- На графике B3 Bypass/Enable — общий обход. В обходе пунктиром остаётся
  настроенная кривая, голубой линией показан фактический ровный отклик.
- Кривая рассчитана по тем же коэффициентам, что обрабатывают звук.
  Это **кривая EQ**, а не измеренный спектр входа/выхода.

## Первая проверка

1. Безопасно извлечь SD в Windows. MPC полностью загрузить без карты,
   затем вставить карту и подтвердить **Start r18**.
2. Выбрать короткий сэмпл, открыть Resample → Sample → FX.
3. Добавить Graphic EQ, изменить усиление точки, добавить/удалить точку.
4. Добавить Tube Drive и Reverb. Для хвоста реверберации на странице
   Resample Sample поставить K2 Tail, например2 секунды.
5. Render → K1 To Pad → выбрать свободный пэд → Apply. Сравнить исходный
   и полученный звук, проверить Undo/Redo. Затем сохранить результат
   обычным сохранением сэмпла/проекта.
6. Для выхода из окна — Cancel; после завершения — Project → нижний
   Mod Off → подтверждение B3 → штатный Eject.

Play, Stop и Main Volume продолжают обслуживаться штатным приложением.
Исходник этой пробы — PCM выбранного диапазона Trim; обычные Tune/огибающая/
фильтр источника ещё не запекаются автоматически. Живое сравнение черновика
в миксе, отдельная вкладка Sample→Filter→EQ, EQ в обычном FX Select и
измеренный спектроанализатор остаются следующими задачами.

На компьютере проверены реальные штатные фабрики, параметры и обработка
аудио, включая цепочку EQ/TubeDrive/Delay/Reverb/Limiter и изменение результата
после перестановки. Нагрузка, звук, Undo и Save/reopen этой версии на MPC
ещё требуют аппаратной проверки. Установленная прошивка не перезаписывается.
