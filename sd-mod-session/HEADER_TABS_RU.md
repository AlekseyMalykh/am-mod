# r12b — общие верхние кнопки и компактные вкладки

r12/r12a заменяли рисунок только у активной группы Tune в Sample. На Trim/Filter оставался штатный индикатор Tune из двух страниц. В r12b отдельная перерисовка Tune убрана; общий штатный класс верхней кнопки получает единый рисунок после дочерних элементов.

## Оформление

- Чёрный фон; название по центру, единая высота шрифта.
- Выбранная вкладка: янтарные название и текущий сегмент. Остальные группы: белое название и серые сегменты.
- Сегмент5px, промежуток2px. Текущий сегмент высотой3px, остальные1px; позиции не меняются при выборе.
- Название и индикаторы занимают максимум29px внутри прежней области кнопки, без сдвига остального экрана.
- Tune/Play/Lights всегда имеют3 сегмента, в том числе на Trim/Filter. У остальных групп количество берётся из штатной модели.
- Обычные верхние команды получают тот же фон и расположение названия, сохраняя штатный цвет текста действия (например красный Cancel). У переключателя выделено включённое состояние; шкалы вкладок у одиночной команды нет.

Общий рисунок применяется к этому компоненту в26 уже разобранных типах окон: Sample, Sequence, Project, запись/сохранение сэмпла, FX, настройки, Song, Step Edit и другие типы из ui-audit.json. Он ограничен верхней полосой45px; кнопки других размеров/типов или вне неё в правку не входят. Реальное покрытие каждого окна ещё нужно подтвердить на устройстве.

Области нажатия, команды и сочетания Shift прежние. Третья виртуальная страница добавлена только в Sample B2. Сегменты параметров внизу не заменяются этой правкой.

## Короткая проба

1. Подтвердить **Start r12b compact headers trial**.
2. В Sample открыть Trim, Tune/Play/Lights и Filter. У средней группы во всех случаях3 сегмента, без смены стиля. У выбранной страницы — один янтарный сегмент.
3. Открыть Sequence, FX, запись и настройки: проверить общий вид, названия и количество страниц. В окне подтверждения проверить цвет/читаемость Cancel. Проверить Shift и возврат обычных команд.
4. Проверить нижние параметры, клики энкодера в Lights и RGB из r12a. Работа новых исправлений без аппаратной пробы не подтверждена.
5. Выход: Project → Mod Off, затем штатный Eject. Фото окна с отличающимся видом поможет уточнить его тип и размеры.

## Техническая граница

Pinned vptr `0x706e940`, slot paintOverChildren `+0xd8` исходно содержит no-op `0x10e2e10`. Подменяется только слот данного класса в RAM клона. Общая функция no-op и код JUCE Button не перехватываются. Ancestor guard сформирован из аудита26 окон. Режимы0/1/2 — команда/переключатель/группа страниц. Заголовок — JUCEString Button+0xb8; число/индекс страниц — +0x214/+0x218. Native page count не меняется; третья страница учитывается только при рисовании Sample B2.

В RAM-журнале HEADER_TABS отмечается первый рисунок каждой колонки каждого окна, максимум78 записей, без имён проектов или сэмплов.

## r13d: подписи подтверждений

QuestionScreen исключён из общей перерисовки верхних кнопок: его штатная привязка меняет подписи ответов отдельно, а Button+b8 может содержать внутренние Answer1 / Answer2. Native paint остаётся видимым; команды/подтверждение не меняются. Компьютерный GUI-стенд проверяет отсутствие наложения и сохранение отрисовки вкладок Sample.
