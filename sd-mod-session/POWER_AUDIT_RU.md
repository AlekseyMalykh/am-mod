# r21b — проверка возможностей зарядки

Согласованы два будущих режима: Standard (штатная зарядка) и Low Battery
(разрешать зарядку USB только при низком заряде). Управление зарядкой ещё
не реализовано: сначала требуется установить реальный интерфейс контроллера.

Эта сборка сохраняет мод r21a и добавляет однократный отчёт только для чтения.
Она не меняет зарядку, USB-аудио, GPIO, I2C, прошивку или настройки аккумулятора.
Рабочего переключателя режимов в Input Config пока нет.

1. Безопасно извлеки карту в Windows, загрузи MPC без карты, затем вставь её.
2. Подключи USB к обычному источнику, от которого MPC штатно заряжается.
   Аккумулятор специально разряжать не требуется.
3. Подтверди Start r21b. Перед запуском мода будет выполнен сбор отчёта;
   ограничение ожидания — 20 секунд. Обычно чтение занимает гораздо меньше.
4. Когда мод загрузится, выбери Mod Off и дождись штатного интерфейса.
5. Выполни штатный Eject, верни карту в ПК и сообщи об этом.

В корне карты появится MPC_POWER_AUDIT.txt. Он содержит доступные свойства
power_supply, имена драйверов и роли USB. Наличие файла с правами записи
само по себе не доказывает, что драйвер разрешает менять зарядку.
Текущая политика зарядки во время проверки остаётся штатной.
