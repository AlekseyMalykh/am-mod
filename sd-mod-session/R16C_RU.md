# r16c — прослушивание события через обычный Sample input

r16b аппаратно подтвердила выбор L/C, Cancel и Apply без звука. В r16c прослушивание направлено через штатный вход игры Sample / 16 Levels (1e27360) и соответствующий отпусканию вход (1e270d0), а не через общий EventAudition полного MPC.

## Поведение

- Исходный вариант отмечен янтарным; последний выбранный — голубым. Совпадение чередует оба цвета. При входе автоматического прослушивания нет.
- При открытом редакторе исходное выбранное событие временно пропускается при воспроизведении секвенции; остальные события продолжают играть. Это фильтр воспроизведения, без удаления или сохранённого Mute.
- Пэд выбирает и прослушивает вариант, включая исходный. Это работает при Play и Stop. Отпускание использует штатный путь 16 Levels. Подтверждение B3 Apply записывает только выбранное событие; B1/B2 отменяет выбор. После выхода временный фильтр снимается.
- Полная копия выбранного события сохраняет одновременно Tune, Slice и остальные модификаторы; исходный сэмпл и настройки обычного режима 16 Levels не меняются. Рабочий перехват действует только внутри нашего вызова и для точного локального объекта настроек.
- Прослушивание не включает запись. Если штатная запись уже активна, оно блокируется; локальный Write в Steps — отдельный режим.
- Глобальные Play/Stop и Main Volume идут штатным путём. Кнопки C/L в Steps и Events сохранены.

## Проверка

Безопасно извлечь SD в Windows, вставить в уже полностью загруженный MPC и подтвердить **Start r16c**. На тестовом проекте:

1. Events → L → 16 Levels: в Stop нажать несколько пэдов, включая исходный. Проверить звук и цвета, Cancel, затем выбор и Apply.
2. Повторить при Play: исходное событие на круге молчит, другие играют; по пэдам слышен выбранный вариант. После Cancel исходная нота снова играет, после Apply — новая.
3. Повторить для C/Chop и из Steps. Проверить отпускание, быстрые нажатия, Play/Stop, выход во время прослушивания.
4. Если зависло, не повторять: дать восстановлению около минуты и вернуть карту для журнала. Для нормального выхода Mod Off → B3 → штатный Eject.

Проверки ARM/QEMU исполняют настоящие очередь, создание MIDI-сообщений, Sample input, перехват 16 Levels и отпускание. MIDI-служба и конечный получатель движка в стенде заменены адаптерами: реальный звук и отсутствие зависаний на MPC требуют этой пробы. Диагностика PAD/AUDIO_WAIT и восстановление после затянувшегося обработчика сохранены. Сэмплы и проекты не очищаются; встроенная прошивка не записывается.
