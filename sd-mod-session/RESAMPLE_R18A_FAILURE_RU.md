# Разбор аппаратной ошибки r18a — 27.10.2026

Это рабочие изменения исходников после r18a, не выпущенная сборка и не
подтверждённое исправление проигрывания. Карта не перезаписывалась.

## Два разных отказа

Журнал пробы сохранён в `backups/20261027-r18a-failure-314c97c1`.

1. Со штатными FX: `FX_CAPTURE_REJECTED stage=manager present=0`, затем
   `NATIVE_FX_CONTEXT ready=0`. Старое сообщение `Cannot prepare render/FX`
   не означало отказ доступа к папке. Изменять разрешения файловой системы
   по этому сообщению оснований нет.
2. Без FX: назначение результата завершилось, после попытки проигрывания
   приложение упало с `11/SEGV`. Зафиксированный пик памяти596.1MiB ниже
   лимита800MiB; журнал не сообщает OOM. Точный адрес сбоя пока неизвестен.

## Исправленный доступ к штатным FX

Поиск конкретных PluginManager/MpcPlayHead в UI service registry был неверным:
локальная проверка сама добавляла эти записи и тем самым скрывала аппаратный
отказ. Теперь источник — проверенная цепочка владельцев приложения:

| Источник | Поле | Проверяемый тип / значение |
|---|---|---|
| JUCE global71e3dc8 | application | AC50Application vptr6e07288 |
| application | f8 | ровно тот UI registry, который захватил мод |
| application | d8 | AudioIO vptr6e0c430 |
| AudioIO |148 | core vptr6e0cf38 |
| core |4d0 | PluginManager vptr6da1f90 |
| core |490 | MpcPlayHead vptr6d8a418 |

Основание: feec30/feec60 записывают/очищают JUCE instance;
14379b0 создаёт AudioIO и UI registry;14ea860 сохраняет core;
14ee2b0 сохраняет playhead и PluginManager. `check_fx_owner_map.py`
проверяет22 инструкции из неизменённого ELF1.3.0.12 и слот реального getter
13ad070. Никакого поиска объектов по куче или подстановки темпа120BPM нет.

Обновлённая проверка запускает захват при пустом реестре и отклоняет чужой
реестр, отсутствующего владельца, неверные типы, состояние разрушения и
неверный темп. Все25 настоящих AIR/MPC DSP и цепочка до5 FX прошли QEMU и
UBSan. Владельцы в этом тесте — ограниченные фикстуры; аппаратный результат
нового пути ещё не получен.

Ошибка подготовки FX теперь отличима от нехватки памяти: при отсутствующем
адаптере `Native FX unavailable`, при отказе создания процессора
`Cannot initialize FX`. Отказ сохраняет исходный reader до Cancel и не
назначает результат на пэд.

## Диагностика падения нового сэмпла

Приложение создало в RAM файл
`Settings/Akai/MPC Sample/MPC Sample.crashinfo`, но прежний recovery сохранял
только его имя, затем размонтировал временную память. Содержимое старой
пробы поэтому не восстановлено из имеющихся текстовых журналов.

В шаблоне autorun добавлено чтение двух известных путей crashinfo после
остановки clone и проверки MainPID=0, до размонтирования RAM. Результат
включается в основной отчёт. Максимум64KiB на файл; ссылки, ссылки в
родительских путях и специальные файлы пропускаются. Нового обработчика
сигналов, coredump, наблюдателя и записи во внутреннюю прошивку не добавлено.
`check_native_crash_snapshot.py` проверяет обычный и альтернативный путь,
отсутствие файла, ограничение размера, ссылки и FIFO в отдельных временных
каталогах. Проверены порядок recovery и включение файла в отчёт.

Дополнительно выполнена настоящая функция получения буфера sampler21fdd40.
В локальном тесте она получает35 кадров результата PCM/EQ и удерживает их
после уничтожения producer, Sample и provider. Тест обычного native reader
также проходит; обе проверки прошли UBSan. Это не полная инициализация
аппаратного голоса, не воспроизведение на устройстве и не доказательство
исправления SEGV. Назначение на настоящую модель, загрузка голоса и обновление
интерфейса остаются областями дальнейшего разбора.

## Что ещё требуется

Локально причина SEGV не воспроизведена. Нельзя объявлять Apply/проигрывание,
Undo/Redo и Save/reopen результата исправленными. Если дальнейший локальный
разбор не выявит причину, потребуется отдельная диагностическая проба с
сохранением crashinfo; её следует явно обозначить как диагностику, а не
готовое исправление. В этой работе новый пакет на SD не устанавливался.

Live Original/FX/Rendered в миксе, отдельная Filter→EQ, EQ в FX Select и
визуализация самого аудиосигнала ещё не завершены.
