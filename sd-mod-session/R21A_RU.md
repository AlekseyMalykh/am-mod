# r21a — Stereo → Mono и янтарные панели

Пробная сборка для MPC Sample 1.3.0.12. Работает с SD без записи внутренней
прошивки. Сохраняет функции r21, включая выбор нескольких нот в Tune.

## Note Repeat и Knob FX

Верхняя панель Note Repeat янтарная, подписи делений чёрные. Выбранное
деление отмечено нижней чертой. Белые боковые линии перекрываются на всей
высоте верхних кнопок. Нижняя панель K1–K3 больше не закрашивается.
Knob FX использует тот же насыщенный янтарный цвет, включая фон K1–K3.

## Stereo → Mono

1. Выбери исходный стерео-сэмпл в Sample и нажми Shift+B3.
2. Нажми целевой пэд. K1 или Bank переключает банк.
3. B1 — Cancel, B2 — Left, B3 — Right. Выбранный канал становится
   самостоятельным моно-сэмплом. Это извлечение канала, без суммирования L+R.
4. Если цель занята, повторное нажатие Left/Right подтверждает замену.
   Можно выбрать тот же пэд. До подтверждения цель не меняется.
5. Дождись Mono sample ready и нажми B1 Close. Сохрани проект обычным способом.

Преобразуется полный исходный сэмпл; его длина и частота сохраняются.
Копируются настройки инструмента, диапазон Trim/Loop восстанавливается
после назначения моно-сэмпла. Эффекты не запекаются: для этого есть Resample.
Операция входит в одну команду Undo. При ошибке выполняется откат.
Во время преобразования дождись результата; транспортные Play/Stop доступны.

## Проверки

На ARM выполнен настоящий штатный MonoConvertingStream: Left и Right
проверены по каждому отсчёту, выход имеет один канал, исходное число кадров,
частоту и конечный EOF. Отдельно выполнены настоящие CopyPad и контейнер
Undo/Redo с проверкой замены исходного пэда и отката ошибок. В этом стенде
создание Sample, Assign и SamplePool представлены проверяемыми получателями.
Проверены маршруты выбора цели/подтверждения/отмены, отрисовка Repeat,
а также прежние проверки ввода, поиска, Steps, EQ и полного запуска библиотеки.
Это локальная проверка; аппаратная проба Stereo → Mono ещё не выполнена.

Для первой пробы используй отдельный тестовый проект и свободный пэд.
После пробы проверь Undo, сохранение и повторную загрузку результата.
Заверши через Mod Off, дождись штатного интерфейса, затем выполни Eject.

Карту перед переносом из Windows безопасно извлеки. Загружай MPC без карты,
вставляй её после появления обычного интерфейса и подтверждай Start r21a.
