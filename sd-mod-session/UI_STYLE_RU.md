# Am MOD: единый стиль окон (экран 320×240)

Эталон — экран **MIDI In / MIDI Input** (`midi_ui.c`: `heads()`, `knob()`). Всё, что мод рисует сам, подгоняется под него. Дата фиксации: 2026-11-21, сборка 292f25c2.

## Система координат
- Экран 320×240, начало слева сверху. Сверху поверх экрана штатно рисуется полоса прогресса/статуса (на скриншотах она сдвигает картинку примерно на 38 px экранного масштаба, в координатах отрисовки это 0).
- Фон окон мода: чёрный `0xff000000`, заливается `rect(g,0,0,320,240)` (или `0,5,320,235`, если нужно оставить верхнюю строку статуса).
- Три колонки кнопок B1/B2/B3 и три энкодера K1/K2/K3: ширина колонки 106 px (последняя 107–108).

## Верхние шторки (header plates)
Три плашки над окном, соответствуют B1/B2/B3.

| Параметр | Значение |
|---|---|
| Позиция | x = `i*106+2`, y = **2** |
| Размер | w = 102 (у третьей 105), h = **26** |
| Цвет плашки | `0xff242424` |
| Подпись | по центру плашки, `text(g,s,x,2,w,25,13,…)`, **13 pt** |
| Цвет подписи | белый `0xffffffff`; янтарный `0xffffc247` — включено/активно; красный `0xffff4040` — Cancel/Delete/Clear; серый `0xff777777` — недоступно |
| Пустая шторка | не рисуется (чёрный фон), как в штатных окнах |

Где применено: Rear/Routing, Resample, Song Export и Clear All, Mono, Batch, Tuner, Chords, Step (Sound/Events/Edit, Back/Do It), Palette, Mod Settings, MIDI.

Исключения (намеренно):
- **Компрессор** (`compressor_ui.c`): плашки Type/Warm/Bypass y=1, h=28, цвет `0xff202020`, подписаны под родные плашки Color/Type/Bypass. Рядом штатные кнопки без плашки.
- **Sample Record**: подпись To Seq вписана в штатную шапку, поверх закрашивается чёрным `rect(107,0,105,35)`.
- Штатные окна (меню Project, Input Config) рисуют шапку сами: без плашек, текст «Back» центром примерно на y≈11–13.

## Нижние плашки параметров (K1–K3)
| Параметр | Значение |
|---|---|
| Позиция | x = `col*106+2`, y = 198 или 199, h = 39–40 |
| Ширина | 102 (у третьей 105) |
| Фон | `0xff202020`; в фокусе `0xff302412` (тёмно-янтарный) |
| Верхняя кромка в фокусе | янтарная линия 1 px |
| Название | 11–12 pt, серый `0xffaaaaaa` (в фокусе янтарный), y ≈ 200 |
| Значение | 14–16 pt, белое (в фокусе янтарное), y ≈ 214 |

## Шрифты и выравнивание
Функция `text(g,str,x,y,w,h,size,colour[,flags])`; флаги выравнивания: `0x21` — слева, `0x24` — по центру (используются в `midi_ui.c`/`song_ui.c`).

| Назначение | Размер |
|---|---|
| Подписи шторок | 13 |
| Заголовок окна (жёлтый/белый по центру) | 17–20 |
| Строки списков | 14–16 |
| Название параметра K1–K3 | 11–12 |
| Значение параметра | 14–16 |
| Подсказки/статус внизу | 10–12, серый |
| Мелкие метки таблиц (CH, PORT…) | 10, `0xff999999` |
| Подпись под To Seq при Rear | 9, `0xffbbbbbb` |

Правила:
- Подпись центрируется по плашке по горизонтали и по высоте плашки (h на 1 px меньше плашки).
- Подчёркивание «включено»: янтарная линия 2 px под подписью, ширина ≈ 44 px по центру (To Seq), в компрессоре 90 px на y=25.
- Заголовок окна под шторками: y≈30–40, центр, 17–20 pt.
- Строки списков: левый край x=12, ширина 296, шаг 26–31 px.

## Song
- Список: row pitch **26 px** (определяется по зазору между строками; запасное значение 33), LIST_TOP 38, LIST_BOTTOM 198.
- Номер шага — ячейка слева; полоска цвета шага слева от строки.
- Повторы: плашка x=236, w=72, текст `"N bars ×R"` 11 pt по центру, у выбранной строки голубой, иначе белый.
- Shift-шапка: `Clear All` (красный) слева, `Duplicate` (белый) справа, без серых плашек.

## Как править
1. Шторки: меняйте только по шаблону выше (`i*106+2`, y=2, 102/105×26, `0xff242424`, 13 pt).
2. Новые окна: брать цвета из таблицы, не вводить новые оттенки.
3. После правки собрать `python3 build_mixer_r27r.py` и проверить окна на приборе: шторки должны выглядеть как в MIDI In.
