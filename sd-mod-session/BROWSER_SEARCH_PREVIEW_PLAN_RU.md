# Состояние r14c

Реализованы ограниченный поиск в текущей папке / подпапках / содержащей библиотеке, выбор пэда в результатах Samples, раздельные штатные обработчики загрузки Samples/Projects и обновление Search по Shift. ARM-проверки пройдены, аппаратная проба r14c ожидается. Предпросмотр по B3, громкость K3 и подтверждаемое удаление Erase остаются отдельным этапом: их нельзя считать готовыми по наличию поиска.

# Следующий этап — браузер сэмплов и проектов

Запрос пользователя от24.10.2026. Это план; в r13b браузер не изменён.

- Shift+B3 — Search в открытом разделе Samples или Projects. Ввод через существующую телефонную клавиатуру на пэдах с сохранением энкодера и +/−. Во время текста пэды не запускают звук; при закрытии восстанавливаются управление и RGB.
- B3 — Preview выбранного сэмпла. Для проектов поиск нужен, а способ аудиопредпросмотра проекта отдельно не задан: проект не загружать автоматически ради прослушивания.
- K3 — Preview Volume, отдельное от pad/kit volume и сохранённого проекта усиление предпросмотра.
- Erase — удалить выбранный файл через штатную операцию, только после подтверждения с именем файла и выбранной по умолчанию отменой. Старую B3 Delete убрать после переноса. Кнопка Erase сама по себе ничего не удаляет. При обновлении списка подтверждение должно оставаться привязанным к первоначально выбранному объекту.

Перед реализацией разобрать штатные browser rows, native Preview transport/gain, sample/project Delete с данными проекта и окно поиска. Сначала подготовить UI/навигацию и текстовый ввод, затем Preview/gain, последним — удаление с подтверждением и отменой. Не расширять текущую область записи на SD ради функции браузера. Проверить поиск, пустой результат, возврат без изменения выбора, смену результата во время Preview, громкость без изменения проекта и отсутствие удаления при отмене.
