# r17 — первая ограниченная проба ресэмплинга

Основа — рабочая r16d. Вход в новое окно: **Sample → Shift + пэд 11**. B1 Cancel, B2 Seq (штатный режим), B3 Sample (новая обработка выбранного сэмпла).

Эта версия обрабатывает исходный PCM в диапазоне Trim. Полная запись звучания пэда с Tune, огибающей, штатным фильтром и другими FX пока не реализована. Собственная цепочка допускает пять EQ с перестановкой; это ещё не пять разных штатных эффектов. Сравнение в миксе и графический анализатор не включены.

## Первая проба

1. Безопасно извлечь SD в Windows. Загрузить MPC **без карты**, затем вставить её и подтвердить **Start r17 resample trial**. Загрузка со вставленной autorun-картой ранее зависала на 0%; этот сценарий пока не исправлен.
2. Сохранить текущий проект. Для пробы использовать новый проект и один короткий простой сэмпл, например около секунды. Найти свободный пэд для результата.
3. Открыть Sample → Shift + пэд 11 → B3 Sample. На первый раз оставить Repeats = 1, Tail = 0, FX пустыми. B3 Render готовит результат в RAM и показывает **Result ready**. Сам рендер не заменяет звук на пэде.
4. Сначала проверить отмену: B1 Back вернёт к настройкам; затем B1 Cancel закроет окно. После закрытия исходный пэд должен звучать как раньше.
5. Повторить Render. На экране результата **K1 → To Pad**, **K2 → нужный банк**, **K3 → свободный пэд**. Проверить назначение по экрану и нажать B3 Apply. В первой пробе исходный пэд не заменять.
6. После закрытия окна нажать пэд результата. Проверить звук, затем Undo и Redo. Первое аппаратное прослушивание нового RAM Sample ещё не подтверждено стендом.
7. Только после этого сохранить проект под новым именем на External. Закрыть мод через Project → нижний Mod Off → B3; в штатном приложении открыть сохранённый проект и проверить результат.

Для проверки EQ после успешного простого рендера: в настройках Sample нажать B2 FX, выбрать пустой слот K1 и B3 Edit. K1 — частота, K2 — усиление, K3 — Q; B3 — следующая полоса, Shift+B3 — тип. B2 Bypass, B1 Back. Для первого сравнения можно сделать небольшое ослабление. В списке FX Shift+B2/B3 перемещают эффект выше/ниже; B2 переключает bypass. Снова Render и назначение на свободный пэд.

**Play / Stop и Main Volume остаются штатными.** В открытом окне ресэмплинга пэды не играют. Для обычного выхода сначала закрыть окно через Cancel (из Result ready — Back, затем Cancel), дождаться возврата Sample, затем Project → Mod Off. После Apply окно закрывается само после подтверждённой очистки рабочего задания. Если настоящий Apply уже успел завершиться, поздняя отмена не скрывает результат; используется Undo.

## Что проверено и что ещё предстоит

ARM/QEMU и UBSan проверяют чтение/рендер/EQ, реальный RAM Sample, регистрацию/назначение, Cancel во время чтения/DSP/копирования и перед native dispatch, задержанный Cancel после завершённого Apply, Undo/Redo, остановку повторной постановки задач, прямой транспорт/master volume, уничтожение контекста и поздние события интерфейса. Полная библиотека загружается с native rootfs; все 50 callbacks проверены.

Конечный физический sampler, реальный GUI/получатели параметров, Save/reopen и полное аппаратное выключение остаются предметом пробы. Стенд не воспроизводит весь порядок завершения устройства. При неожиданном зависании не повторять нажатия; сообщить, на каком шаге оно возникло, и вернуть карту с журналом после восстановления штатного интерфейса. Если устройство совсем не реагирует, используется прежний порядок экстренного выключения и загрузки без карты.

Встроенная прошивка и постоянная загрузка не меняются. Пакет использует прежний r16d launcher: копия приложения и рабочие изменения живут в RAM, сохранения на SD — в штатных папках MPC-Sample. Это первая экспериментальная аппаратная проба, а не обещание отсутствия сбоев. Исходный r16d архив сохранён отдельно.
