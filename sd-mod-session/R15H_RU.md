# r15h — штатная строка Mod Off без накладки

Убрана дополнительная отрисовка Mod Off поверх Project. Она ошибочно рассчитывала координату по предполагаемой высоте строки и перекрывала Key / Scale.

Меню полностью рисуется штатным кодом: Load Project, Save Project, New Project, SD Card Access, Key / Scale, Mod Off. Mod Off — последняя белая строка, без дублирования. Подтверждение выхода сохранено: B1 Cancel, B3 Mod Off. Цвет кнопки подтверждения в самом диалоге не менялся.

Остальные функции r15g сохранены. Ресэмплинг не включён.

## Проверка

1. Безопасно извлечь карту в Windows, вставить в полностью загруженный MPC, подтвердить Start r15h.
2. Открыть Project. Проверить, что Key / Scale виден целиком, а ниже есть ровно один белый Mod Off. Выделение каждой строки должно быть штатным, без выглядывающих частей.
3. Открыть Key / Scale и вернуться. Выбрать Mod Off: B1 отменяет выход, B3 подтверждает.

Прошивка устройства не переписывается. ARM/QEMU-проверки не заменяют проверку экрана MPC. После пробы: подтверждённый Mod Off → штатный Eject; в Windows использовать безопасное извлечение.
