# MPC Sample Lab

Локальная интерактивная модель Akai MPC Sample (AC50), восстановленная по корпусу и строкам штатной прошивки.

## Запуск

```powershell
npm install
npm run dev
```

Откройте адрес, который напечатает dev-сервер. Проект работает локально и не отправляет аудио в сеть.

## Уже реализовано

- корпус и раскладка аппаратных контролов MPC Sample;
- настоящие названия AC50-экранов и переходы Sample, Sequence, Step Edit, Project, MIDI, Song, Resample и других режимов;
- 16 пэдов, четыре банка, Shift+Pad shortcuts, transport, record, K1–K3, data encoder и фейдер;
- 32-шаговый секвенсор и tempo;
- назначение WAV/MP3 на каждый пэд;
- офлайн-ресэмплинг двухтактного паттерна в WAV;
- сохранение проекта в JSON и экспорт Lua-модели для будущего firmware bridge.

Браузерная часть является исполняемой моделью логики, а не оригинальным ARM ELF. Контур запуска штатного ARM64 Linux расположен в соседней папке `../arm-runtime`.
