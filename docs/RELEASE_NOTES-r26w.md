# Candidate r26w — Standard/AM Mod lighting and Note Repeat

Project → Pad Lighting selects a global SD preference, separate from projects.
Standard restores native pad output and disables custom colour controls; new mod
windows use fixed palettes. AM Mod restores retained identity colours. Audio,
pitch/transpose and project data are unchanged. The native Project menu has seven
entries in its six-row viewport, with Mod Off last.

Note Repeat owns B1/B2/B3 over both compressors, including a latched overlay and
queued quick release. Type/Warm painting and commands defer to the native rates.

See [Russian release notes](RELEASE_NOTES-r26w.ru.md) for controls, persistence,
mode scope and exact validation boundaries. Local unpublished device candidate;
physical scrolling and combined native-main UI checks remain pending.
