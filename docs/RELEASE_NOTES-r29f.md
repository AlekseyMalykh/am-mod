# r29f (research build after r29e)

Adds a log of the **stock Knob FX / FX Select screen** (`KNOBFX` lines in `MPC_CLONE_TRIAL.txt`): which memory words change when you pick an effect, toggle Bypass or select pads. It is used to find where the stock firmware keeps the chosen effect, its Bypass state and the target pads. Use it in **FX mode = Stock** (the stock screen is not shown in Am MOD). No audio or UI changes. Includes r29e.
