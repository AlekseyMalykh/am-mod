# r27e — готовность к публикации

**Состояние:** локальный предварительный релиз подготовлен. Публичный — r26s;
удалённые ветки, теги и GitHub Release этим этапом не изменяются.

## Проверено

- Сборка r27e, общий номер версии, все 50 preload-callback.
- Актуальные ARM/QEMU/UBSan отчёты: курсоры128 пэдов/восьми банков/четырёх режимов,
  штатный setter цели браузера, пустые пэды и программа, источники/цели/Standard,
  Steps WRITE/TOGGLE, K/сброс, Note Repeat, настройки/восстановление XPJ,
  отсутствующий Temp-Project, EQ/Filter и OptoCat/Warm.
- Пакетная проверка хешей и shell-синтаксиса; установщик1.0.2 не меняется.
- r27e записана на SD и сверена:75 файлов; шесть XPJ и пользовательские файлы
  сохранены. Новый релизный ZIP меняет документацию, autorun побайтно тот же.
- Видимость ранней DRM-заставки и упоры K ранее подтверждены на MPC.

## Перед стабильным релизом повторить на MPC

1. Новый изменённый проект: дождаться автосохранения; ручной Save/Load без Auto Save Error.
2. A/B/страховочная копия: ноты, секвенции, сэмплы, эффекты, имя и подтверждение Save;
   нормальное выключение, работа stock без карты, повторный старт мода.
3. Курсоры пустого Sample и браузера, смена банка, источники Copy/Batch/Chop/Mono/Render,
   свободная/занятая цель и все скорости курсора. Standard/Piano/Scale.
4. Note Repeat: быстрое отпускание и latch, B1–B3/Type; OptoCat/Warm/Bypass после New Project.
5. Исходные открытые случаи L06, L11, L13 и физическая FAT32.

Ранние проверки отдельных подсистем в полной VM не равны полному прогону
именно итогового пакета; такой прогон и аппаратный проход всех функций не заявляются.
Уместный канал сейчас — **prerelease**, без заявления, что все обращения закрыты.
Синт, стемы и микшер — пожелания, не незавершённые функции этого релиза.
