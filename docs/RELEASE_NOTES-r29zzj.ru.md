# Am MOD r29zzj

Mixer > Input:
- Индикатор уровня входа рядом с фейдером (вкладка MIX): пик выбранного входа до обработки.
- Кнопка Mute глушит Input (как глушит трек в остальных местах); K2 по-прежнему тоже переключает.
- Вкладка ROUTE: поворот DATA выбирает строку (Record via, Record track, Record FX, а для Rear ещё Rear mode), K1 или нажатие DATA меняет значение. K2/K3 остаются Pan/Level для Rear.
