# MPC Sample Mod Installer 1.1.0

Обновление установщика Am MOD от 12 ноября 2026 года. Совместимо с пакетом r28d и более ранними поддерживаемыми пакетами.

## Новые возможности

- Кнопки GitHub и All releases в главном окне.
- Вкладка Release news с описанием последнего основного релиза, новыми функциями и исправлениями. Refresh news обновляет сведения, Download this release загружает показанный пакет.
- Заметки из README выбранного локального ZIP доступны без сети.
- Форма отчёта об ошибке с версией мода, шагами воспроизведения, ожидаемым и фактическим результатом.
- Диагностический ZIP с отчётом, журналом установщика и доступными журналами SD. Форма показывает список файлов, сбор журналов можно отключить.
- Copy report копирует полный текст. Open GitHub issue открывает заполненный черновик обращения.

## Установка или обновление мода

1. Скачайте и запустите MPC-Sample-Mod-Installer.exe.
2. Подключите SD-карту MPC к компьютеру и выберите её в установщике.
3. Нажмите Latest release либо откройте скачанный ZIP мода. Можно также загрузить выпуск из вкладки Release news.
4. Нажмите Install и подтвердите версию и карту.
5. Безопасно извлеките карту, вставьте её в MPC и перезапустите устройство.

Установщик рассчитан на MPC Sample с прошивкой 1.3.0.12. Перед обновлением сделайте резервную копию проектов и сэмплов.

## Отправка отчёта с журналами

1. Повторите проблему на MPC, затем подключите его SD-карту к компьютеру.
2. Выберите карту в установщике и нажмите Report a bug.
3. Проверьте версию мода. Заполните краткое описание, шаги, ожидаемый и фактический результат.
4. Проверьте список файлов. Снимите Include available SD journals and installer log, если нужен отчёт только с описанием.
5. Нажмите Save diagnostic ZIP и выберите место на компьютере.
6. Проверьте архив. Журналы могут содержать имена проектов и пути к файлам.
7. Нажмите Open GitHub issue. При необходимости войдите в GitHub.
8. Приложите сохранённый ZIP в браузере, проверьте черновик и отправьте обращение. Для длинного описания нажмите Copy report и вставьте полный текст в обращение.

В архив могут входить MPC_MOD_VERSION.json и autorun/MPC_MOD_EVENTS.txt, autorun/MPC_CLONE_TRIAL.txt, autorun/MPC_CLONE_ALREADY_ATTEMPTED.txt. Недоступные журналы перечисляются в collection.txt. У больших журналов сохраняются последние 2 МиБ. Подготовка отчёта работает и без выбранной карты.

Прикрепление журнала и окончательная отправка выполняются в браузере. Для отправки обращения нужна учётная запись GitHub.

## Проверки

Тесты установщика пройдены на Windows и Linux. Windows-версия собрана с PyInstaller 6.11.1. Проверены получение сведений с GitHub и чтение заметок r28d без сети. Визуальная проверка осталась незавершённой из-за тайм-аута инструмента захвата окна.
