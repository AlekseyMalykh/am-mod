# Am MOD r29zzk

Mixer > Input:
- B1 теперь Back (вкладки MIX больше нет). Level остаётся на фейдере, Mute на кнопке Mute; Pan и Monitor перенесены в ROUTE.
- Строки ROUTE: Pan, Monitor (монитор рекордера Off/On, нужна открытая сессия Sample Record), Record via, Record track, Record FX, Rear mode.
- Энкодер: вращение переходит между строками, клик включает редактирование строки, вращение меняет значение, повторный клик принимает. K1 по-прежнему меняет выбранную строку сразу.
- Список FX на всех каналах: Copy теперь Shift+Erase, Paste на Shift+B2.
- Диагностика: строки KNOB_RESET MIXER / PADBANK в логе (время сброса по Pad Bank + K).
