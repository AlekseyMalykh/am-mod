# r28e-fx11 (кандидат в r29a)

Исправление: окна Save Project и Save Sample только External (SD). K3 принудительно External при открытии окна и при любом движении K3. Диагностические логи (SAVE_SCREEN/SAVE_K3/SAVE_BUTTON) пока включены.

Master FX: закреплённая строка "Sample Comp" пока скрыта (компрессор Sample появляется только после первого открытия в Sample, а для Duck не было экрана). Вместо неё добавляйте OptoCat из каталога FX.

Ввод текста: окна имён, поиска и экспорта (проект, сэмпл, имена треков в микшере, экспорт Stems) теперь по умолчанию открываются в режиме Pads. K1 по-прежнему переключает на Encoder. Новая настройка мода: вкладка Quick > Text input (Pads/Encoder), хранится на карте.


Исправлено: экспорт Stems не работал (SD_EXPORT_UNAVAILABLE), когда назначением был External (Samples/User/Export на карте); стемы всегда сохраняются в Samples/User/Export на SD, что бы ни показывало окно экспорта, в папку с названием песни. Первая вкладка настроек мода переименована Pads -> Quick.

Stems: стандартный микс-WAV переносится в папку песни как "<песня>_Master.wav" и не остаётся в Samples/Export. Ввод Pads по умолчанию теперь действительно принимает пэды (раньше показывал Pads, но пэды не работали, пока не переключить K1).

Имена файлов стемов теперь содержат название трека: "<песня>_track A_<название>.wav" (только если трек переименован), "<песня>_Master.wav".

- Экраны эффектов: строка значений под картинкой убрана (значения на панели параметров). Новые детальные картинки с подписями AM MOD: Tape Delay (бобины, ролики, головки), Tape (кассета с VU и кнопками), Vinyl (проигрыватель), Sample Delay.
- Кассета Tape: две кнопки PLAY/STOP (PLAY нажата, пока идёт звук, STOP — когда остановился), бобины крутятся только при звуке, стрелка VU качается по уровню сигнала.
