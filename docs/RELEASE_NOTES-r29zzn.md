# r29zzn

- Tuner is now a full-screen window: note row, straight +-50 cent scale with a moving needle, frequency in Hz and the detected note.
- Open it from Mixer > Input > ROUTE (DATA click on the Tuner row) or from Sample Record with B3. B1 / DATA / B2 / B3 close it.
- Not tested on a device yet: pitch detection on real input and the repaint rate.
