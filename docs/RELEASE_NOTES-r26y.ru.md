# r26y — локальный кандидат

Не опубликован; публичный релиз остаётся r26s. Перед испытаниями сделайте
резервную копию проектов и сэмплов.

- Вместо Pad Lighting — **Mod Settings** с четырьмя прокручиваемыми разделами,
  B2/B3 для вкладок и последним пунктом Restore recommended в каждом разделе.
  Сброс требует подтверждения: B1 — Cancel, B3 — Restore.
- Отдельные переключатели окрашивания волны и спектра цветом пэда. Фильтры,
  огибающие и боковые шкалы сохраняются; рекомендуемый вариант — Original.
- Обмен системных цветов с пользовательскими: остаются пять пользовательских
  слотов, подписи обновляются, старые ID XPJ сохраняются.
- Настройка мигания выбранного рабочего пэда: Steady, Slow, Normal, Fast.
- Полный снимок отображения и параметров OptoCat/Warm/Type входит в XPJ.
  Duck и Bypass остаются под управлением штатного сохранения. Ошибочная
  загрузка не меняет текущий снимок; старые проекты читаются.
- Копия при обычном выключении содержит исходное имя/папку проекта, в том числе
  при асинхронной штатной записи. Восстановление сохраняет каталог сэмплов копии;
  первый Save требует отдельного подтверждения. Штатное автосохранение
  продолжает использовать Temp-Project; оно не перенаправляется в оригинал.
- Mod Off убран из Project; обычное выключение с копией и аварийное
  восстановление штатного приложения сохранены. Ранняя заставка **Am MOD**
  выводится загрузчиком до подготовки приложения, с отдельным аварийным возвратом.
- SD-проект подставляется в первую штатную полную загрузку; поздняя повторная
  автозагрузка отключена. Штатный Temp-Project и ручные Load сохраняются.
- Steps: SEQ RECORD сохраняет WRITE; SAMPLE RECORD включает TOGGLE
  (добавить/удалить событие), с взаимным выключением режимов и их LED.
- Сохранены исправление K, OptoCat/Warm, Note Repeat, Standard Piano/Scale,
  EQ, цвета Copy/Batch/Chop/Mono/Resample, Delete через ERASE, exFAT и
  экспериментальная поддержка FAT32.
