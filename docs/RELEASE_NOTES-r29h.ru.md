# r29h (исследовательская сборка после r29g)

Строка `ROUTE_PADS` в логе теперь показывает у каждого пэда **штатный id маршрута** (`id=`). Проект хранит выделение пэдов для FX Select в `audioRoute.destination` каждого пэда; лог показывает, как это приходит в аудиотракт. Звук и интерфейс не менялись. Включает r29g.
