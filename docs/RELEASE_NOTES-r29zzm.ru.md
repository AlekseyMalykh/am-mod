# Am MOD r29zzm

Mixer > Input > ROUTE:
- Первая строка теперь Tuner (нота и центы выбранного входа, детектор высоты YIN); K1 показывает центы на шкале с нулём по центру.
- Pan переехал на K2 для Mic/USB (для Rear остаются Pan L/R на K2/K3).
- Record track заблокирован (серый, с подсказкой), пока Record via = Input.
- Включает r29zzl: строки Record routing убраны из Mod Settings; пэды эффектов 9-12 мигают красным при Bypass и горят ровным тусклым красным при Chain Bypass.
