# r29f (исследовательская сборка после r29e)

Добавлен журнал **штатного экрана Knob FX / FX Select** (строки `KNOBFX` в `MPC_CLONE_TRIAL.txt`): какие слова памяти меняются при выборе эффекта, переключении Bypass и выделении пэдов. Нужен, чтобы найти, где прошивка хранит выбранный эффект, его Bypass и целевые пэды. Использовать в **FX mode = Stock** (в Am MOD штатный экран не показывается). Звук и интерфейс не менялись. Включает r29e.
