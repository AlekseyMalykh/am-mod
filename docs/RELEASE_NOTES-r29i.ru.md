# r29i (тестовая сборка после r29h)

**Knob FX / FX Select в режиме Am MOD теперь действует только на выделенные пэды.**

- Когда для FX Select выделена **часть** пэдов, они идут штатным путём (штатный эффект, затем Master), остальные идут через треки микшера как обычно. Эффект больше не задевает невыделенные пэды.
- Когда выделены **все** пэды (B2 All) или ни один, ничего не меняется: пэды идут через микшер, а эффект (если есть) действует на сумму Master как штатная вставка.
- Выделенные пэды обходят треки (и их метры и Track FX), пока выделены.
- Известно: если невыделенный пэд сыграли первый раз, когда уже звучала долгая нота выделенного, нота может один раз сменить путь. Если услышите щелчок, сообщите.

Включает r29h (`ROUTE_PADS` с id маршрутов) и всё предыдущее.
