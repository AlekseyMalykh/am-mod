# Am MOD r29zzi

Mixer > Input теперь с тремя вкладками (B1 MIX, B2 FX, B3 ROUTE), как у обычных каналов.

- MIX: полоса Input с Level (фейдер), Pan (K1) и Mute (K2). Действуют на звук выбранного входа после цепочки Input FX, до маршрута записи Track/Master, и сохраняются в проекте.
- FX: список эффектов входа как раньше (Shift+B1 возвращает назад).
- ROUTE: источник, Record via / track / FX (пока меняются в Quick Mod Settings) и K записи для Rear.
- Phase, Mono/Stereo, мониторинг и запись по источникам в этой сборке не вошли.
