# Кандидат r26e — экспериментальная поддержка FAT32

[English](RELEASE_NOTES-r26e.md) · Изменения относительно [r26d](RELEASE_NOTES-r26d.ru.md).

- Запуск AM Mod с **FAT32 / MS-DOS (FAT32) в экспериментальном режиме** и exFAT на прошивке **1.3.0.12**. Аппаратная проба FAT32 на MPC пока не выполнена. Существующую карту FAT32 не нужно переформатировать или освобождать от проектов и сэмплов.
- Определённую файловую систему поддерживают загрузчик, песочница, диагностика и ARM-помощник сброса записи проектов и журнала. В песочнице приложения для записи доступны только две штатные папки SD; проверки типа файловой системы, полного пути и идентичности каталогов сохраняются.
- Установщик **1.0.2** принимает FAT32 на Windows/macOS/Linux и проверяет возможности пакета. Старые пакеты только для exFAT отклоняются на FAT32 до резервного копирования и записи. Нужна полная папка `autorun/` из r26e; замены одного скрипта недостаточно.
- Библиотека приложения r26d не менялась: сохраняются исправления цветов пэдов, восстановления проектов и спектр Filter/Filter Env/EQ со штатными кривыми.

Имя тома — например, `MPC` или `MPCSAMPLE`: латинские буквы ASCII, цифры, `.`, `_`, `-`, без пробелов. Это ограничение имени карты, а не проектов и сэмплов. FAT32 ограничивает размер одного файла **4 ГиБ минус 1 байт**. NTFS, APFS и ext4 для установки не поддерживаются.

## Проверки

- Регрессии установщика: установка, резервная копия, повторная установка, удаление, сохранность пользовательских файлов, названия файловых систем в разных ОС и отказ старым пакетам на FAT32.
- Проверки рабочих shell-функций: exFAT/FAT32 допускаются; подмена файловой системы, папки только для чтения, отсутствие папок и дополнительные доступные для записи диски отклоняются.
- Отдельные настоящие образы FAT32 и exFAT: побайтовая проверка установки/повторной установки/удаления, сохранность проекта с кириллическим именем, ARM `syncfs` проектов и журнала; отказ при неверной файловой системе, изменённой идентичности каталога и метаданных-ссылке.
- Полная проверка FAT32 в эмуляторе пройдена: штатный autorun, песочница, автоматическое восстановление проекта, штатное сохранение через Mod Off и возврат к штатному приложению. В XPJ сохранились три MIDI-события, темп 137 BPM и уровни микшера/дорожки; исходный проект и контрольный пользовательский файл не изменились. Файл повторно сверили после остановки VM и подключения её образа только для чтения.
- Из-за медленной программной эмуляции ARM время ожидания службы возврата увеличили до 600 секунд только в RAM-настройках VM и повторили возврат после первоначального тайм-аута. Файлы сборки и её таймеры не менялись.
- exFAT прошёл установку/сброс записи на настоящем образе и проверку песочницы в полном эмуляторе. Первая попытка в эмуляторе вернулась к штатному приложению после тайм-аута запуска во время паузы VM; повторная проверка песочницы пройдена. Полный цикл восстановления/сохранения приложения проверен на FAT32; для exFAT в этой проверке он не повторялся.
- Аппаратная проба FAT32 на MPC пока не выполнена. Экспериментальный кандидат не опубликован.

Команды повторения проверок и сборки приведены в английской версии заметок.
