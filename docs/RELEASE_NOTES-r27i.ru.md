# Проверочная r27i — луп независимо от выбора пэда

В r27h автор подтвердил: после запуска лупа и выбора другого пэда курсор
переходил правильно, но звучащий луп не выделялся. Аппаратная проверка
показала, что прежнее изменение N16 не закрывает этот сценарий.

r27i сопоставляет звучащие голоса с инструментом пэда независимо от MIDI-ноты.
Штатная подсветка использует разные правила выбора ноты для текущего пэда
и его соседей; постоянное использование карты нот не должно быть условием
индикации лупа. Все обращения к списку голосов остаются на штатном владельце
подсветки. UI/RGB получают числовой снимок.

Пульсирует назначенный цвет звучащего пэда. Белый курсор остаётся на последнем
выбранном пэде. После остановки голоса пульсация выключается. Выбранный пэд
показывает курсор поверх своего цвета, мют сохраняет серый цвет.

Добавлены ограниченные записи `SAMPLE_PLAYING PAD` с индексом пэда, состоянием
и числом голосов, чтобы проверить фактический путь на MPC при повторном отказе.

Проверки ARM64/UBSan используют настоящий предикат состояния голосов прошивки:
смена MIDI-ноты не скрывает активный инструмент, остановка голоса снимает
признак воспроизведения. Результат штатной функции подсветки передаётся без
изменений. На MPC исправление ещё не подтверждено.

Проверка: остановить Seq, запустить луп на A01, выбрать A02; A01 должен
пульсировать своим цветом, A02 — белым курсором. Запустить второй луп,
выбрать третий пэд, затем поочерёдно остановить оба лупа. Повторить в другом
банке и в Standard, где остаётся штатная подсветка.

Все восемь пользовательских цветов, насыщенные системные цвета, исправление
имени после Save и SD-хранилище временных сэмплов сохранены. На заставке
`version: r27i`, в About — r27i. Публичный релиз остаётся r27f.
