# Раскладка ручек FX в r30b

K1–K3 и Shift-слой, DATA выбирает страницу. Amp Model меняется на K1, B3 — Solo. Во всех редакторах FX: Shift+B2 — Paste, Shift+B3 — Chain Bypass. В EQ Shift+DATA добавляет точку. В редакторе Sample Comp Shift+DATA переключает Warm. Shift+Erase копирует эффект.
