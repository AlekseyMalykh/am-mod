# Am MOD r29zzj

Mixer > Input:
- Input level meter next to the fader (MIX tab), raw peak of the selected input.
- The Mute button mutes the Input (as it mutes a Track elsewhere); K2 still toggles it too.
- ROUTE tab: DATA turn selects a row (Record via, Record track, Record FX, and Rear mode on Rear), K1 or DATA press changes it. K2/K3 stay Pan/Level for Rear.
