# Am MOD r28e-fx1 (test build, not for release)

r28e plus the Illustrated FX branch. Hardware-untested.

- **Mod Settings → Pads → FX view: Illustrated / Classic.** Illustrated (default) draws an animated, parameter-reactive picture for every mixer effect; Classic is as r28e. Graphic EQ is unchanged. The pictures cost CPU only while an effect screen is open.
- **New mixer effects:** Shimmer Reverb, Pitch Shifter, Reverse Delay, Tremolo, Slow Attack, Ring Modulator, Bit Crusher and OptoCat Comp (independent per track/master). Projects that use them do not load in older Am MOD versions.
- **Master FX page:** a status line shows the Sample-mode compressor (Duck/OptoCat, Bypass, gain reduction).
