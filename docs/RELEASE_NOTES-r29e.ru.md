# r29e (тестовая сборка после r29d)

- **Shift+Knob FX вне Sample теперь недоступен** (в режиме Am MOD он больше не передаётся штатному действию, например Input Config в Seq). В Sample по-прежнему открывает Микшер на Track FX последнего нажатого пэда.
- Включает r29d (FX mode Stock / Am MOD, по умолчанию Am MOD) и диагностику `ROUTE_PADS`.

Известная проблема: штатный эффект FX Select, сохранённый в проекте (например Vinyl Emulator), в режиме Am MOD может звучать, хотя микшер его не показывает. Чтобы убрать: переключить FX mode в Stock, отключить эффект и вернуться. Разбираюсь.
