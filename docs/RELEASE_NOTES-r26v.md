# Candidate r26v — clear focus and selected-only destinations

Local unpublished candidate based on r26u. Unassigned empty targets stay off;
occupied background pads retain dim identity. Only assigned targets use green
(free) or red (occupied). Sample, Chop and held-Sound selection use an obvious
400ms white / 400ms identity cursor; Sample selection resets the phase immediately.
Mute event flashes, Seq rhythm, Steps erase precedence, five identity colours,
OptoCat/Warm, native K handling, EQ sidebars and experimental FAT32 are preserved.

See [Russian details and verification scope](RELEASE_NOTES-r26v.ru.md).
Physical MPC and full combined native-main checks are pending.
