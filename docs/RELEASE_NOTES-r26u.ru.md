# Кандидат r26u — системные роли подсветки

Локальная тестовая сборка, не опубликована. На основе r26t; OptoCat/Warm,
ограничения Gain, исправление K, EQ-индикаторы и экспериментальный FAT32 сохранены.

- Pad Colour и Sequence Colour: Default и пять цветов — Blue, Violet, Magenta,
  Orange, Pink. Системные красный, зелёный, белый, янтарный, голубой и серый исключены
  из этих меню. Стабильные числовые ID не перенумерованы, Pink добавлен с ID13.
- Старые цветовые метаданные сохраняются без автоматической перезаписи: Default,
  Green/Lime/Mint/Cyan отображаются синим; Amber/Yellow/White — фиолетовым;
  Red — пурпурным; Blue/Violet/Magenta/Orange сохраняют свой оттенок.
  Название в поле цвета показывает отображаемый оттенок. Старые версии мода
  не поддерживают новый Pink: перед возвратом на них нужно убрать этот цвет
  либо открыть исходную резервную копию проекта.
- Все места назначения Batch Copy/Extract, Mono, Resample и поиска сэмплов:
  пустые зелёные, занятые красные. Назначенные ярче, текущая цель пульсирует
  тем же красным/зелёным. Цвет источника не перекрашивает цель.
- Обычный Copy/браузер получают снимок занятости из модели; штатный красный
  обозначает выбор назначения, а не доказательство занятости.
  При недоступном снимке сохраняется штатная индикация.
- Выбранные Batch-источники: двойная белая вспышка ↔ свой цвет.
- Sample: независимый белый курсор, собственные цвета занятого банка,
  пустые места не загораются от сохранённого цветового назначения.
- Mute: тусклый серый фон и серые вспышки120 мс по записанным событиям,
  в том числе после выхода из Mute. Аудио и признак Mute не меняются.
- Native Chop: цвет источника и белый курсор вместо штатного оранжевого
  выбранного среза. Музыкальные Velocity/Filter/Tune-раскладки не заменяются
  сеткой сэмплов.
- Steps: muted серый; красное предупреждение удаления важнее курсора/playhead.
  Согласованный музыкальный ритм Seq сохранён, цвета берутся из безопасной палитры.

[Полная карта и границы реализации](PAD_LIGHTING_MAP.ru.md).
Отдельные Loop/Song-LED-маркеры и полная унификация штатных Erase/FX остаются
описанным проектом схемы. Их штатные действия не переделаны в этой сборке.
Оранжевый и розовый нужно проверить на физических пэдах рядом с системными цветами.

Проверки ARM/QEMU/UBSan и preload описаны в локальном verification; физическая
проверка новой схемы ожидается после записи. Это не утверждение о прохождении
полного приложения в VM или проверке всех состояний на MPC.
