# Проверочная r27j — отчётливое мигание лупа

Играющий пэд Sample/Loop теперь чередует назначенный цвет с полным погашением:
400 мс цвет / 400 мс выключен. Прежнее чередование яркого и обычного уровня
могло сливаться с постоянно подсвеченными загруженными пэдами.

Выбранный пэд сохраняет белый курсор с выбранной в настройках скоростью.
Если он же играет, между белыми вспышками виден его назначенный цвет.
При выборе другого пэда звучащий пэд продолжает мигать цветом/погашением.
Остановка голоса возвращает обычную подсветку содержимого. Для мюта остаётся
серый цвет. Standard сохраняет штатную подсветку.

Проект, по сообщению автора, теперь загружается правильно. Настройки восьми
цветов, запоминание имени Save и SD-хранилище временных файлов сохранены.
На заставке — `version: r27j`.

ARM64/UBSan проверяют полное погашение, 128 пэдов, восемь банков и восемь
цветов, приоритет курсора и переход при выборе соседнего пэда. Нужна проверка
на MPC: A01 Loop → выбрать A02 → остановить A01. Публичный релиз пока r27f.
