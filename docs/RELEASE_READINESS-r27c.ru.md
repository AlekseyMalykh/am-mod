# r27c — готовность к проверке

Локальная проверочная сборка; публикация остановлена по просьбе автора.
Auto Save Error после New Project воспроизведена и исправлена в полной VM.
Проверки ARM/UBSan: источники и цели, настраиваемый курсор, сброс K,
очередь ввода, Scaled, recovery и загрузка, DSP OptoCat и EQ.
Показ заставки r27a и малые подписи подтверждены пользователем; текущий
пакет ещё требует теста прибора. FAT32 всё ещё экспериментально.
L01–L04/L06/L08/L11/L13/L16/L22 не закрывать одним прохождением тестов:
нужны исходные аппаратные сценарии. См. KNOWN_ISSUES.ru.md.
