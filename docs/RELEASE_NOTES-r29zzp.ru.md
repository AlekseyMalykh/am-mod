# r29zzp

- Окно тюнера поверх режима Sample: удерживайте Stop и нажмите Chop. Каждый удар по пэду показывает высоту его сэмпла (нота, центы, Hz, имя пэда). Закрывают B1/B2/B3/Chop.
- Окно тюнера выглядит одинаково в Mixer (Input > ROUTE), Sample Record (B3) и режиме Sample.
- Sample Record: подпись «Tuner» опущена и больше не закрывает значок порога.
- На устройстве ещё не проверено: чтение PCM выбранного пэда на очереди модели (строки лога TUNER_SAMPLE) и результат на реальных сэмплах.
