# Проверка готовности r26x

[English](RELEASE_READINESS-r26x.md) · [Все замечания Leusha](TESTER_FEEDBACK_LEUSHA.ru.md) · [Известные проблемы](KNOWN_ISSUES.ru.md)

Дата: **2 ноября 2026**. **Стабильный релиз пока не готов: не все важные замечания закрыты.**
Публичный релиз — [r26s](https://github.com/AlekseyMalykh/am-mod/releases/tag/r26s).
Предыдущая сборка для теста — r26w; r26x — локальный кандидат с новыми
изменениями, ещё не опубликованный и не подтверждённый на MPC.

## Что считать исправлением

- **Подтверждено на MPC:** исправление крайних значений K в r26i; автор подтвердил,
  [#2 закрыто](https://github.com/AlekseyMalykh/am-mod/issues/2). Ранее автор подтвердил
  сохранение цвета при Sample playback, Leusha — различие Green/Cyan.
- **Реализовано и проверено автоматически:** перечисленные ниже изменения.
  Это не аппаратное подтверждение всех переходов и исходных сценариев Leusha.
- **Открыто / частично:** остаётся исходный сценарий или существенная проверка.
- **Предложение:** функции в коде нет либо выполнена только часть идеи.

В сводке Leusha сохранены 1–20,21a–d и дополнительный22: **25 строк учёта**,
среди которых есть вопросы, предложения и связанные случаи одной проблемы.
Все исходные формулировки и следующие проверки сохранены в подробной таблице.

| L08–L09, L22 | Реализованы цвета временных окон/компрессора, наследование Copy/Extract, Undo/Redo/rollback; исходные банковые сценарии и полный Save/Load на MPC ещё нужны |

## Что добавлено после публичной r26s

1. r26t–v: двойное мигание выбранных источников Batch Copy/Extract/Mono/Resample;
   выбранные свободные цели зелёные, занятые красные; невыбранные пустые погашены.
2. Default + пять цветов: Blue, Violet, Magenta, Orange, Pink; служебные оттенки
   исключены из нового назначения. Старые ID не перенумеровываются.
3. Белый/свой цвет по400мс для текущего Sample/Chop/Sound; серые вспышки записанных
   muted-событий при сохранении заглушённого звука.
4. r26w: Project → Pad Lighting, общий Standard / AM Mod с сохранением на SD;
   Mod Off — последний из семи пунктов в штатном окне на шесть строк.
5. Приоритет Note Repeat над компрессорными B1–B3, включая защёлкнутый overlay.
6. r26x: игнорирование отложенного paint скрытого Repeat, одно восстановление
   заголовка после закрытия; тест последующих кадров Type без цикла перерисовок.
   Это исправленный воспроизведённый путь в тесте, а не подтверждение исходного
   периодического мигания на MPC.
7. r26x: **Lights/Piano/Scale и музыкальные цвета 16 Levels доступны и в Standard**,
   включая тонику/лад/Transpose16/цвета ролей. Pad/Seq Colour в Standard отключены.

OptoCat/Warm и все предыдущие исправления сохранены. Gain −6…+6 dB; лапка и красная
GR-полоска получают одну фактическую редукцию, бантик — вход; сон скрывает шкалы/фон.
Переключение Type не включает оба алгоритма одновременно, Bypass общий.

## Проверки и их границы

ARM/QEMU normal/UBSan: K/FIFO/Scaled, native compressor factory/DSP/пainter,
палитры/управление/история Copy/Extract, EQ/штатные боковые шкалы,
восстановление проекта/выходная копия, штатный resample, настройки Pad Lighting
и реальная модель семи пунктов Project. Изменившиеся исходники проверяются по
SHA-256; сборка проверяет полный preload-конструктор поверх замороженных патчей.

Для r26x добавлены проверки скрытого Repeat paint, стабильной подписи Type,
доступа к Lights/Transpose16 в Standard и одинаковых Piano/Scale LED-значений
для обоих режимов. Участки native генератора, GUI и аудио в части тестов заменены
фикстурами. Это **не новый полный прогон native main, не реальный MPC и не проверка FAT32 на карте**.

## Обязательная приёмка перед стабильным релизом

| Проверка | Критерий закрытия |
|---|---|
| L01, две тестовые копии A/B и пустой stock | Правильные собственные ноты/секвенции/сэмплы/темп/микшер/FX после запуска и перезапуска; выбран ожидаемый сохранённый XPJ |
| L02–L03, Mod Off → stock → другой проект → перезапуск | Нет ошибок project/sample; пути выходной копии разрешаются, запись завершена |
| L04, обычный Save после каждого перехода | Понятные имя и путь, исходные A/B сохранны, выходная копия не подменяет обычный Save незаметно |
| OptoCat/New Project | Повторные New Project, оба типа, Warm/Bypass; нет сообщения о недоступном OptoCat |
| Note Repeat | Удержание/защёлка, быстрые отпускания, B1–B3 меняют скорости; Type не мигает и не меняется сам |
| Project/Pad Lighting | Все семь пунктов доступны прокруткой; Mod Off последний, Cancel работает; режим переживает перезапуск |
| 16 Levels | В Standard и AM Mod открываются Lights, Piano/Scale, транспонирование; сохранение XPJ сохраняет настройки |
| Рабочие палитры | Copy/Batch/Chop/Extract, банки, занятые/пустые цели, Undo/Redo, Mute; выбранное различимо; первый Chop проверен отдельно |

FAT32 остаётся **экспериментальным**: реализация есть с r26e и в публичной r26s,
но аппаратного подтверждения в доступных сообщениях нет. Закрытое
[#1](https://github.com/AlekseyMalykh/am-mod/issues/1) и успешное форматирование
в exFAT не доказывают запуск с FAT32. Это можно сохранить как явное ограничение
релиза для exFAT, не выдавая экспериментальную поддержку за подтверждённую.

После короткого аппаратного прогона можно отдельно рассмотреть **предрелиз**
с перечисленными открытыми пунктами. Публикация в этом аудите не выполнялась.
Публичный [закреплённый #3](https://github.com/AlekseyMalykh/am-mod/issues/3)
пока описывает r26s; его надо синхронизировать при публикации новой версии.

Ограничения: OptoCat сессионный; Internal временный; автозагрузка выбирает
самый свежий сохранённый XPJ, а не последний открытый; штатное пересохранение
может удалить расширение мода. Миграция Lights при переименовании и отдельные
служебные схемы Song/Loop не реализованы.
