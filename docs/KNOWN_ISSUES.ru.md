# Известные проблемы, проверки и пожелания

Обновлено **3 ноября 2026 года**. Подготовлен локальный предварительный **r27e**;
публичная стабильная версия — **r26s**. Доступные загрузки указаны в Releases.
[Полные изменения](RELEASE_NOTES-r27e.ru.md) · [Готовность](RELEASE_READINESS-r27e.ru.md) ·
[Настройки](MOD_SETTINGS.ru.md) · [Исходный список Leusha](TESTER_FEEDBACK_LEUSHA.ru.md).

«Реализовано» означает наличие изменения и указанного покрытия; это не закрывает
весь исходный аппаратный сценарий. В текущей версии Mod Off удалён: проверять
обычное выключение, сохранение на External и запуск stock без карты.

## Пожелания, не вошедшие в релиз

- Синт — **отложен по решению автора**, сейчас не реализуется.
- Экспорт стемов — не реализован; микшер и маршрутизация эффектов отдельно не спроектированы.
- L15: дополнительный вход в Key/Scale через Input Config.
- L17/L18: исследовать низкочастотную детализацию и яркость спектра без потери кривых.
- L21b: отдельный RGB-редактор; нынешний обмен палитры им не является.
- L21c/L21d: сменяемые персонажи и помощь с графикой; B2 Duck/OptoCat выбирает алгоритм, не независимую картинку.
- L14: инструкция Piano/Scale добавлена; [физический проход](FEATURES.ru.md#быстрый-вход-в-16-levels-pianoscale) ещё можно уточнить по отзывам.

Идеи C01/C02: живое изменение удерживаемых аккордов/арпеджио и динамика по силе нажатия — [отдельный план пожеланий](IDEAS.ru.md), не реализовано в r27e. Velocity новых ударов уже передаётся; непрерывный pressure ещё нужно исследовать.

## Ограничения

Автозагрузка выбирает самый свежий сохранённый SD XPJ, а не последний открытый.
Internal в моде временный. Stock может удалить необязательные поля мода при
пересохранении XPJ. Поддержка сброса K не охватывает штатные Duck/другие FX.
Новейшие курсоры и полный финальный пакет требуют аппаратного подтверждения;
полный запуск именно итогового r27e в VM не заявляется.
