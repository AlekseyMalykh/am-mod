# Готовность r27b

Релиз подготовлен локально, не опубликован. Пока остаются аппаратные сценарии,
публиковать как **prerelease**. Публичная r26s не менялась.

- Сборка, preload-конструкторы и нужные ARM/QEMU normal/UBSan проверки пройдены.
- About только информационный, пятый/последний; обе стороны кольца проверены.
- Версия/репозиторий едины для DRM-заставки, заставки приложения и About.
- На MPC подтверждены K и видимость r27a. Подписи r27b требуют аппаратной пробы.
- Точные хеши пакета/библиотеки/помощника и результаты VM хранятся в отчётах.
- L01–L04 не закрыты целиком. L06, L11, штатный Copy Shift+Bank и физическая
  FAT32 остаются открытыми; эмулятор не заменяет пользовательский сценарий.

До stable: читаемость r27b, A/B с разными нотами/темпом/сэмплами/эффектами/
настройками, выключение/восстановление, первый Save/Cancel/Review, недостающие
сэмплы, пустая карта, FAT32. Сделайте бэкап проектов/сэмплов.
[Изменения](RELEASE_NOTES-r27b.ru.md).
