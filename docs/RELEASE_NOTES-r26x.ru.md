# AM Mod r26x — локальный кандидат

[English](RELEASE_NOTES-r26x.md) · [Аудит готовности](RELEASE_READINESS-r26x.ru.md)

**Не опубликован.** Публичный ZIP остаётся r26s. r26x объединяет изменения
локальных r26t–w и следующие исправления; это не заявление об устранении всех багов.

- **Note Repeat / Type:** скрытый overlay больше не рисует заголовок и не отмечает
  себя активным. После закрытия заголовок компрессора восстанавливается один раз.
  Проверяются отложенный hidden paint и32 последующих кадра Type без цикла repaint;
  исходное периодическое мигание на MPC ещё нужно проверить.
- **16 Levels в Standard:** доступны Lights, Piano/Scale и музыкальная подсветка,
  тоника/лад/Transpose16/цвета ролей. Pad Colour/Seq Colour остаются отключены.
- Сохранены пять пользовательских цветов + Default, отдельные системные цвета,
  белый400/400мс курсор, двойные источники, выбранные зелёные/красные цели,
  погашенные пустые без выбора и серые вспышки muted-событий.
- Сохранены Standard/AM Mod, семь пунктов Project со штатным окном на шесть строк,
  Mod Off последним, приоритет Note Repeat B1–B3, OptoCat/Warm/GR/сон/общий Bypass,
  Gain −6…+6 dB, EQ и подтверждённое исправление K.
- README, обе версии FEATURES/KNOWN_ISSUES/FEEDBACK, таблица Leusha, карта цветов
  и CHANGELOG приведены к актуальным статусам. Благодарность Leusha за подробные
  тесты и идеи сохраняется; новые сообщения пользователям не отправлялись.

Автоматические ARM/QEMU normal/UBSan-проверки и SHA-256 относятся к указанным
границам и фикстурам, а не ко всему прибору. Новый полный запуск native main и
аппаратный тест r26x не выполнялись. [Обязательная приёмка и открытые P1](RELEASE_READINESS-r26x.ru.md#обязательная-приёмка-перед-стабильным-релизом).
FAT32 экспериментальный; exFAT поддерживается. Установка: полная `autorun` в корень SD,
проекты и сэмплы можно оставить. Для прошивки1.3.0.12.
