# AM Mod r27l

- Пока Mute в Steps удерживается или включён коротким нажатием, шаги с нотами для заглушения подсвечены системным зелёным, а полностью заглушённые шаги — системным красным. Шаг с обоими типами нот чередует эти цвета. Курсор и воспроизведение сохраняют цвета статуса.
- После выхода из Mute заглушённые шаги виднее на фоне пустых и по-прежнему дают серую вспышку при прохождении.
