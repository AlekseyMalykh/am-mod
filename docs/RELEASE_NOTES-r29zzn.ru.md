# r29zzn

- Тюнер стал окном на весь экран: ряд нот, прямая шкала ±50 центов с бегающей чертой, частота в Hz и найденная нота.
- Открывается из Mixer > Input > ROUTE (клик DATA на строке Tuner) и из Sample Record кнопкой B3. Закрывают B1 / DATA / B2 / B3.
- На устройстве ещё не проверено: определение высоты на реальном сигнале и частота перерисовки.
