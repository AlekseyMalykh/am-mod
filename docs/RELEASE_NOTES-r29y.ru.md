# r29y (тестовая сборка после r29k)

**Am MOD: ресемплинг одного пэда (Sample) теперь проходит через микшер.**

- Приватный рендер ноты использует тот же offline-путь микшера, что и стемы Song: фейдер/Mute/Solo трека, Track FX, посылы, Master FX и Pad Link влияют на результат. Стоковый FX Select игнорируется (как в r29k).
- Файлы стемов не создаются; в новый сэмпл штатным writer'ом записывается обработанный Master.
- Режим Stock не меняется (микшера нет, стоковый FX Select действует).
- Ресемплинг Seq в этой сборке не менялся.

## r29y
- Ресемплинг из экрана Sample: вопрос «Seq / Sample» убран, источник — выбранный пэд, сразу выбор целевого пэда.
- Ресемплинг секвенции в Am MOD: рендер идёт через Mixer (треки, Send, Track FX, Master FX), как Song-экспорт.
- Известные проблемы: режим передачи по USB недоступен, пока работает мод; чтобы вернуть Stock, удалите папку `autorun`.
