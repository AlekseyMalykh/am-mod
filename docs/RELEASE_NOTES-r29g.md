# r29g (research build after r29f)

Polls and logs the **stock Knob FX / FX Select screen** (`KNOBFX` lines in `MPC_CLONE_TRIAL.txt`): which memory words change when you pick an effect, toggle Bypass or select pads. It is used to find where the stock firmware keeps the chosen effect, its Bypass state and the target pads. Use it in **FX mode = Stock** (the stock screen is not shown in Am MOD). No audio or UI changes. Now polls the screen continuously (not only when it paints). Includes r29f.
