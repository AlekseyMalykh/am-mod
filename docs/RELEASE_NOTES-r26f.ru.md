# Кандидат r26f — быстрые повороты ручек

[English](RELEASE_NOTES-r26f.md) · Работа по [обращению #2](https://github.com/AlekseyMalykh/am-mod/issues/2).

После быстрого поворота K1/K2/K3 до упора значение могло оставаться промежуточным. В воспроизведённом сбое последнее значение проходило напрямую мимо переполненной очереди, затем старые движения перезаписывали его. Исправление сохраняет последние абсолютные положения ручек в порядке поступления; фокус остаётся на последней повёрнутой ручке.

Кнопки, пэды и относительные движения энкодера сохраняют порядок; движения ручек не объединяются через Shift/другие действия или смену владельца управления. Обработка физической Main Volume не менялась. Включена [экспериментальная поддержка FAT32 из r26e](RELEASE_NOTES-r26e.ru.md); exFAT по-прежнему поддерживается. Прошивка: **1.3.0.12**.

Проверки рабочего кода обработчика/очереди на ARM/QEMU воспроизвели старый сбой: вместо 0 оставалось 28. Исправление прошло быстрые потоки к минимуму/максимуму для K1/K2/K3, проверки заполнения/оборота кольцевой очереди, 50 000 конкурентных обновлений, маршруты ввода имён и ресэмплинга — обычно и с UBSan. Полный штатный загрузочный конструктор установил все 50 перехватчиков. Получатели параметров/аудио в тестах ввода заменены записывающими заглушками.

**Нужна проверка Warp на настоящем MPC.** Проверить резкие повороты к обоим упорам на Warp и других страницах, включая функции с Shift и смену выбранного пэда. Сам экран Warp и аппаратный АЦП этими тестами не проверялись. Кандидат не опубликован; автоматические тесты сами по себе не закрывают обращение.

Установить полную папку `autorun/` из кандидата или использовать установщик 1.0.2. Переносить проекты и сэмплы или переформатировать карту не требуется. Команды повторения проверок и сборки — в английской версии заметок.
