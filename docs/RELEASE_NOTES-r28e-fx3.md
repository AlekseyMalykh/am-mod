# Am MOD r28e-fx3 (diagnostic build, not for release)

r28e-fx2 plus extra logging on the Save Project / Save Sample screens (storage state, K3 and Save button), to find why Save Project can show only Internal. Behaviour is otherwise the same as r28e-fx2.

The log is written to `autorun/MPC_CLONE_TRIAL.txt` on the card (lines `SAVE_SCREEN`, `SAVE_K3`, `SAVE_BUTTON`).
