# r29zg

- Исправление (Save Project / Save Sample): сообщение «Insert SD card to save» появлялось случайно, даже когда карта вставлена, и в режиме Stock, и в Am MOD. Мод читал флаги внешнего хранилища окна Save не по тому смещению (0x11a0/0x11b8 вместо 0x10a0/0x10b8), поэтому видел произвольный байт, и при нулевом значении рисовал сообщение и перехватывал кнопку Save. Теперь используются правильные флаги. Строка `SAVE_SCREEN` в журнале дополнительно печатает старые смещения (`old_offsets=`) для сравнения.
- Включает r29zf (диагностика ресемплинга `RESAMPLE_MIX PROJECT` / `RESAMPLE_MIX BUSES`).
