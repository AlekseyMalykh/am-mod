# Исправление рабочей папки — r27f

Автор подтвердил исправление на MPC Sample в сборке r27e-workspace-fix1
3 ноября 2026 года. Исправление включено в публичную предварительную r27f.

## Подтверждённая причина отказа загрузки

В журнале MPC Sample от 3 ноября 2026 года все девять записанных попыток
импорта завершаются одинаково: исходный файл доступен, но целевая папка
`/data/TempProjects/Temp-Project_[ProjectData]/` отсутствует (`ENOENT`).
Это затронуло встроенные Drill-808-Knock1/2, Claps, FX, файлы SD и импорт
из другого проекта. Пользователь также сообщил об отказах Copy Pad,
рендера сэмплов и секвенций. После записи проверочной сборки автор подтвердил
устранение регрессии назначения на пэды.

Изменения курсора r27d/r27e читают штатный индекс выбранного пэда и меняют
подсветку; они не создают и не удаляют рабочие каталоги. Новый однократный
запуск с внешним проектом заменяет первый Load временного проекта. Теперь
он явно обеспечивает временный каталог до и после Load, при New Project
и при старте без загрузки проекта. Дополнительная загрузка проекта не нужна.

## Изменения

- Создание только штатных временных каталогов, если их нет.
- Сохранение существующих файлов, путей проекта и настроек автосохранения.
- Проверка каталога после штатной очистки при смене проекта.
- Отказ от использования символической ссылки или файла вместо каталога.
- Ограниченный журнал копирования сохранён для аппаратной проверки.
- OptoCat/Warm, курсоры, палитра и обработка K не изменены этим исправлением.

В r27f на заставке отображается `version: r27f`, в About — версия r27f.
Идентификатор установленной сборки также записан в MPC_MOD_VERSION.json.

## Что проверено

ARM64 и UBSan: отсутствие каталога воспроизводит отказ настоящего
File::copyFileTo из прошивки; после подготовки каталога тот же вызов
успешно копирует файл без изменения его содержимого. Проверены загрузка
проекта с очисткой временного каталога, последующая ручная загрузка,
New Project, старт без Load, сохранность готовых файлов и создание файла
результата рендера. Контейнер результата Load, исключения и исходное
автосохранение остаются под проверками. Это не заменяет тестов на MPC.

## Проверка на устройстве

1. После холодного запуска загрузить Drill-808-Knock1/2 из библиотеки.
2. Назначить другой сэмпл через поиск на пустой и занятый пэды.
3. Проверить обычный Copy Pad и Batch Copy.
4. Проверить Render Sound и Render Sequence с назначением на пустой пэд.
5. Создать New Project и повторить загрузку и Copy Pad сразу после открытия.
6. Загрузить сохранённый проект вручную и повторить загрузку сэмпла.
7. Сохранить проект и штатно выключить MPC; затем проверить восстановление.

Подтверждение получено; список полезен для дальнейших регрессионных проверок.
