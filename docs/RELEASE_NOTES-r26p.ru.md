# Кандидат r26p — повторная привязка компрессора и общий Bypass

[English](RELEASE_NOTES-r26p.md)

Исправлена найденная в r26o ошибка: после New Project новый мастер-процессор
Colour снова может получить OptoCat. Таблица перехватов создаётся один раз
и не перезаписывается. Старые вызовы остаются штатными, позднее удаление
старого экземпляра не отключает новый. Если аудиоблок ещё выполняется,
интерфейс повторяет попытку привязки без ожидания в аудиопотоке.
Тип и параметры OptoCat сохраняются в RAM при замене мастера.

B3 использует единый штатный параметр Bypass для Duck и OptoCat. Bypass
выключает оба, повторное нажатие включает только тип на текущей странице.
B2 при включённом Bypass меняет страницу без включения обработки.
Shift+Pad5 открывает работающий тип; если оба выключены — Duck с активным
Bypass. Настройка Warm сохраняется во время сна. Специальные параметры
OptoCat пока живут только в сессии; штатный Bypass следует состоянию проекта.
Все исправления r26o, Warm, графика, шкалы, ограничение +6 dB, K и цвета сохранены.

ARM/QEMU и UBSan проверяют реальную фабрику, обработку и удаление Colour,
четыре смены мастера, неизменность таблицы, старые вызовы и позднее удаление,
отказ от привязки внутри выполняющегося блока и успешный повтор, общий Bypass,
штатные изменения параметра и выбор страницы при открытии. Границы интерфейса
и событий проверены с тестовыми объектами. Проверка полного приложения и
физического MPC для New Project/Shift+Pad5/B3 ещё нужна. Локальная сборка.
