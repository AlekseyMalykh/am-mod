# r29j (тестовая сборка после r29i)

**Исправление: FX Select в Am MOD теперь действительно действует только на выделенные пэды.**

- r29i на устройстве не сработала: штатные маршруты выделенных и невыделенных пэдов оба указывают на другие буферы, поэтому проверка по «main» не совпадала. В r29j они различаются по id маршрута (выделенные: шина эффекта, невыделенные: основная шина).
- Если для FX Select выделена часть пэдов (в Stock, сохранено в проекте), эти пэды идут штатным путём (штатный эффект, затем Master), остальные через треки микшера. Если выделены все или ни одного, все пэды идут через микшер как раньше.
- Выделенные пэды обходят треки (метры, Track FX), пока выделены.
