# Кандидат r26r — лапка по сжатию и курсор Sound

[English](RELEASE_NOTES-r26r.md)

Бантик — входной сигнал, лапка — фактическое подавление компрессором.
Лапка, красная полоса и число GR теперь получают один снимок значения из DSP.
Чем сильнее подавление, тем дальше лапка; при постоянном сжатии она остаётся
прижатой, при восстановлении возвращается. Attack/Release уже действуют
в этой огибающей аудио: отдельной визуальной огибающей и запуска удара
по одному только входному уровню больше нет. Громкий вход без GR, Gain и Warm
сами по себе не двигают лапку. Для выразительности размах нелинейный
(1-exp(-GR/3)), красная шкала сохраняет размерность 0–60 dB.
Аудио DSP, предел усиления, графика и сон сохранены.

В Steps при удержании B1 Sound выбранный пэд чередует белый курсор 240 мс
и назначенный цвет 400 мс. Остальные пэды и выбор звука не меняются.
Для выбранного пустого слота белая фаза сохраняется; затем виден назначенный
цвет, если он есть, либо индикация пустого слота. Обычный курсор Steps не изменён.

ARM/QEMU и UBSan проверяют связь реального DSP Attack/Release с лапкой,
удержание GR, нулевую/некорректную GR, отсутствие ложного удара от громкого
входа/Ratio1/Gain/Warm, Bypass/графику, все 13 цветов/восемь банков и пустые
пэды в Sound. Пульсация Seq из r26q, K, Copy/Extract, общий Bypass и повторная
привязка мастера сохранены. Новые визуальные изменения ещё нужно проверить
в полном приложении/на MPC. Локальный кандидат, не опубликован.
