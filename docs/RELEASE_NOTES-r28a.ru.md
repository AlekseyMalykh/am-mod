# Am MOD r28a · экспериментальный релиз

Для Akai MPC Sample с прошивкой **1.3.0.12**. Дизайн микшера, редакторов эффектов и экспорта ещё будет дорабатываться. Перед обновлением сохраните резервную копию проектов и сэмплов. В установщике выберите `am-mod-r28a.zip` вручную. При ручной установке скопируйте полную папку `autorun/` из архива в корень SD-карты.

## Что нового

- Микшер с восемью треками A–H, Master, групповой регулировкой громкости, панорамой, мьютом, соло, посылами, именами треков и отменой изменений.
- До четырёх эффектов на трек или Master. В каталоге есть встроенные эффекты, трёхполосный Graphic EQ и Sidechain Compressor с выбором управляющего трека. Для каждого эффекта открывается редактор с собственным представлением сигнала.
- В Song появился экспорт стемов с эффектами микшера и без них. Все WAV начинаются с одной позиции. Полностью тихие дорожки пропускаются.
- В Project → Key / Scale / Tempo крутите K3 для изменения целых BPM и Shift + K3 для изменения сотых BPM.
- Стрелка вверх у подписи кноба отмечает дополнительный параметр под Shift. Запись автоматизации параметров остаётся в планах.

## Как пользоваться микшером

1. Нажмите **Pad FX + Knob FX** вместе. Пэды 1–8 выбирают треки A–H, пэд 16 выбирает Master. Удерживайте несколько пэдов или добавляйте треки через Shift + пэд, чтобы выбрать группу.
2. Для маршрутизации выберите трек и нажмите **Pad FX**. Нажмите пэд с загруженным звуком, чтобы назначить его на трек. Повторное нажатие возвращает звук напрямую на Master. Банки переключаются в окне назначения. Выходы A–H тоже идут на Master.
3. **K1** управляет панорамой, **K2** — уровнем посыла, **Shift + K2** — его назначением, **K3** — цветом трека. Буква под FX указывает назначение, красная шкала показывает входящий посыл на принимающем треке.
4. Групповой **фейдер** сначала подхватывает текущие уровни и затем сохраняет разницу в дБ. **Shift + фейдер** уравнивает уровни группы и двигает их вместе.
5. **B2** — Mute, **B3** — Solo. **Shift + B2** в общем окне открывает имя одного выбранного трека. K1 выбирает ввод энкодером или пэдами, B3 сохраняет. **Shift + − / +** отменяет или возвращает изменение.

## Как пользоваться эффектами

- Выберите один трек или Master и нажмите **Knob FX**. Поворот DATA выбирает слот, нажатие открывает эффект или каталог для первого свободного слота. Цветные пэды **9–12** открывают соответствующие слоты напрямую.
- В списке **B2** копирует эффект, **B3** вставляет его в выбранный слот. **Erase → B3** удаляет эффект с подтверждением. **Shift + поворот DATA** меняет местами соседние эффекты. **Shift + нажатие DATA** переключает обход эффекта.
- В редакторе **B1** возвращает к списку, **B2** переключает обход текущего эффекта. Дополнительные параметры доступны через **Shift + K1–K3**, а нажатие DATA переключает страницы, если их несколько.
- В **Graphic EQ** нажмите **Shift + B3**, чтобы добавить точку, и поворачивайте DATA для её выбора. Всего доступно до трёх точек.
- В **Sidechain Compressor** параметр **Key Track** задаёт управляющий трек, а белая метка на шкале Key показывает **Threshold** в dBFS. Красная шкала Send в редакторе показывает суммарный входящий посыл.

## Как экспортировать стемы

1. Откройте нужную песню в **Song**, нажмите **B1 Export**. Поверните DATA, выберите **Stems with FX** или **Stems without FX** и подтвердите **B3 Do It**.
2. Введите имя экспорта. В окне имени **K1** переключает ввод энкодером или пэдами. Подтвердите **Do It** и дождитесь окончания записи.
3. Рядом со штатным WAV микса появится одноимённая папка со стереофайлами WAV 24 бит. Дорожки называются `Имя - track A.wav` … `Имя - track H.wav`. Если напрямую на Master идёт слышимый сигнал, он записывается в `Имя - Master.wav`. Для повторного экспорта выберите новое имя папки.

Режим **without FX** отключает цепочки эффектов микшера при рендере стемов. Обработка самих пэдов сохраняется. Файл `Имя - Master.wav` содержит прямой сигнал Master, поэтому при сборке в DAW импортируйте его вместе с дорожками A–H с общей нулевой позиции. Штатный WAV полного микса можно использовать как референс.

## Исправления

- Удержание **Tap Tempo** в Sample и Seq сохраняет текущие цвета пэдов при включённой подсветке Am MOD.
- В Sample состояние трека видно по пэдам и волне. При Mute пэд чередует свой цвет с красным, при Solo — с зелёным. Звуки, исключённые чужим Solo, приглушены визуально.
- В **Sample → B1 Mix** снова видны **Pad Colour** и образец цвета. Крутите **K2 без Shift** при включённой подсветке Am MOD.
- В микшере пэды **9–12** ярко подсвечивают занятые слоты эффектов. Пустые слоты и все четыре пэда при групповом выборе серые.
- Кнобы OptoCat используют выбранный режим **Parameter Takeover** для обычных и Shift-параметров.
- Исправлены заголовок **Song**, шапка кнопок микшера и наложение подсказки DATA на каталог эффектов.
- Обработано подтверждение **B3** после **Erase + пэд** в Seq. В Steps номер страницы, позиция шага, позиция воспроизведения и Follow/Hold видны одновременно, в том числе при временном сообщении.

Целевые проверки микшера, эффектов, аудиомаршрутизации и строки состояния Steps прошли в ARM-эмуляторе. Полный тест Steps остановился на проверке цвета пэда в Mute. Итоговая сборка r28a ещё не проверена на физическом MPC.
