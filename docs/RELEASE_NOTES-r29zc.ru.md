# r29zc

- Подсветка пэдов: палитра Am MOD остаётся включённой, пока окно Sample закрыто штатным диалогом (прогресс ресемплинга и другие модальные окна) или Sample Record. Раньше пэды переключались на стоковые цвета.
- Диагностика: строки `INPUT_FX` в консольном логе показывают маршрут записи (точка, трек, Wet/Dry, готовность цепочек эффектов) и первые вызовы входного аудио. Нужны, чтобы найти, почему запись через Track/Master остаётся чистой.
- Включает r29zb (ресемплинг сэмпла сохраняет атаку).
