# Установка и обновление Am MOD r30c

[Главная](../README.ru.md) · [Руководство](USER_GUIDE.ru.md) · [English](INSTALL.md) · [Español](INSTALL.es.md)

## Подготовка

Нужен **Akai MPC Sample** с прошивкой **1.3.0.12** (на экране 1.3.0). Другие модели MPC и прошивки не поддерживаются. Скопируйте всю карту в резервную копию: прежде всего `MPC-Sample`, проекты, сэмплы и настройки. Рекомендуется exFAT. FAT32 экспериментален и не хранит файлы от 4 ГиБ. Имя тома — латиница/цифры без пробелов, например `MPC`.

Мод запускает копию приложения в RAM и не перепрошивает устройство. В кандидате r30c **проекты, сэмплы и аудиоэкспорты Internal постоянно хранятся во внутренней памяти**; остальные системные данные остаются изолированными. Штатная K3 выбирает Internal/External в окнах Save/Export. У старых SD-only пакетов сохраняются прежние ограничения. Штатная прошивка и старые моды могут потерять новые поля при пересохранении проекта; работайте с отдельной копией.

## Рекомендуется: установщик 1.4.0

1. Скачайте `am-mod-r30c.zip`, `MPC-Sample-Mod-Installer.exe` и `SHA256SUMS.txt` со [страницы r30c](https://github.com/AlekseyMalykh/am-mod/releases/tag/r30c). Для установщика ZIP распаковывать не нужно.
2. Сохраните текущий проект в External. Подключите карту через картридер или Project → SD Card Access. Для первой установки используйте штатное окно USB-накопителя или картридер.
3. Запустите установщик, выберите ZIP мода, обновите список карт и проверьте диск, имя и размер выбранной карты. Нажмите Install.
4. Установщик проверит пакет, распознает структуру ниже, сохранит предыдущий autorun в `~/AM-Mod-Backups/`, скопирует и сверит файлы. Это копия autorun, не проектов. Не отсоединяйте устройство во время записи.
5. Безопасно извлеките диск в ОС компьютера. В SD-окне AM Mod — B3 Disconnect, затем B3 Return; в штатной прошивке следуйте её инструкции отключения.
6. Выключите и включите MPC: копирование обновления не меняет уже запущенное приложение в RAM. В меню загрузчика выберите AM Mod. Проверьте r30c в **Project → Mod Settings → About**.

| Карта | Куда устанавливается AM | Что сохраняется |
|---|---|---|
| Обычная | `autorun/` | Проекты и сэмплы вне autorun |
| mpc-boot-thingy | `autorun/apps/am-mod/autorun/`, `boot.entry` в родительской папке | Меню загрузки и другие приложения |
| D.S.B Boot | `autorun/os/AM-Mod/` | Меню загрузки и другие системы |

Для D.S.B нужны обновлённый входной скрипт AM и `sampleboot.inplace`: не удаляйте этот маркер. Старый несовместимый пакет или неполная структура D.S.B отклоняются до записи. При наличии маркеров сразу двух загрузчиков установщик требует устранить неоднозначность.

Установщик поддерживает **уже установленный** загрузчик; D.S.B, mpc-boot-thingy и SampQOL он сам не скачивает и не устанавливает. Получайте их у авторов отдельно. Файлы SampQOL в ZIP AM не входят. Прямого выхода из AM в D.S.B в r30c пока нет.

## macOS / Linux и командная строка

Установите Python 3, возьмите `installer/mpc_mod_installer.py` из репозитория. Автоматическое распознавание карты такое же.

```bash
python3 installer/mpc_mod_installer.py cards
python3 installer/mpc_mod_installer.py install am-mod-r30c.zip --card /Volumes/MPC --dry-run
python3 installer/mpc_mod_installer.py install am-mod-r30c.zip --card /Volumes/MPC
python3 installer/mpc_mod_installer.py status --card /Volumes/MPC
```

В Windows вместо точки монтирования укажите `E:` — фактическую букву вашей карты; в Linux — её путь монтирования. Dry run ничего не записывает, status проверяет управляемые файлы установки. Графическому интерфейсу нужен Tk, CLI работает без него.

## Ручная установка

При выключенном MPC или безопасно подключённой к ПК карте сохраните старые файлы. На обычной карте замените **всю** папку `autorun/` папкой из ZIP. Не создавайте лишний уровень `autorun/autorun/`. Не смешивайте библиотеку одной версии с загрузчиком другой.

Для **D.S.B** скопируйте **содержимое** autorun из ZIP в `autorun/os/AM-Mod/`, сохранив `sampleboot.inplace`. Для **mpc-boot-thingy** предпочтителен установщик: он одновременно создаёт вложенный autorun и boot.entry. Не заменяйте корневой autorun загрузчика папкой AM.

## Обновление, удаление, восстановление

- Обновляйте тем же способом: установщик снова распознает загрузчик. После извлечения диска перезапустите MPC.
- Удаление установленного этим инструментом AM: `python3 installer/mpc_mod_installer.py remove --card /Volumes/MPC`. В режиме меню удаляются управляемые файлы AM; загрузчик и другие системы сохраняются. Резервные копии остаются.
- Аварийный запуск штатной системы: выключите MPC и извлеките карту мода. Чтобы использовать карту в Stock, отключите/переименуйте её autorun на компьютере. На карте с загрузчиком удобнее выбрать Stock в его меню.
- Для отката восстановите полный подходящий autorun из резервной копии при выключенном MPC. Не смешивайте версии. При необходимости восстановите отдельную копию проектов.
- Если запуск не удался: проверьте прошивку, имя тома, файловую систему, вложенность папок и полноту распаковки. Укажите версию, загрузчик и шаги; диагностический отчёт можно подготовить установщиком. Не прикладывайте личные проекты без намерения ими поделиться.

## Первая проба

Откройте копию небольшого проекта. Сыграйте пэд, откройте микшер, измените и обойдите эффект. Через K3 сохраните в Internal и External, затем полностью перезапустите MPC и загрузите проекты. Проверьте также сохранённый сэмпл и аудиоэкспорт. MIDI, импорт и Sample Swap пробуйте отдельно. Финальный пакет и сторонние загрузчики ещё требуют аппаратных проверок.
