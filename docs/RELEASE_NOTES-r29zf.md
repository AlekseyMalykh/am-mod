# r29zf

- Diagnostics only (no behaviour change): the `RESAMPLE_MIX PROJECT` line lists the Solo/Mute masks, every track send (`track>destination@level`) and the pad output; the `RESAMPLE_MIX BUSES` line lists the peak of every Track bus A-H and Direct in the first blocks of a resample. Used to find why a pad resample is silent when a send destination track is soloed.
- Includes r29ze.
