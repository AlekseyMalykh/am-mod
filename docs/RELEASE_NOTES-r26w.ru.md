# Кандидат r26w — Standard / AM Mod и Note Repeat

Локальная проверочная сборка на основе r26v. Не опубликована.

## Project → Pad Lighting

Два режима общей подсветки:

- **AM Mod** — текущая схема: пять назначаемых цветов, мигающие курсоры,
  красные/зелёные выбранные цели, серые вспышки Mute, музыкальный ритм Seq.
- **Standard** — штатные RGB-значения в Sample, обычном Chop, Copy/браузере,
  Seq и живых штатных 16 Levels. Mod-цвета и дополнительные playback-вспышки
  не перекрашивают эти окна. Pad Colour, Seq Colour и страница пользовательских
  Lights не перехватывают управление.

У новых функций нет официального аналога. Их Standard — фиксированная палитра:
в Steps события синие, Mute красный, playhead зелёный; курсор белый.
Batch/Mono/Resample используют фиксированные источники/цели, без назначенных
цветов сэмплов. Музыкальные раскладки мода сохраняют функции и фиксированные
обозначения; пользовательские цветовые модификаторы Lights не применяются.

B2 выбирает Standard, B3 — AM Mod; K1/энкодер тоже меняют режим. B1 возвращает
в Project. Настройка действует на все проекты этой установки на SD; загруженный
или новый проект её не сбрасывает. Отдельный скрытый файл
`MPC-Sample/Projects/.am-mod-pad-lighting` сохраняется атомарной заменой.
По умолчанию AM Mod. При ошибке записи предыдущее значение сохраняется и
показывается ошибка; без доступного каталога SD — явно отмеченный Session only.

Назначенные цвета и музыкальные настройки остаются в проекте. Возврат в AM Mod
восстанавливает их отображение. Настройка не меняет ноты, pitch, транспозицию,
компрессоры, аудио или данные проекта.

## Project: порядок и прокрутка

1. Load Project
2. Save Project
3. New Project
4. SD Card Access
5. Key / Scale
6. Pad Lighting
7. **Mod Off**

Сохраняется штатный Menu/ListBox с окном на шесть строк и штатной навигацией,
семь элементов находятся в модели; последний пункт доступен при прокрутке.
Новый payload меню собирается из собственного `project.S`; исходный шестистрочный
payload проверяется побайтно. Изменение применяется только в RAM-копии при
загрузке библиотеки до native main. Прошивка устройства не переписывается.

## Note Repeat поверх компрессора

B1/B2/B3 принадлежат Note Repeat, когда его окно открыто: B2 выбирает скорость,
а не Duck/OptoCat. Проверяется и удержание кнопки, и видимость оставленного
открытым штатного окна. Состояние Repeat сохраняется в билете события, чтобы
быстрое отпускание не меняло назначение уже поставленной в очередь кнопки.
Заголовок Type/Warm не рисуется поверх скоростей. Пары press/release уже начатой
команды сохраняют владельца; освобождение памяти окна снимает его состояние.

## Проверки

ARM/QEMU/UBSan: сохранение общей настройки, смена/сброс проекта, неизменность
цветовых данных и pitch/transpose, восстановление штатного RGB и обратный переход,
Project-контролы, native deep-copy/разрушение семи строк на двух PIE-базах,
Mod Off последним, шесть видимых строк и tagged dispatch. Отдельно проверены
Note Repeat B1–B3 и быстрый release для обоих компрессоров, прежние DSP/метры,
K, Copy/Extract/Undo/Redo, EQ и полный preload constructor.

Новая прокрутка и переключение на физическом MPC ожидают аппаратного теста.
Проверка native-модели/лимита строк не заменяет визуального теста всего окна.
Полное объединённое приложение в VM этой сборкой не запускалось.
