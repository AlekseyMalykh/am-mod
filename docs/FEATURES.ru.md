# Функции AM Mod

[English](FEATURES.md) · **Русский**

Локальный кандидат **r26x**, 2 ноября 2026; публичный ZIP — **r26s**. Прошивка MPC Sample **1.3.0.12**.

**Статусы:**
- **Подтверждено** — проверено на настоящем MPC Sample.
- **Проба** — указанные автоматические проверки пройдены; аппаратная проверка уточняется отдельно.

Подтверждение относится к конкретной пробе, а не ко всем сочетаниям функций в последующих сборках. История по сборкам — в [CHANGELOG](../CHANGELOG.md).

Обозначения: **B1–B3** — три кнопки над экраном, **K1–K3** — три ручки под экраном, «энкодер» — большое колесо DATA.

## Кандидат r26x — ещё не опубликован

Публичный ZIP — **r26s**. Описание новых режимов ниже относится
к локальному кандидату **r26x**, а не к этому архиву.
[Проверка готовности и оставшиеся задачи](RELEASE_READINESS-r26x.ru.md).

- **Project → Pad Lighting:** Standard / AM Mod, общая настройка на SD.
  В Standard отключены Pad Colour/Seq Colour; **16 Levels Lights с Piano/Scale,
  тоникой, ладом и Transpose16 доступны в обоих режимах**.
- AM Mod: **Default + пять цветов** — Blue, Violet, Magenta, Orange, Pink.
  Красный, зелёный, белый, янтарный, cyan и серый оставлены служебным состояниям.
  Старые назначения читаются без перенумерации и не стираются переключением режима.
- В Sample/Chop/Sound текущий пэд чередует белый курсор и свой цвет по 400 мс.
  Источники Batch выделяются двойной белой вспышкой. Пустые невыбранные цели
  погашены; выбранная свободная цель зелёная, занятая красная.
- Записанные события заглушённых звуков вызывают серые вспышки без звука.
- Mod Off — последний из семи пунктов Project; сохранено штатное окно на шесть строк.
  Note Repeat имеет приоритет над B1–B3 компрессора. Исправлен путь скрытой
  перерисовки Repeat, способный вызывать мигание Type после отпускания.
- Сохранены OptoCat/Warm, Gain −6…+6 dB, Shift Attack/Release/Knee, лапка по GR,
  боковые шкалы EQ, подтверждённое исправление K и экспериментальный FAT32.

Новые изменения проверяются автоматически; проверка на MPC указана отдельно.
**L01–L04 (загрузка проектов, Mod Off, пути сэмплов и обычный Save) остаются
открытыми для полной проверки. Стабильный релиз пока не готов.**
История опубликованных сборок: [CHANGELOG](../CHANGELOG.md),
[изменения r26s](RELEASE_NOTES-r26s.ru.md).

## 1. Запуск, выход и сохранение

| Функция | Статус |
|---|---|
| Запуск с SD через штатный механизм autorun. Мод проверяет SHA-256 штатного приложения и своих файлов и запускает изменённую копию приложения в RAM. Прошивка и загрузчик не перезаписываются | подтверждено |
| Запуск при вставке карты в работающий MPC и загрузка MPC с уже вставленной картой | подтверждено (r23a) |
| При запуске штатное приложение закрывается: экран и пэды на несколько секунд гаснут, затем появляется мод. То же при Mod Off. В это время не выключайте MPC и не вынимайте карту | ожидаемое поведение |
| **Project → Mod Off** — последний пункт меню Project (вход: Shift+пэд 16), с подтверждением: B1 Cancel, B3 Mod Off | подтверждено |
| При Mod Off мод сохраняет отдельную копию проекта со сэмплами в `MPC-Sample/Projects/Mod-Exit-Last.xpj` + `Mod-Exit-Last_[ProjectData]`, затем возвращает штатное приложение. При ошибке записи мод не выключается: доступны Back и Retry | подтверждено |
| **Кнопка питания** (короткое нажатие): штатный вопрос → копия проекта на SD (экран *Saving project copy*) → выключение | подтверждено (r23) |
| Сохранение проектов и сэмплов на **External** (`MPC-Sample/Projects`, `MPC-Sample/Samples`, включая подпапки); такие файлы открываются штатным приложением | подтверждено |
| **Internal** внутри мода временный: всё, что сохранено туда, пропадает после выхода из мода | — |
| Браузер подписывает накопитель по фактической папке: SD или Internal RAM | подтверждено |
| Настройки мода (Orig Note, Lights, цвета секвенций и др.) хранятся в дополнительном поле проекта XPJ. Штатное приложение его игнорирует, а при пересохранении проекта удаляет | подтверждено (Orig Note, r23a) |

Автозагрузка выбирает самый свежий сохранённый XPJ в Projects на SD или на один
уровень глубже по времени изменения файла, а не по истории ручных открытий.
Выходная копия заменяет предыдущую Mod-Exit-Last после успешного сохранения.
Незакрытые сценарии переходов/Save перечислены в [L01–L04](KNOWN_ISSUES.ru.md).

## 2. Интерфейс

| Функция | Статус |
|---|---|
| **Нижняя панель K1–K3**: название параметра и значение видны всегда, по центру, на чёрном фоне. У выбранного поля янтарные название, значение, рамка и шкала. Непрерывные параметры показаны полосой, переключатели — сегментами | подтверждено |
| Понятные подписи вместо внутренних имён: **Length**, **Q**, **Time Sig** | подтверждено |
| Отметки **S в рамке** рядом с параметрами, которые меняются с Shift: белая, при нажатом Shift — красная. Например, в Sample → Mix под Shift на K2 появляется **Kit Volume** | подтверждено |
| Замок Loop отодвинут к правому краю K3 | подтверждено |
| **Верхние кнопки и вкладки**: единый чёрный фон, центрированные подписи, компактные индикаторы страниц (выбранная — янтарная). Группы вкладок отличаются от одиночных действий | проба (охват всех экранов) |
| Окна подтверждения показывают настоящие подписи ответов вместо внутренних `Answer1 / Answer2` | подтверждено |
| **Note Repeat** и **Knob FX**: янтарная верхняя панель с чёрными подписями; у Knob FX янтарный фон K1–K3 | проба |
| **Pan** и другие диапазоны, симметричные относительно нуля (Tune), заполняются от отметки в центре влево или вправо | проба (r24q) |
| **Окна мода** (Chords, Steps, меню Edit в Steps, Stereo → Mono, Resample) в одном блочном стиле: блоки B1–B3 сверху, информационные блоки, сетка 4×4 по раскладке пэдов | проба (r24s) |

**Текущая схема r26x.** Исторические подтверждения функций ниже не означают
проверку всех новых сочетаний. Полная [карта режимов](PAD_LIGHTING_MAP.ru.md)
содержит также предложения; реализованная часть перечислена здесь.

**Project → Pad Lighting:** Standard / AM Mod. Настройка общая, сохраняется на SD
отдельно от XPJ. Standard оставляет штатные цвета штатных экранов и фиксированные
цвета новых окон. Pad Colour/Seq Colour не редактируются и не применяются;
их сохранённые назначения остаются. **Музыкальные раскладки Lights для 16 Levels
Tune (Piano/Scale, тоника, лад, Transpose16 и цвета групп) доступны в обоих режимах.**
Mod Off остаётся последним пунктом Project; семь пунктов помещены в штатное окно
на шесть видимых строк. Полную прокрутку ещё нужно проверить на MPC.

| Состояние в AM Mod | Индикация |
|---|---|
| Назначенный цвет звука/секвенции | Default + Blue, Violet, Magenta, Orange, Pink; старые ID сохраняются, служебные оттенки отображаются через безопасное соответствие |
| Текущий пэд Sample/Chop или Sound в Steps | 400 мс яркий белый / 400 мс свой приглушённый цвет |
| Выбранные источники Copy/Batch Extract/Mono/Resample | Двойная короткая белая вспышка поверх цвета источника |
| Пустая цель без назначения/выбора | Погашена |
| Занятый пэд вне выбранных целей | Приглушённый собственный цвет |
| Назначенная или текущая свободная цель | Зелёная; текущая дополнительно пульсирует яркостью |
| Назначенная или текущая занятая цель | Красная; текущая дополнительно пульсирует яркостью |
| Удаление / перезапись | Красный служебный сигнал, подтверждение операции сохраняется |
| Mute / событие заглушённого звука | Приглушённый серый / серая вспышка события без включения звука |
| Шаги | Цвет звука (Default — синий), белый курсор, cyan playhead, серый Mute; в Standard — синий, белый, зелёный playhead, красный Mute |
| Seq в AM Mod | Выбранная при Stop — раз в такт, играющая — по долям, очередь — вдвое чаще; фон и остальные занятые пэды не гаснут |

Системные цвета нельзя выбрать как новые Pad Colour/Seq Colour.
Музыкальные роли Lights/Chords и клавиатура текста имеют отдельные палитры.
Отдельные новые служебные маркеры Loop/Song остаются предложениями.

В AM Mod цвет задаётся через **Sample → B1 Mix → K2 Pad Colour без Shift**.
Нажатия энкодера перебирают Volume → Pad Colour → Pan. **K1 остаётся Volume**,
**Shift+K2 — Kit Volume**. Standard убирает дополнительный параметр Pad Colour.

## 3. Ввод имён пэдами

Работает в окнах Save Project / Save Sample и в поиске. **K1** переключает Encoder / Pads, введённый текст при этом сохраняется. Основная клавиатура подтверждена на устройстве.

| Пэд | Буквы | Цифры |
|---|---|---|
| 13 | `_` | 1 |
| 14 / 15 | ABC / DEF | 2 / 3 |
| 9 / 10 / 11 | GHI / JKL / MNO | 4 / 5 / 6 |
| 5 / 6 / 7 | PQRS / TUV / WXYZ | 7 / 8 / 9 |
| 2 | пробел | 0 |
| 1 / 3 | курсор влево / вправо | |
| 4 | буквы ↔ цифры | |
| 8 | перебор `. - _ #` | |
| 12 | верхний регистр, пока удерживается | |
| 16 | Backspace (удалить слева); **Shift+16** — Delete (удалить справа) | |

- Повторные нажатия одного пэда перебирают буквы. Другой пэд или пауза больше 1 секунды фиксирует букву.
- Энкодер и +/− двигают тот же курсор, место вставки показано чертой `|`, которая в имя не попадает.
- Цвета: буквы белые, цифры зелёные, символы янтарные, регистр фиолетовый, удаление красное.
- Только латиница.

## 4. Исходная нота, тональность и Lights

| Функция | Где | Статус |
|---|---|---|
| **Orig Note** — исходная нота сэмпла (C…B или `--`). Только отметка, звук не меняет. Semi Tune показывает полутоны и название получившейся ноты | Sample → Tune → Shift+K1 | подтверждено, включая сохранение (r23a) |
| **Key / Scale** проекта: K1 — тоника, K2 — лад (Major, Natural Minor, Dorian, Phrygian, Lydian, Mixolydian, Locrian, Chromatic) | Project → Key / Scale | подтверждено |
| **Lights** — подсветка пэдов 16 Levels Tune по нотам | Sample → B2: Tune → Play → **Lights** | частично подтверждено |

Lights: обычно K1 — режим, K2 — тоника, K3 — лад; с Shift K1 — Transpose16, K2 — цветовая группа, K3 — её цвет.
- Режимы: **Monochrome** (штатные цвета), **Piano** (белые и чёрные клавиши), **Scale** (тоника / ноты лада / вне лада). Старые значения Tonic/Degrees читаются как Scale.
- Тоника и лад наследуются от проекта (подпись **(P)**) или задаются для звука отдельно. 12 цветов, включая Off; исходная высота сэмпла выделяется отдельным цветом.
- **Transpose16 −24…+24** сдвигает раскладку 16 Levels Tune, не трогая обычное воспроизведение пэда.
- Цвета учитывают Orig Note, Semi Tune, номер пэда и Transpose16. Без Orig Note используются штатные цвета.
- Lights действуют и в редакторе Tune-событий из Events и Steps (см. §9).

### Быстрый вход в 16 Levels Piano/Scale

1. Выберите звук и задайте **Sample → Tune → Shift+K1 → Orig Note**.
2. При необходимости задайте **Project → Key / Scale**.
3. На Sample нажимайте **B2: Tune → Play → Lights**; K1 выбирает Piano/Scale,
   K2 — тонику, K3 — лад. `(P)` означает наследование настройки проекта.
4. Включите **16 Levels**, через **Shift+16 Levels → Type** выберите **Tune**.
5. На Lights **Shift+K1 → Transpose16** сдвигает раскладку. Lights работают
   при Standard и AM Mod. Monochrome или отсутствие Orig Note оставляют штатные цвета.

Инструкция сверена с кодом; полный проход по физическим кнопкам ещё ожидает проверки.

## 5. Chords

**Статус: проба (r24v).** Режим аккордов поверх 16 Levels Tune.

1. Выберите мелодический сэмпл, задайте ему **Orig Note**; при входе в Chords Play переключается в **Poly** автоматически.
2. Тональность берётся из Key / Scale проекта или из Lights звука.
3. Включите **16 Levels → Tune** и нажмите **Chop**. Выход — **B1 Back** или повторный Chop.

| Пэды | Функция | Цвет |
|---|---|---|
| 1–8 | восемь ступеней лада (тоники) | зелёный |
| 9 / 10 / 11 / 12 | добавки 6 / 7 / maj7 / 9 | янтарный |
| 13 / 14 / 15 / 16 | Maj / Min / Dim / Aug; 13+14 = Sus4 | голубой |

- **K1** — октава −2…+2. **K2** — обращение −3…+3. **K3** — арпеджиатор: Off, Up, Down, Up-Down, Up-Down+, Random, As Played, Chord. **Shift+K3** — скорость арпеджио 1/4, 1/8, 1/8T, 1/16, 1/16T, 1/32; **Shift+K1** — диапазон 1–2 октавы. **B3** — Latch, **B2** — сброс. Клик энкодера выбирает параметр.
- При каждом входе арпеджиатор выключен (**Off**); при включении начинает с 1/4. Он идёт в темпе проекта и играет, только пока удерживаются тоники.
- Удержание **Note Repeat** повторяет удерживаемый аккорд целиком со скоростью штатного Note Repeat (1/16, пока не выбрана другая).
- **Knob FX** работает как обычно: пока он включён, K1–K3 управляют штатными эффектами.
- Экран повторяет пэды: название аккорда с добавками, его ноты, сэмпл и тональность, затем сетка 4×4 (типы белые, добавки янтарные, тоники зелёные, последняя тоника в рамке).
- Tap Tempo работает внутри Chords; SEQ, Sample и другие кнопки режимов выходят из него.
- При Latch On выбранный тип аккорда сохраняется после отпускания, добавки включаются и выключаются нажатием. При Latch Off работают, пока удерживаются.
- Seq Record + Play записывает каждую ноту аккорда отдельным обычным событием Tune, которое потом можно править в Events и Steps.
- Октава, обращение, Latch и арпеджиатор сбрасываются при новом входе и в проект не сохраняются.
- Двойное нажатие Stop во время воспроизведения безопасно глушит все голоса (исправлено в r24f).

Схема типов и добавок вдохновлена [ChoralRoot FM-1](https://github.com/Quixotic7/ChoralRootFM1); его код не использовался.

## 6. Запись аккордов (Poly)

| Функция | Статус |
|---|---|
| В 16 Levels → Tune при Poly несколько одновременно нажатых пэдов записываются **отдельными событиями** со своими высотой, velocity и длительностью, в том числе при отпускании в обратном порядке. Формат проекта штатный | подтверждено (r23a) |

## 7. Steps — шаговый секвенсор на пэдах

**Вход:** Shift+SEQ → B2 Steps. **Возврат:** B2 Events. Работает с событиями той же секвенции, что и штатный Step Edit. **Статус:** основная работа подтверждена.

- 16 шагов выбранного звука на пэдах. Порядок по времени: 13–16 → 9–12 → 5–8 → 1–4.
- +/− листают страницы, энкодер выбирает шаг. Shift+энкодер сдвигает события выбранного звука по сетке; на границе секвенции переходит по кругу.
- **K1 Sound**, **K2 Grid** (1/4…1/64 и триоли через Shift+K2), **K3 Velocity**; Shift+K1 — банк.
- **B1 Sound + пэд** беззвучно выбирает звук. Пока Sound удерживается, выбранный пэд чередует белый курсор и назначенный цвет (r26r, включено в r26s).
- **SEQ RECORD** включает локальный WRITE: при OFF пэд выбирает шаг, при ON добавляет ноту в пустой шаг. Работает и в Stop, и в Play.
- **Erase+пэд** удаляет события выбранного звука на шаге одной командой Undo.
- **B3 Edit** — Copy / Paste / Paste to Pad / Note Length. **Shift+B2** — Follow / Hold страницы воспроизведения.
- **Mute**: удерживать и нажимать шаги или коротким нажатием закрепить режим. **Shift+Mute** снимает заглушение со всего звука.
- **Shift+K3 Other Sounds** — тусклая отметка шагов, где есть события других звуков. Клик энкодера прячет и показывает курсор.
- Метки **C / L** у шага и подсветка кнопки Chop / 16 Levels открывают редактор события (§9). На пустом шаге при WRITE ON 16 Levels открывает набор нот.
- Схема Steps соответствует §2: цвет выбранного звука, пустые шаги погашены, Other Sounds — слабый белый фон; курсор/воспроизведение/Mute зависят от Pad Lighting.
- На экране те же 16 шагов показаны сеткой 4×4: рамка, заливка, номера и данные событий согласованы с физическими пэдами. Клик энкодера скрывает и показывает курсор вместе с рамкой.

## 8. Events / Step Edit

| Функция | Статус |
|---|---|

## 9. Редактор события Chop / 16 Levels

Если у выбранного события есть отметка C или L, соответствующая кнопка Chop или 16 Levels подсвечивается и открывает окно выбора. Работает из Events и из Steps; если подходящих событий на шаге несколько, сначала показывается их список.

| Функция | Статус |
|---|---|
| Пэды выбирают вариант (срез, ноту, значение). **B3 Apply** применяет, B1/B2 отменяют. До Apply событие не меняется | подтверждено (r16b) |
| Прослушивание выбранного варианта; исходное событие на время редактирования молчит, остальные играют | L подтверждено (r16c), C — проба |
| Исходный вариант отмечен янтарным, выбранный белым | подтверждено |
| Типы Levels: Velocity, Tune, Filter, Layer, Attack, Decay, Probability, Ratchet, Slice, Articulation; Tune листается по октавам | подтверждено |
| **Несколько нот в Tune**: пэды добавляют и убирают ноты (до 16); Apply заменяет событие отдельными событиями одной командой Undo | проба (r21) |
| Цвета Lights звука в редакторе Tune | проба |

## 11. Браузер, поиск и предпрослушивание

**Поиск:** Sample Select / Open Project → **Shift+B3 Search**. Запрос вводится пэдами, энкодером и +/−. B2 переключает ввод и результаты, B1 закрывает поиск. **Статус:** поиск в текущей папке подтверждён, остальное — проба.

- Область поиска: **Folder / Subfolders / Library** и накопитель (Current / Internal / SD Card) — K3 или Shift+K3.
- Без учёта регистра. Сэмплы: WAV, AIF/AIFF, MP3, FLAC, OGG. Проекты: XPJ. До 4096 совпадений.
- Сэмплы: пэд беззвучно выбирает место загрузки, **клик энкодера загружает**, оставаясь в поиске. **B3 Preview** включает автопрослушивание при прокрутке. **Shift+клик** открывает папку файла и выделяет его. Пэды — по текущей схеме §2: выбранная свободная цель зелёная, занятая красная; пустые без выбора погашены, остальные занятые сохраняют приглушённый цвет.
- Проекты: клик показывает подтверждение открытия (B3 Open / B1 Cancel).
- **K3 Preview Vol 0–100 %** — громкость предпрослушивания относительно Main Volume. Показывается только на выбранном аудиофайле.
- **Erase** на аудиофайле в `Samples/User` вызывает штатный Delete со штатным подтверждением.
- В **Open Project** физическая **Erase** удаляет выбранный XPJ вместе с
  папкой `_[ProjectData]` после подтверждения. Для папки проекта или отдельной
  `_[ProjectData]` вопрос **B1 Cancel / B3 Delete** подтверждает удаление папки
  вместе с сэмплами; отменить результат нельзя. В L05 оставлен исходный случай
  недоступного удаления в браузере/поиске, которому нужна проверка на приборе.

## 12. Batch Copy

**Вход:** Sample → Shift+Erase → B2 Batch. **Статус:** подтверждено (r14e).

- До 16 исходных пэдов из любых банков; таблица **Source → Destination**.
- **K1** — авто-банк. **K2** — авто или конкретный пэд. **K3** — First free / Same pad / Bank free. Ручные цели задаются Shift+K1/K2 или пэдами, Erase возвращает строку к Auto.
- **Shift+K3** — Sound only / **Sound + events**: события звука копируются во всех секвенциях (проба, r15e).
- Занятые цели помечены `!`. B3 показывает число копий и перезаписей, повторное B3 подтверждает.
- Клик энкодера прослушивает источник строки. Вся операция отменяется одним Undo.
- Цвета пэдов — по текущей схеме §2: выбранные источники с двойной белой вспышкой, назначенные свободные цели зелёные, занятые красные; пустые без выбора погашены.

## 13. Batch Extract

**Вход:** обычный Chop с волной и срезами → удерживать Shift → **B2 Batch**. Shift+B1 — штатный Extract, Shift+B3 — Split. **Статус:** подтверждено на устройстве (r15c: три сэмпла с верным числом кадров).

- Выбор 1–16 чопов, таблица **C001 → B01** с теми же правилами целей, что в Batch Copy.
- Создаются отдельные обрезанные сэмплы `Chop-A01-001`… и назначаются на цели. Общий Undo; при ошибке выполняется откат.
- Клик энкодера прослушивает чоп, повторный останавливает.

## 14. Stereo → Mono

**Вход:** Sample → **Shift+B3**. **Статус:** проба (r21a/r21d).

- Пэд выбирает место результата, K1 или Bank — банк. **B1 Cancel**, **B2 Left**, **B3 Right**.
- Выбранный канал всего сэмпла становится отдельным моно-сэмплом с настройками исходного. Занятую цель нужно подтвердить повторно. Один Undo.
- На экране блоки Source и Target; цель краснеет, если перезапишет звук.

## 15. EQ пэда

**Вход:** Sample → B3: **Filter → Filter Env → EQ**. **Статус:** звучание подтверждено (r19c).

| Управление | Функция |
|---|---|
| K1 | Freq |
| K2 | Gain ±18 дБ |
| Shift+K2 | Q |
| K3 | Bypass, Bell, Low Pass, High Pass, Notch, Low Shelf, High Shelf |
| клик энкодера | выбор параметра (с Shift — в обратном порядке) |

На экране показана АЧХ. Для Low Pass, High Pass и Notch вместо Gain показано `--`.

**Спектр выбранного пэда** (БПФ на 4096 точек, 20 Гц–20 кГц) доступен на всех страницах Sample B3: **Filter → Filter Env → EQ**. В EQ приглушённые янтарные столбцы рисуются за кривой; в Filter и Filter Env отключена только волна, а штатные кривые фильтра/огибающей и регуляторы сохраняются; спектр рисуется приглушённым полупрозрачным фоном. После остановки звука спектр плавно опадает.

## 16. Ресэмплинг

**Вход:** Sample → **Shift+пэд 11**: B1 Cancel, **B2 Seq** (штатный ресэмплинг секвенции), **B3 Sample** (выбранный пэд со своей обработкой).

| Функция | Статус |
|---|---|
| Рендер выбранного пэда с его настройками и FX на выбранный пэд: Loop временно проигрывается один раз, хвост дозвучивает. Тихий или ошибочный результат на пэд не назначается | подтверждено (r20g) |
| Учитываются прямые Pad Link исходного пэда и состояние Bypass | подтверждено (r23a) |
| Выбор цели по §2: свободная выбранная зелёная, занятая красная, пустые без выбора погашены. Имя результата: «имя Resample» | рендер подтверждён; новая подсветка — проба |
| На странице цели показаны источник и банк сеткой 4×4; цвета и выделение соответствуют §2 | проба r26x |

## 17. Ограничения

- Только прошивка **1.3.0.12**: на любой другой версии мод не запустится.
- Internal внутри мода временный; работайте с External.
- Штатное приложение не читает настройки мода в проекте и удаляет их при пересохранении. Музыкальное содержимое проекта при этом не теряется.
- Автоматическая миграция привязанных к имени настроек Lights при переименовании сэмпла не реализована. Это отдельно от реализованного наследования Pad Colour/EQ в Copy/Extract с Undo/Redo.
- Проверка в эмуляторе не заменяет проверку на устройстве: тайминги, звук, батарея и USB-аудио там другие.
- Быстрое арпеджио на медленной карте может вызвать штатное сообщение *Disk too slow*.
