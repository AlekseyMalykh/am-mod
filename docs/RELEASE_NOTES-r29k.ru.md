# r29k (тестовая сборка после r29j)

**Am MOD теперь игнорирует штатный эффект FX Select, сохранённый в проекте.**

- По схеме пути звука в Am MOD штатный FX Select (и шторка Knob FX) не используются. Проект, сохранённый в Stock с эффектом FX Select и выделенными пэдами, в Am MOD больше не звучит с этим эффектом: пэды идут на трек или Direct, затем на Master.
- Технически: пэд, направленный на шину FX Select, считается направленным на основную шину программы, и микс микшера всегда идёт туда.
- Выделение остаётся в проекте; режим Stock его по-прежнему применяет.
- Разделение пэдов по FX Select из r29i/r29j убрано.
