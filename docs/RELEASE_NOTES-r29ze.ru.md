# r29ze

- Исправление (запись в Am MOD): эффекты Track и Master не попадали в запись. После первого изменения цепочки эффектов новая программа ждала, пока её примет аудиопоток, но принималась только та линия, что уже использовалась; линии Track и Master навсегда оставались в ожидании, маршрут не переключался. Теперь неиспользуемые линии принимают новые программы на тишине, и маршрут становится готовым. Найдено в консольном логе r29zd (`INPUT_FX route ... ready=0 result=0/0/2`).
- Диагностика: строка `INPUT_FX route` теперь показывает число эффектов каждого трека A-H.
- Включает r29zd (свободный пэд рендерит сразу, занятый спрашивает).
