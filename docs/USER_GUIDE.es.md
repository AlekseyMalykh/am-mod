## Mezclador

En Am MOD pulsa **Knob FX**. Desde Sample, **Shift+Knob FX** abre los FX de la pista del último pad tocado (o Master si es Direct). Los pads 1–8 eligen A–H, 16 Master, 15 Input, 13 Synth. Mantén un pad de pista y toca otros (o usa Shift) para agrupar. B1 vuelve a Sample.

El fader cambia el nivel; K1 es Pan, K2 Send (Shift: Send To), K3 Colour. DATA alterna Level / Pan / Send / Colour. Mute / Shift+Mute silencia / borra todos los mutes; B3 / Shift+B3 del resumen hace solo / lo borra. Pads 9–12: cuatro ranuras insert en serie. FX: Shift+Erase / Shift+B2 / Shift+B3 = Copy / Paste / Chain Bypass.

## Sintetizador, Input y Piano Roll (r30d)

Detalles: [guía del sintetizador](SYNTH_GUIDE.es.md). El pad 13 del mezclador abre el sintetizador; Loop + pad (13–16, 9) o + / − eligen el módulo, DATA pasa las páginas y Shift+K edita el parámetro oculto. K1 en Keys es Transpose16 y Shift+K1 es Layout. Shift+Sample abre Input ROUTE desde cualquier pantalla. En Piano Roll mantén DATA, gira el encoder y mueve el fader para seleccionar un área. **Mod Settings → About → Exit to bootloader** guarda una copia del proyecto y vuelve al menú de D.S.B (o al firmware original); véase [menús de arranque](BOOTLOADERS.es.md).

## Otras funciones

Mute+B3 / Mute+B2: modo mute de secuencias / borrar mutes locales. Mantén Stop y pulsa Chop: afinador. Step Edit → Events/Steps → Knob FX: Piano Roll (B1 vuelve). Shift+Pad8 → B2: Map / Log MIDI. Browser → Shift+B1 / Shift+B2: Sample Swap / importar programas. Shift+Pad16 → Mod Settings: modo, audio USB, paleta, pantalla.
