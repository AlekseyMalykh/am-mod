# Руководство Am MOD r30b

[README](../README.ru.md) · [USB](USB_GUIDE.ru.md) · [English](USER_GUIDE.md)

## Микшер

В Am MOD нажмите **Knob FX**. На Sample сочетание **Shift+Knob FX** открывает FX трека последнего сыгранного пэда; если пэд Direct, выбирается Master. Пэды 1–8 выбирают A–H, 16 — Master, 15 — Input. Удержание одного пэда трека и нажатие других или Shift позволяют выбрать группу. B1 возвращает в Sample. Из компрессора переход в Mixer отключён; откройте его через Sample.

Фейдер меняет уровень; группа сохраняет разницу уровней, Shift+фейдер выравнивает. K1 — Pan, K2 — Send (Shift: Send To), K3 — Colour. Клик DATA выбирает Level / Pan / Send / Colour, вращение меняет выбранное значение. Mute / Shift+Mute — заглушить / снять все mute; B3 / Shift+B3 в обзоре — Solo / снять все solo. Shift+B2 — имя трека. Кнопки ± листают A–H и Master.

**Pad FX → Assign Pads:** нажатие пэда назначает его выбранному треку, повторное отправляет Direct. B2 Pad Lock блокирует изменения. Банки назначений независимы от банка секвенций.

**B2 Route:** вкладки Pads / Sends / Sidechain. Sends задаёт From / To / Send. Энкодер и ручки пропускают собственный трек и все назначения, создающие петлю; это относится и к группе. Sidechain Key — детектор, а не звуковой посыл. Посыл входит в принимающий трек перед его FX.

## FX Chain

На треке, Master или Input доступны четыре insert-слота; пэды 9–12 открывают их. DATA выбирает слот; клик открывает редактор или каталог для Empty. K3 в каталоге фильтрует категории. В списке Shift+вращение DATA меняет порядок эффектов.

Звук обрабатывается **последовательно сверху вниз**. Изменение первого эффекта слышно на входе второго. Спектр EQ показывает живой сигнал выбранного слота после обработки; жёлтая кривая показывает только настройку этого EQ. В bypass живой спектр/анимация эффекта гаснут, а метр трека продолжает показывать проходящий сигнал.

| Управление | Действие |
|---|---|
| K1–K3 / Shift+K | Параметры текущей страницы / дополнительный слой |
| DATA в редакторе | Листать подписанные страницы; в EQ — точки |
| B1 FX List | Вернуться к цепи |
| B2 Bypass | Обход выбранного эффекта |
| Shift+B3 | Обход всей цепи |
| Shift+Erase / Shift+B2 | Копировать / вставить эффект |
| Erase | Удалить с подтверждением |
| Shift+DATA в EQ | Добавить точку (до четырёх) |
| Пэды 1–8 / 15 / 16 | Список FX выбранного Track / Input / Master |

Основные параметры находятся на первой странице: Time/Feedback/Mix у Delay, Rate/Depth/Mix у модуляции. [Полная таблица](FX_KNOB_LAYOUT.ru.md). Amp Model меняется на K1; [описание вариантов](AMP_VOICES.ru.md). Настройки takeover Parameter / Knob FX / Fader — Pickup, Scaled, Jump — учитываются отдельно.

## Компрессор

На Sample **Shift+Pad5** открывает Duck / OptoCat; B2 меняет тип. В обоих редакторах сразу выделен K1. DATA вращением меняет выбранное значение, клик выбирает следующую колонку K1 → K2 → K3, Shift+клик — предыдущую с переходом по кругу. Shift меняет слой, не фиксируя отдельную страницу.

Duck: Attack / Release / Amount; Shift меняет третью колонку на In Boost. OptoCat: Threshold / Ratio / Gain; Shift — Attack / Release / Knee. У OptoCat B1 — Warm, B3 — Bypass. Закреплённый Sample Comp на Master относится к этому же штатному компрессору; это не дополнительный последовательный экземпляр.

## Входной канал и запись

*Режим Am MOD.* **Входной канал** — место, где Mic, USB и Rear попадают в микшер. Откройте его **пэдом 15** в микшере.

| Управление | Действие |
|---|---|
| **Фейдер** | уровень входа |
| **Mute** | заглушить вход |
| **B1 Back** | в обзор |
| **B2 FX** / **B3 ROUTE** | цепочка Input FX (четыре слота, как на треке) / список маршрутизации |
| **Shift+B2 Paste** / **Shift+B3 Chain Bypass** | вставить эффект / байпас всей цепочки |

**Строки ROUTE.** Вращением выберите строку, **кликом** войдите в правку, вращением измените, кликом примите.

| Строка | Значение |
|---|---|
| **Tuner >** | открывает [тюнер](#тюнер) |
| **Monitor** | Off / Auto / On: слышать вход |
| **Record via** | **Input**, **Track** или **Master**: из какой точки берётся запись |
| **Record track** | трек A–H, если *Record via* = Track |
| **Record FX** | **Dry**: без эффектов. **Wet**: эффекты до выбранной точки (Track: Input FX, эффекты трека, фейдер и пан; Master: плюс эффекты Master) |
| **Rear mode** | только для источника Rear: Stereo, Rear L, Rear R, L+R Split, L+R Mix |

K2 — пан входа (для Rear: K2/K3 — Pan L/R, с **Shift** — Level L/R). Мониторинг слышит сигнал из той же точки, из которой идёт запись. Записывайте на штатном экране **Sample Record**, как обычно: *Tap pad to record*. Настройки одинаковы для Mic, USB и Rear.

## Ресемплинг

Ресемплинг рендерит то, что вы слышите, в новый сэмпл. В Am MOD он идёт через микшер (фейдер трека, Mute/Solo, Track FX, посылы, Master FX, компрессор); в Stock — через штатный FX Select. Уровень результата зависит от фейдеров.

1. **Пэд:** на экране Sample выберите пэд со звуком, нажмите **Shift+Pad 11** (источник — этот пэд, вопросов нет). **Секвенция:** на экране Sequence нажмите **Shift+Pad 11** (заголовок *Resample Seq*).
2. Откроется **страница назначения**. Выберите целевой пэд:
   - **свободный пэд** — рендер начинается сразу;
   - **занятый пэд** показывает *Replace?*: нажмите тот же пэд ещё раз или **B3 Replace**, чтобы перезаписать; **B1 Back** (или другой пэд), чтобы передумать. Цель подсвечивается красным на экране и на пэде.
3. **Pad Bank** листает банк вперёд, **Shift+Pad Bank** назад; **удерживая Pad Bank**, нажмите пэды 1–8 (красные), чтобы перейти в банк. Буквы банков следуют за диалогом. Банк назначения не связан с банком секвенций: после завершения или отмены вы возвращаетесь в свой банк секвенций.
4. Если транспорт запущен, окно спросит *Stop playback?*: **B3 Stop & Render** останавливает и запускает рендер, **B1 Cancel** продолжает воспроизведение.
5. Показывается прогресс; отмена — **B1**. Результат появится на целевом пэде.

## Тюнер

Одно полноэкранное окно везде одинаковое: названия нот, прямая шкала ±50 центов с движущейся стрелкой (зелёная в пределах ±5 центов), частота в Гц и нота с октавой.

- **Входной сигнал:** микшер → Input → ROUTE → **Tuner** (клик DATA) или **B3** на штатном экране *Sample Record* (подпись *Tuner* рядом со значком порога). **B1**, **B2**, **B3** или DATA закрывают окно.
- **Сэмпл пэда:** на экране Sample удерживайте **Stop** и нажмите **Chop** (**Stop+Chop**). Окно открывается поверх экрана Sample: ударьте по любому пэду, и окно покажет высоту сэмпла этого пэда (*Sample A05*). Ударные и шумовые сэмплы дают *No pitch found*; ноты ниже примерно 60 Гц не определяются. **B3 «Orig note»** сохраняет найденную ноту как **Original note** сэмпла (только нота; высота звука не меняется). **B1**, **B2** или **Chop** закрывают окно.


## Sample Record и Input Config

B1 на Sample Record меняет мониторинг Off / Record / On; значок перечёркнут только в Off. В Rear Routing отдельные Mon L/R управляют сторонами. В режиме Am MOD используйте Input FX и Record FX Wet / Dry в Input ROUTE; штатный пункт **Rec Input Effects** скрыт. В Stock этот пункт сохранён. В Routing Stop завершает/отменяет локальную запись и проходит в транспорт; повторный Stop гасит голоса и хвосты FX.

## Сохранение, экспорт и помощь

Сохраняйте в **External**. Song → Export → Stems пишет треки и Master в `Samples/User/Export/<song>/`; посылы делают стемы перекрывающимися. Для отдельных USB-треков см. [USB](USB_GUIDE.ru.md).
