# Что полезного в az0x-open-source для Am MOD

Проверена ветка mpc-sample/1.3.0 официального репозитория https://github.com/inmusic-software/az0x-open-source. В aarch64-poky-linux опубликованы 69 каталогов пакетов. Это GPL/LGPL-компоненты Linux-окружения, а не исходный код самого приложения MPC Sample. README производителя отдельно обозначает публикацию как исходники Linux environment.

| Пакет | Практическая польза |
|---|---|
| linux-imb-6.12.60+git-r0 | Точные структуры и ABI ядра, USB UAC2, configfs, ALSA, DRM, драйверы SoC; позволяет собирать совместимые RAM-модули. |
| libusbgx-0.2.0+git-r0 | Разбор схем и создание USB-функций; полезен для штатного az0x-usb-gadget/gt. |
| alsa-lib-1.2.11-r0, alsa-utils, alsa-state | Работа PCM/raw MIDI, конфигурация портов и диагностика; устраняют необходимость угадывать ioctl-поведение. |
| systemd-255.21 и dbus-1.14.10 | Реальное управление службами, namespace и USB target при переходах мода. |
| glibc-2.39, linux-libc-headers-6.6 | Совместимая пользовательская ABI для утилит и preload-кода. Версия UAPI-заголовков не равна версии работающего ядра. |
| libusb-1.0.27 | Пользовательский доступ USB, чтение дескрипторов и разработка host-утилит. |
| bluez5-5.72 | Системная Bluetooth-реализация; наличие исходников не доказывает доступность конкретного сценария на устройстве. |

Архивы хранятся через Git LFS: 134-байтовый файл из raw.githubusercontent.com — указатель, а не архив. Для ядра получен настоящий файл 153539184 байта и проверен SHA-256 9d6999d9f69f5afd396a634facadc9219dcb85407264273d912355dd6db38f9b.

Для задачи USB-имён найдено и исправлено отсутствие назначения iChannelNames в опубликованном f_uac2.c. Соответствующий модуль проверен на оригинальном ядре MPC в QEMU. Ядро следует брать из part2/kernel.fit: part1 содержит другое, восстановительное ядро 6.12.23. Конфигурация извлекается из встроенного IKCONFIG основного ядра. На MPC нельзя загружать модуль, собранный под другое ядро, или применять force-vermagic.

Открытие этих пакетов не предоставляет исходники интерфейса, секвенсора, проектного сериализатора или DSP самого MPC-приложения. Для изменений этих частей по-прежнему нужны существующие native hooks и проверка привязок к прошивке.
