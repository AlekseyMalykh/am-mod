# Am MOD r29zzi

Mixer > Input now has three tabs (B1 MIX, B2 FX, B3 ROUTE), as on normal channels.

- MIX: the Input strip with Level (fader), Pan (K1) and Mute (K2). They act on the audio of the selected input after the Input FX chain, before the Track/Master record route, and are saved in the project.
- FX: the Input effect list as before (Shift+B1 goes back).
- ROUTE: source, Record via / track / FX (still changed in Quick Mod Settings for now) and the Rear record knobs.
- Phase, Mono/Stereo, monitoring and per-source record settings are not in this build.
