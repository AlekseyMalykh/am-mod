# Кандидат r26q — пульсация пэдов Seq в темп

[English](RELEASE_NOTES-r26q.md)

Пэды выбора секвенций сохраняют свой цвет и коротко вспыхивают:
выбранный при Stop — раз в такт, играющий — каждую долю, ожидающий
переключения — вдвое чаще. После фактического переключения частота обычная.
Между вспышками остаётся фоновое свечение. Остальные занятые пэды имеют
одинаковую яркость до и после Play. Пустые слоты погашены, кроме выбранного
и ожидающего переключения. Запись и штатные обозначения Mute сохранены.

Темп и размер берутся из проверенного штатного playhead в потоке интерфейса.
При воспроизведении используется штатная позиция 960 тиков на четверть
с интерполяцией между обновлениями; при остановке — монотонное время
и текущий темп/размер. Если playhead недоступен, используется 120 BPM, 4/4.
Вспышка — до 90 мс и не больше трети периода; фон 96/255, пик 255/255,
остальные занятые пэды 192/255. Ожидание переключения по-прежнему определяется
по штатной пульсации целевого пэда.

ARM/QEMU и UBSan проверяют 20/60/120/137/300 BPM, 3/4 и 6/8, изменение темпа,
цикл/смену позиции/Stop, интерполяцию, цвета, пустую очередь, постоянство
яркости остальных пэдов и границы Mute/записи/Steps. OptoCat, Warm, общий
Bypass, повторная привязка мастера после New Project и все исправления r26p
сохранены. Полное приложение и физический MPC для новой индикации/очереди
ещё нужно проверить. Локальный кандидат, не опубликован.
