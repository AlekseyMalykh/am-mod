# AM Mod r27m

- В Sample волна и спектр заглушённого пэда становятся серыми. После снятия Mute возвращается обычный цвет. Спектр на Filter, Filter Env и EQ сохраняет отдельный цвет кривых.
- При включённом Mute в Sample занятые незаглушённые пэды подсвечены системным зелёным, заглушённые — системным красным, пустые выключены. В обычном режиме заглушённые пэды видны серым, а записанные события дают более яркую вспышку.
