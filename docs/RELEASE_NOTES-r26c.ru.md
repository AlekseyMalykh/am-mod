# r26c — исправления и новые функции

Заменена на [r26d](RELEASE_NOTES-r26d.ru.md): r26c вместе с волной стирала штатные кривые фильтра и огибающей. Исправление отключает только волну.

[English](RELEASE_NOTES-r26c.md) · Изменения относительно r26a, включая r26b.

Это сборка для проверки на устройстве. Работа цветов подтверждена на MPC; остальные изменения ожидают аппаратного подтверждения перед публикацией.

## Исправленные баги

- **Смешивание проектов при включении:** автозагрузка теперь открывает сохранённый проект целиком. Раньше сэмплы проекта B могли загружаться вместе с секвенциями проекта A, а после пустого стартового проекта — без секвенций. Открытие проекта из поиска тоже использует полную загрузку.
- **Фокус Pad Colour:** энкодер управляет выбранным цветом и возвращает управление штатным параметрам при их выборе или удержании Shift.
- **Синие вспышки при воспроизведении:** пэды Sample сохраняют назначенные цвета при проигрывании событий секвенции, в том числе в других банках.
- **Green был похож на Cyan:** у зелёного убрана синяя составляющая. Сохранённые назначения цветов сохраняют свои ID.
- **Влияние индикаторов кнопок на пэды:** сообщения кнопочной подсветки больше не вызывают посторонние изменения RGB пэдов в Steps.

## Добавленные и изменённые функции

- **Pad Colour на K2 без Shift:** Sample → B1 → Mix. K1 остаётся Volume, Shift+K2 — Kit Volume. Нажатия энкодера переключают Volume → Pad Colour → Pan.
- **Спектр во всей вкладке B3:** спектр выбранного пэда доступен на Filter, Filter Env и EQ.
- **Только спектр на страницах фильтра:** в Filter и Filter Env спектр с частотными подписями заменяет волну, курсор и временную линейку. Заголовки и штатные регуляторы параметров остаются доступны. В EQ сохраняются его кривая и спектр.

## Проверка

- Пройдены ARM/QEMU-проверки и UBSan для загрузки проектов, цветов пэдов, фокуса, отрисовки спектра и EQ.
- В полном эмуляторе поверх пустого стартового проекта восстановлены три нотных события, секвенция, темп и громкости микшера/трека проекта B. При воспроизведении выход RGB сохранял назначенный цвет с изменением яркости.
- Автор подтвердил работу цветов на реальном MPC. Замена волны в r26c прошла проверки отрисовки и ожидает отзыва с устройства.

При старте по-прежнему выбирается самый новый сохранённый XPJ в папке Projects на SD или на один уровень ниже. Совместимость: MPC Sample **1.3.0.12**, SD-карта **exFAT**. Поддержка FAT32 в обновление не входит.
