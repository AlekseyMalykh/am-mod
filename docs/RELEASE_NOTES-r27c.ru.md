# r27c — проверочная сборка

Локальная сборка; не опубликована. Публичный релиз остаётся r26s.
**Перед установкой рекомендую сделать бэкап сэмплов и проектов.**
Для MPC Sample 1.3.0.12; exFAT поддерживается, FAT32 экспериментально.
Обновлять нужно всю папку autorun без форматирования карты.

## Новое относительно r27b

- Исправлена отложенная Auto Save Error после New Project: при первом
  автосохранении штатный сериализатор создаёт недостающий Temp-Project.xpj
  из текущего проекта. Предыдущий проект не подмешивается.
- Белое выделение в библиотеке, обычном/пакетном Copy, Chop, Mono и Render
  подчиняется Selected Pad → Cursor pulse: Steady / Slow / Normal / Fast.
  Между вспышками виден назначенный цвет; пустой пэд гаснет.
- Удержание Pad Bank + поворот K сбрасывает соответствующий параметр к
  заводскому значению; Pad Bank → Shift + K — его Shift-параметр.
  Дальнейшее вращение до отпускания Pad Bank не меняет сброшенный параметр.
  Штатный выбор банков пэдами 1–8 при удержании Pad Bank сохранён.

Сохранены OptoCat/Warm, исправление Scaled/K, настройки в XPJ, один полный
Load при запуске, малые подписи версии/репозитория внизу заставки,
кривые фильтров, огибающие и боковые шкалы EQ.

Сброс реализован для параметров Sample, EQ, OptoCat, Key/Scale, Lights,
Chords и настроек Steps. Выбор объекта (Sound/Bank), меню и неподдержанные
параметры не сбрасываются. Штатные FX Duck и другие FX пока не имеют таблицы
заводских значений; жест там ничего не меняет. Master Volume не затрагивается.

## Проверка

Автоматические ARM/UBSan проверки охватывают таймер автосохранения,
приоритеты цветов, все четыре скорости курсора, отдельные обычные/Shift
сбросы, очередь ввода и сохранение Scaled. В полной VM воспроизведена
исходная ошибка New Project и проверено создание читаемого пустого XPJ.
Физический тест этой сборки на MPC ещё нужен.

1. New Project → подождать более минуты: не должно быть Auto Save Error.
2. Изменить End → Pad Bank + K2: 100%; Shift + K2: Zoom 0%, End не меняется.
3. Удерживая Pad Bank, выбрать банки пэдами 1–8; отпустить и проверить игру.
4. Проверить белое выделение в библиотеке/Copy/Batch/Mono/Render и все режимы
   Cursor pulse. Цели остаются красными/зелёными, свободные без выбора погашены.
