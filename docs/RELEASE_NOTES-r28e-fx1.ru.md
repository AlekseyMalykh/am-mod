# Am MOD r28e-fx1 (тестовая сборка, не релиз)

r28e плюс ветка Illustrated FX. На устройстве не проверено.

- **Mod Settings → Pads → FX view: Illustrated / Classic.** Illustrated (по умолчанию) рисует анимированную картинку, реагирующую на параметры, для каждого эффекта микшера; Classic как в r28e. Graphic EQ не менялся. Картинки нагружают процессор только при открытом экране эффекта.
- **Новые эффекты микшера:** Shimmer Reverb, Pitch Shifter, Reverse Delay, Tremolo, Slow Attack, Ring Modulator, Bit Crusher и OptoCat Comp (независимый на каждом треке/мастере). Проекты с ними не открываются в старых версиях Am MOD.
- **Страница FX мастера:** строка состояния компрессора режима Sample (Duck/OptoCat, Bypass, gain reduction).
