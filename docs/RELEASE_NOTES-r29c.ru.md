# r29c (тестовая сборка после r29b)

- **Версия на экране загрузки:** заставка бралась без изменений из старой базовой сборки и показывала прежнюю версию. Теперь она пересобирается в каждом пакете и показывает текущую.
- **Диагностика области действия Knob FX и mute пэда:** в лог пишутся строки `ROUTE_PADS` (куда штатная прошивка направляет какие пэды). Нужно, чтобы найти, почему Knob FX может задевать невыбранные пэды; звук пока не менялся.
- Включает r29b (External в Save) и всё из [r29a](RELEASE_NOTES-r29a.md).
