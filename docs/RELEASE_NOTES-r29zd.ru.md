# r29zd

- Ресемплинг из окна Sample: нажатие свободного пэда назначения сразу запускает рендер; нажатие занятого пэда спрашивает подтверждение (повторное нажатие того же пэда или B3 «Replace»; Back или другой пэд отменяют выбор).
- Включает r29zc (палитра пэдов под штатными диалогами, диагностика `INPUT_FX`) и r29zb (ресемплинг сэмпла сохраняет атаку).
