# AM Mod r27p

MPC Sample **1.3.0.12**. Изменения после публичной r27n; все её функции и исправления включены.

- **Запись и мониторинг Rear.** Sample Record → B2 Routing: K1 выбирает Record Rear L / Record Rear R / Record L + R. Нажмите пэд для монозаписи. Для L + R сначала выберите пэд L, затем другой пэд R: запись обоих каналов начинается одновременно после второго выбора. B1 или STOP отменяет первый выбор; занятые пэды требуют подтверждения. STOP завершает запись. Удерживайте Pad Bank и используйте пэды 1–8 для банков. Обычная стереозапись на один пэд сохранена в штатном Sample Record; Routing предлагается только для источника Rear.
- **Мониторинг без записи.** Input Config → Shift+B2 Routing: B2/B3 включают мониторинг L/R, K2/K3 задают панораму, Shift+K2/K3 — громкость мониторинга. Эти же органы доступны в Routing записи. В Input Config нажатия пэдов не запускают запись. Панорама и громкость мониторинга не меняют записываемые сухие моноканалы. Настройки сохраняются с проектом.
- **Приоритет Knob FX.** При открытом Knob FX физические K1–K3 управляют эффектом, в том числе поверх добавленных экранов. После закрытия управление Routing возвращается. Note Repeat сохраняет свои органы управления.
- **Scale и Orig Note.** Выбор Orig Note сразу включает Scale. Подсветка Tune читает текущий сэмпл из модели проекта, в том числе после выбора другого пэда в компрессоре и в банках A–H.
- **Нажатия в меню.** Быстрый клик энкодера после выхода из Mod Settings передаётся текущему штатному меню. Скрытый Sample больше не перехватывает управление Project.
- **Copy и EQ.** После входа в Copy через Shift+Erase можно отпустить Shift, удерживая Erase; Shift+Pad Bank листает банки назад. При возврате из Seq в Sample сохраняется вкладка EQ.

**Ограничения записи:** монозапись и раздельная запись требуют Rec Length **Free**, создают WAV 24 бит / 44,1 кГц и используют штатный порог входа. Записывается сухой сигнал. Стереозапись и исходные экраны источников Rear L / Rear R остаются штатными.

**Проверки:** ARM64/UBSan проверяет выбор пэдов, отмену, подтверждение замены, банки и приоритет FX/Repeat. Аудиотесты покрывают синхронную сухую запись, панораму/громкость мониторинга и отмену. Полная установка нативных перехватов проходит проверку. Предыдущий интерфейс r27o проверялся в VM; r27p записана с проверкой всех 77 файлов и принята автором на MPC. Это не закрывает все исторические замечания. FAT32 остаётся экспериментальным.

**Установка:** сделайте резервную копию проектов и сэмплов. Скопируйте `autorun/` в корень карты или выберите ZIP в установщике 1.0.3. Latest release теперь выбирает r27p.
