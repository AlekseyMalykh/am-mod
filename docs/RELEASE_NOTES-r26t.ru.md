# Кандидат r26t — заметное выделение пэдов

[English](RELEASE_NOTES-r26t.md)

Выбранные источники Batch Copy и выбранные срезы Batch Extract чередуют белую
вспышку 240 мс и свой цвет 400 мс. Невыбранные пэды сохраняют постоянный оттенок.
Это исправляет случай, когда все Chop фиолетовые и выбранные не отличаются
от остальных. Белый назначенный цвет тоже пульсирует по яркости.

Такой же указатель источника добавлен в Stereo→Mono и Resample. Цветные цели
сохраняют белый/свой цвет с другой фазой; Stock-цели остаются белыми, а красные
предупреждения о перезаписи — красными. Подсказка Batch теперь White blink.
Обычный Copy Pad тоже получил мигание выбранных источников: штатная битовая
маска выделения выдаёт чистый красный; по проверенному режиму он отделён от
предупреждений браузера/перезаписи/Mute. Copy Sequence не перекрашивается
цветами звуковых пэдов.

В редакторе Chop/Tune выбранный вариант чередует белый с исходным цветом.
Chop-варианты используют Pad Colour источника; янтарная отметка исходного
значения сохраняется между вспышками выбора. Обычный Chop сохраняет штатную
оранжевую отметку, Sound, сетка/playhead Steps и согласованная пульсация Seq
сохранены. Метаданные проекта, события, прослушивание/аудио и Undo не меняются.

ARM/QEMU и UBSan проверяют реальную штатную маску Copy (обе половины128 пэдов),
приоритеты RGB, все13 цветов, фиолетовые страницы Chop, восемь банков Copy,
выбор вариантов и прежние операции/команды. Проверен полный preload constructor;
полное приложение и физический MPC для новых указателей ещё нужно проверить.
Все функции r26s, шкалы EQ, Warm и Gain OptoCat −6…+6 dB сохранены.
Локальный кандидат, не опубликован.
