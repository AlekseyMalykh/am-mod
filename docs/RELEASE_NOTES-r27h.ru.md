# Проверочная r27h — палитра, активные лупы и имя проекта

Проверочная сборка поверх r27g. В публичный репозиторий пока не опубликована.

## Цвета

Пользователю доступны **8 цветов и Default**: Blue, Violet, Magenta, Orange,
Coral, Lime, Teal, Yellow. Default повторяет первый пользовательский слот.
Общий набор расширен до **14 цветов**: восемь пользовательских и шесть
системных. Свободная цель — чистый зелёный, занятая — чистый красный,
воспроизведение — насыщенный циан, исходное значение — насыщенный янтарный.
Белый курсор и серый мют сохраняются. Яркость состояний отделена от оттенка.

Смена системного цвета по-прежнему обменивает его с прежним владельцем,
поэтому один и тот же цвет не назначается одновременно системной роли и
пользовательскому слоту. Старые карточные AM_SETTINGS1 и проектные AMS1
читаются с переносом назначений и обменов; новые записи используют
AM_SETTINGS2 и AMS2. Идентификаторы назначений пэдам не перенумеровываются.

Насыщенность задана программно; различимость оттенков на конкретных
рассеивателях требует аппаратной оценки. В Standard сохраняется штатная
подсветка, пользовательские назначения не применяются.

## Играющие лупы Sample/Loop

Назначенный цвет активного пэда пульсирует по штатному состоянию голосов,
даже при остановленном транспорте секвенции. После остановки звучания
пульсация прекращается. Белый курсор выбранного пэда имеет приоритет;
между его вспышками виден назначенный цвет. Мют остаётся серым.

Состояние голосов читается там же, где штатный PlayingPadsLighting
обновляет подсветку. UI и RGB-обработчики получают только числовой снимок,
не обходят изменяемый список голосов. Аудиопараметры не изменяются.

## Имя после Save и перезапуска

Успешный явный Save в Internal или External запоминает целевой файл для
метаданных восстановления. Старое имя CurrentThings или технический
Temp-Project больше не вытесняют его после New Project. Технические
автосохранения и страховочная копия не считаются новым пользовательским именем.

Сохранённые до исправления копии уже могут содержать имя Recovered Project.
Оно не угадывается по соседним файлам: для повторной проверки вручную
загрузите нужный Workspace-Test.xpj либо явно сохраните проект под нужным
именем, затем штатно выключите и включите MPC.

Восстановление Internal-проекта сохраняет исходное имя и предлагает External
для первого Save, поскольку внутренние изменения мода используют изолированный
RAM-слой. Для постоянной обычной копии проекта выбирайте External.

## Проверить на MPC

1. В Sample → Mix → K2 пролистать все восемь цветов; оценить их различимость.
2. В Copy/Render проверить насыщенные зелёную свободную и красную занятую цели.
3. Запустить несколько лупов и выбрать другой пэд: играющие должны пульсировать;
   выбранный — показывать белый курсор. Остановить луп, проверить Standard.
4. New Project → Save под новым именем на External → выключение → включение →
   Save: имя должно сохраниться. Отдельно повторить Internal → External.
5. Проверить большой сэмпл, Copy Pad и рендер — перенос TempProjects из r27g сохранён.

На заставке `version: r27h`, в About — r27h. OptoCat/Warm и исправление K сохранены.
