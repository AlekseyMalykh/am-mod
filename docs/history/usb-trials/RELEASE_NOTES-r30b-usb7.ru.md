# Am MOD r30b-usb7 — настройки Stock и выход B3

В Stock скрыт пункт FX View, который управляет только эффектами Mixer в Am MOD. Остальные пункты Quick сдвигаются без пустой строки. Видимость определяется запущенным режимом FX: выбор другого режима вступает в силу после перезапуска. Значение Classic/Illustrated сохраняется на карте и доступно в Am MOD.

Сохранено исправление usb6: внутренний контроллер определяется по точной паре id SerialMIDI и name Control Surface. Внешний порт External MIDI с тем же id не создаёт неоднозначность. Регрессионная проверка использует реальные записи обоих портов из журнала usb5.

Для выхода безопасно извлеките диск на ПК, затем нажмите **B3 Disconnect → B3 Return to Am MOD** на MPC. B1 отменяет подтверждение. Кабель и SD-карта остаются подключёнными. После установки перезапустите MPC, чтобы обновить процессы в RAM.

Программные проверки и AArch64-сборка выполнены. Выход B3 после исправления выбора контроллера ещё требует проверки на устройстве. При необходимости сохранён выход отключением USB-кабеля.
