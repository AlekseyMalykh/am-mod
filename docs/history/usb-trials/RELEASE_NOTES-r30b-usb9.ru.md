# Am MOD r30b-usb9 — настройка MIDI-входа B3

Журнал usb8 подтвердил `USB_DRIVE_INPUT_MODE_FAILED errno=22`. Причина: helper вызывал RAWMIDI_IOCTL_DROP для MIDI-входа, тогда как ядро поддерживает DROP только для выхода. До установки режима обычного MIDI выполнение не доходило.

В usb9 используется RAWMIDI_IOCTL_DRAIN со stream=INPUT: для входа это очистка очереди без ожидания передачи. Затем устанавливается RAWMIDI_PARAMS mode=0 и обрабатываются реальные сообщения B3 Note On/Off. Тест теперь воспроизводит поведение ядра: входной DROP возвращает EINVAL, входной DRAIN разрешён. Ошибки DRAIN и PARAMS отдельно записываются в журнал.

Порядок: безопасно извлеките диск на ПК → B3 Disconnect → B3 Return to Am MOD. B1 отменяет подтверждение. Кабель и SD-карта остаются подключёнными. После установки нужен перезапуск MPC.

Сохранены изменения usb8: Stock использует стереомастер USB и скрывает FX View; Am MOD предлагает Stereo / Master + A–H, с мастер-парой 1–2 и восемью стереотреками 3–18. Многоканальная запись и исправленный выход B3 требуют физической проверки. Автоматические проверки и AArch64-сборка проходят отдельно от аппаратного подтверждения.

Проверка ABI: https://github.com/torvalds/linux/blob/v6.1/sound/core/rawmidi.c — обработчики RAWMIDI_IOCTL_DROP, RAWMIDI_IOCTL_DRAIN и snd_rawmidi_drain_input.
