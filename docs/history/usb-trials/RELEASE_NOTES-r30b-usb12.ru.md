# Am MOD r30b-usb12 — тюнер и изменение FX

STOP+CHOP: анализ высоты ноты перенесён из очереди модели в поток с низким приоритетом. Модель копирует до трёх окон по 2048 кадров; поток не обращается к штатным объектам или потокам чтения сэмплов. Кэш учитывает проект, объект сэмпла, границы Trim и частоту. Результаты старого проекта отклоняются.

Mixer FX: изменение параметра сохраняет обработчики остальных слотов. EQ обновляет коэффициенты со своей рампой 5 мс; собственные эффекты мода обновляют совместимые параметры с рампой 20 мс. Штатный изменённый эффект заменяется отдельно с переходом 20 мс: его setter использует блокировки, поэтому вызывается только при подготовке вне аудиопотока. Изменение Size/Predelay Shimmer также готовит новый обработчик. Хвост изменённого штатного эффекта не переносится в новый экземпляр; остальные слоты сохраняют историю. Изменение состава/порядка цепочки использует прежний переход всей цепочки.

FX Chain: B2 — Bypass выбранного эффекта (включая закреплённый Sample Comp); Shift+B2 — Paste. Под треком показаны SLOT и ACTIVE/BYPASS/CHAIN OFF/EMPTY. Кнопки FX/ROUTE у Input сохранены.

Проверки: новые регрессии FX continuity и sample tuner на host, UBSan и AArch64/QEMU; Mixer управление и отрисовка на host/ASan/ARM/UBSan; штатные Mixer FX через реальные фабрики и DSP в ARM/QEMU с запретом RT allocation/mutex. Старые общие сценарии resample UI и Rear Input требуют обновления тестовых ожиданий и не объявлены прошедшими.

Слышимость щелчков и производительность требуют пробы на MPC. Карта при создании пакета не изменяется.
