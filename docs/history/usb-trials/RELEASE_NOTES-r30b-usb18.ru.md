# Am MOD r30b-usb18

- Send To: списки назначений в Route и Mixer исключают все треки, создающие прямую или косвенную обратную петлю. Учитывается групповое выделение. DATA, K2, шкалы и takeover используют один список. Защита от некорректных маршрутов при загрузке сохранена. Sidechain Key не ограничивается аудиопосылами.
- Duck и OptoCat: при входе сразу выделяется K1. DATA выбирает K1 → K2 → K3 → K1, Shift+DATA — в обратном порядке. Duck использует такую же верхнюю янтарную линию и очистку рамок ячеек, как OptoCat.
- Пользователь подтвердил исчезновение щелчков после предыдущих изменений тюнера и FX.

Проверки: маршруты с прямыми и косвенными петлями, групповые посылы, энкодер в обе стороны и полный диапазон ручки; начальное выделение и циклическая навигация обоих компрессоров; последовательные EQ и PCM анализатора второго слота. Автоматические проверки не заменяют прослушивание на MPC. Пользователь повторно проверил два EQ на Track A и подтвердил корректное поведение; DSP цепочки не менялся.

Установка: безопасно извлечь диск в Windows → B3 / Return на MPC → выключить и включить MPC.
