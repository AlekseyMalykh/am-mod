# Am MOD r30b-usb3 — исправление входа в SD Card Access

Исправляет подтверждённый на MPC отказ r30b-usb2: после Connect экран гас, приложение снова запускалось и показывало USB transfer interrupted. В журнале трёх попыток была причина **USB_DRIVE_ERROR NOT_REMOVABLE**. Отказ происходил до передачи карты компьютеру.

Контроллер ошибочно требовал `/sys/class/block/<card>/removable=1`. В MPC этот флаг не позволяет определить физическую SD. Теперь проверяется тип карты **SD**, раздел определяется только по её фактическому монтированию, а CID и номер устройства остаются закреплёнными до возврата. Внутренняя eMMC (тип MMC) не допускается даже при removable=1. Неизвестный тип также отклоняется. Защита от одновременного использования файловой системы MPC и ПК сохранена.

На странице USB transfer interrupted теперь выводится код ошибки. Убран шум о недостающем devno после отказа до подготовки контекста.

**Как проверить:** Project → SD Card Access → B3 Connect. Должен появиться экран передачи и диск на ПК. После копирования безопасно извлеките диск; при необходимости отключите USB. Мод должен вернуться к сохранённому Mod-Exit-Last. Во время передачи аудио/MIDI и приложение приостановлены. Подробности прежнего управления: [usb2](RELEASE_NOTES-r30b-usb2.ru.md).

Добавлены тесты SD с removable=0, отказа eMMC и отсутствующего типа, раннего отката. Наличие исходного отказа подтверждено устройством; **исправленный режим USB-диска ещё требует аппаратной повторной пробы**. Сохраните резервную копию карты перед пробой. Браузерный обмен и режимы Stereo / Master + A–H сохранены.
