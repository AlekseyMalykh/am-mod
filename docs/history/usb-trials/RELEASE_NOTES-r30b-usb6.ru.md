# Am MOD r30b-usb6 — распознавание кнопок SD Card Access

Журнал usb5 подтвердил два разных native MIDI-порта с одинаковым id `SerialMIDI`: `/dev/snd/midiC0D0` с именем `Control Surface` и `/dev/snd/midiC1D0` с именем `External MIDI`. Предыдущий фильтр принимал оба, обнаруживал неоднозначность и показывал `Unplug USB to return`.

В usb6 выбирается только точная пара id `SerialMIDI` и name `Control Surface`; External MIDI больше не мешает выбору. Регрессионная проверка воспроизводит обе записи из физического журнала. В RAM-журнал добавлены первые 96 значащих MIDI-байтов для проверки реальных сообщений кнопок.

Порядок: безопасно извлечь диск на ПК, **B3 Disconnect → B3 Return to Am MOD** на MPC. B1 отменяет подтверждение. USB-кабель и карта остаются на месте. После установки перезапустите MPC, чтобы загрузить новые RAM-процессы.

Проверены целевые сценарии владения картой, точный выбор контроллера, MIDI-парсер, подтверждение/отмена, ASan/UBSan и AArch64-сборка. Работа B3 на MPC после этого исправления требует физической проверки. Выход отключением кабеля сохранён.
