# Am MOD r30b-usb5 — выход из SD Card Access кнопкой MPC

После подключения карты к ПК безопасно извлеките диск в Windows. На MPC нажмите **B3 (Disconnect)**, затем ещё раз **B3 (Return to Am MOD)**. B1 отменяет подтверждение. USB-кабель и SD-карта остаются на месте. Подтверждение не сбрасывает кэш Windows: сначала завершите копирование и извлеките диск на ПК.

Пока основное приложение остановлено, отдельный RAM-процесс слушает внутренний MIDI-контроллер. Удержанная кнопка Connect, отпускание без нового нажатия, повторные сообщения и внешний USB MIDI не должны завершать передачу. После подтверждения хост отключает USB LUN, освобождает backing device, монтирует карту, восстанавливает аудио и загружает Mod-Exit-Last. Если внутренний контроллер не распознан, экран предлагает прежний выход отключением кабеля.

Экран передачи рисуется до выбора framebuffer и обновляется явным KMS commit вместо одного DIRTYFB: заставка загрузки больше не используется как начальный кадр этого экрана.

Проверены моделируемый выход при подключённом USB, повторный вход, отключение LUN перед монтированием, MIDI-парсер, подтверждение/отмена, захват удержанной кнопки и KMS commit; проверки памяти ASan/UBSan и AArch64-сборка прошли. **Работа кнопки и обновление LCD требуют проверки на MPC.** В usb4 физически подтверждены чтение карты через MPC и возврат проекта после отключения USB.
