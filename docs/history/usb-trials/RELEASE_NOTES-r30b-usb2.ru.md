# Am MOD r30b-usb2 — SD Card Access

Пробная сборка поверх r30a с USB-аудио/браузерным обменом из usb1 и отдельным режимом **карты как USB-диска**. Только MPC Sample **1.3.0.12**. **На физическом устройстве пока не проверено.** Перед первой пробой сохраните полную резервную копию карты и используйте отдельную тестовую SD.

## Карта обычным диском на ПК

1. Откройте **Project → SD Card Access**. Пункт находится между New Project и Key / Scale / Tempo.
2. B1 Cancel отменяет вход. B3 Connect останавливает воспроизведение и сохраняет текущий проект с сэмплами в **Projects/Mod-Exit-Last.xpj** и его папку данных. Это отдельная копия; прежняя копия Mod-Exit-Last заменяется только после успешного сохранения новой.
3. Приложение мода временно закрывается. На MPC появляется отдельный экран SD Card Access; карта передаётся компьютеру штатным USB Mass Storage. Копируйте файлы обычным способом через Проводник/Finder.
4. На ПК выполните **безопасное извлечение** диска. После команды Eject мод должен вернуться автоматически; если ОС не послала устройству команду извлечения, отключите USB-кабель **после безопасного извлечения**.
5. Карта отключается от ПК, снова подключается к MPC, мод запускается и загружает именно сохранённую перед передачей копию Mod-Exit-Last. Новые XPJ с более поздней датой, скопированные на ПК, не меняют этот выбор. Если компьютер не подключился за две минуты, режим возвращается к моду.

Не вынимайте физическую SD-карту. Не удаляйте и не переименовывайте Mod-Exit-Last.xpj, его папку данных, рабочие папки Samples и autorun, если хотите сразу вернуться к текущему проекту. Отключение кабеля без безопасного извлечения не восстанавливает данные, оставшиеся в кэше ПК; проверьте последние скопированные файлы.

Во время режима диска **USB-аудио, MIDI, Screen Mirror, браузерный обмен и воспроизведение недоступны**. Возврат включает перезапуск приложения, а не продолжение проигрывания с той же позиции. Браузерный обмен и Screen Mirror после возврата выключены. Загрузка модифицированного autorun, скопированного с ПК, происходит только при следующем обычном запуске устройства; текущий код уже находится в RAM.

Если карту не удалось освободить или USB-режим не запустился, мод пытается вернуть карту и открыть сохранённую копию; в Project будет сообщение об ошибке. Принудительное/ленивое размонтирование не используется. При замене карты или невозможности безопасно вернуть её автоматический возврат может остановиться: не извлекайте носитель во время записи, отключите USB и перезапустите MPC с исходной картой.

## Остальные USB-функции

- **Mod Settings → Quick → USB audio → Stereo** по умолчанию: прежняя передача стереомастера, рекомендуемая для телефона. **Master + A–H** после перезапуска в Am MOD: 18 каналов при 44,1 кГц — Master 1–2, треки A–H на 3–18. Совместимость телефона/DAW и качество передачи требуют аппаратной пробы.
- **SD files via USB → On**: браузер **http://192.168.155.1:8082**, скачивание Projects/Samples и загрузка новых WAV в Samples/User/USB Inbox без перезаписи. Это отдельный способ обмена, доступный при работающем моде. USB-сеть поддерживается не каждым телефоном.

## Проверки

Проверяются передача владения картой, занятый носитель, оставшиеся приватные монтирования, отказ внутреннего накопителя, Eject, обрыв кабеля, отсутствие ПК, сбой USB-переключения, замена карты и восстановление после прерывания. Системные mount/systemd/gadget в этих проверках симулированы; физическая энумерация диска и работа ОС не подтверждены.

ARM/QEMU проверяет реальные меню/диспетчер Project, точный выбор проекта после возврата, сохранение копии, полную библиотеку и аудиобуферы USB. Экран передачи собран и отрисован из производственного кода. Эти проверки не заменяют испытание на MPC с резервной картой.
