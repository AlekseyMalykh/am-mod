# Am MOD r30b-usb11 — имена USB-аудиоканалов на MPC

В режиме Am MOD → USB audio: Master + A–H устройство передаёт собственную таблицу имён: Master 1, Master 2; Track A 3, Track A 4; …; Track H 17, Track H 18. Это девять стереопар Master 1/2, A 3/4, …, H 17/18. Настройки REAPER и Windows не редактируются.

Причина прежних имён подтверждена чтением USB-дескриптора: поток имел 18 каналов, но iChannelNames=0; ASIO-список совпадал со служебными строками USB. В опубликованном inMusic коде UAC2 эти поля также не назначены.

Для исправления используется отдельный GPL-модуль am_usb_names.ko, собранный из точного архива inMusic linux-imb-6.12.60. Он добавляет непрерывную таблицу имён и назначает её индекс как в Input Terminal, так и в AudioStreaming descriptor. A–H обозначены независимыми логическими каналами, без маски surround-колонок. Встроенный ALSA-аудиодвижок ядра используется прежний.

Модуль копируется с проверкой SHA-256 в RAM. Только перед запуском многоканального профиля, когда приложение остановлено, host снимает gadget, регистрирует именованную UAC2-функцию и создаёт gadget заново. Для SD Card Access, Stock, Stereo и восстановления именованные экземпляры удаляются, модуль выгружается и регистрация штатной функции возвращается. Внутренняя прошивка и ядро на eMMC не переписываются. Загрузка ограничена точным kernel release 6.12.60-imb-2025-12-03-rt13. При ошибке подготовки выполняется восстановление штатного USB.

Проверки: восемь host-сценариев, включая отказ загрузки, несовпадение ядра и отказ выгрузки; запуск исходного ядра MPC из part2/kernel.fit в QEMU; фактическое чтение 18 USB string descriptors; запрет удаления используемого модуля; два цикла named → stock. Виртуальный контроллер использовался только для EP0 и объявления дескрипторов, без проверки передачи ISO-аудио. Работу с Windows/ASIO и аудиозапись необходимо подтвердить на MPC.

После установки: перезапустить MPC; выбрать Am MOD и Master + A–H; после смены выбора снова перезапустить; переподключить USB и заново открыть аудиоустройство DAW. Stock и Stereo сохраняют штатный стереомастер. Выход B3 из SD Card Access ранее физически подтверждён.

Соответствующий GPL-код, заголовки, конфигурация и отчёты включены в SOURCE/usb-audio-names. Официальный архив: ветка mpc-sample/1.3.0 репозитория inmusic-software/az0x-open-source, linux-imb-6.12.60+git-r0-patched.tar.xz, SHA-256 9d6999d9f69f5afd396a634facadc9219dcb85407264273d912355dd6db38f9b.
