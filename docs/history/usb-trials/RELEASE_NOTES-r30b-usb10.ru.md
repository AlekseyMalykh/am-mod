# Am MOD r30b-usb10 — красные важные подсказки

Красным выделены подсказки о перезапуске для USB audio и FX mode, остановке воспроизведения/USB audio, безопасном извлечении диска на ПК и необходимости оставить SD-карту в MPC. Обычные описания остаются серыми/белыми, кнопки действий — янтарными. На странице подтверждения SD Card Access исправлена устаревшая инструкция: после извлечения диска используется B3, а не обязательное отключение кабеля.

Сохранён работающий обработчик usb9. Пользователь физически подтвердил возврат проекта через B3 → B3 без отключения USB. Скриншот REAPER подтвердил перечисление 18 каналов; реальная одновременная запись всех стереопар ещё не проверена.

Индивидуальные USB-имена Master L/R, Track A–H L/R пока не реализованы. В данной прошивке usb_f_uac2 встроен в ядро 6.12.60-imb-2025-12-03-rt13; доступные параметры задают имена терминалов/групп, но не 18 отдельных строк каналов. Настройки REAPER, драйвер Windows и ядро MPC этим обновлением не меняются.

После установки требуется перезапуск MPC. Для передачи: SD Card Access → Connect; для возврата — безопасно извлечь диск на ПК → B3 → B3.
