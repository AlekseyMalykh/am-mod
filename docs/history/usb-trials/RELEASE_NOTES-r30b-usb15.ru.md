# Am MOD r30b-usb15

- Все страницы FX: Shift+B2 — Paste, Shift+B3 — Chain Bypass; Shift+Erase — Copy, в том числе из редактора. В EQ новая точка добавляется Shift+DATA; в редакторе Sample Comp Shift+DATA переключает Warm. Подписи верхних кнопок соответствуют действиям.
- Project: у добавленных пунктов Key / Scale / Tempo, Mod Settings и Screen Mirror свои штатные значки из ресурсов установленной прошивки. Иконки первых четырёх пунктов сохранены. В цепочке и каталоге FX микшера используются штатные пиктограммы категорий.
- Компрессор Shift+Pad5: отдельная подсветка пэдов по занятости, пульсирует только выбранный пэд. Общие сигналы штатного экрана больше не изменяют яркость соседних пэдов.
- OptoCat: DATA вращением меняет выделенный параметр; клик выбирает следующий, Shift+клик — предыдущий из шести. K1–K3 и их Shift-слой сохранены. Для штатного Duck остаётся штатное управление.
- Переход в микшер из компрессора снова разрешён: KNOB FX в Am MOD, PAD FX + KNOB FX в стандартном режиме. Переход проходит через Sample.

Проверки: native PNG decode/blit и управление ссылками JUCE Image в Project, DATA и Shift-клики OptoCat, подсветка соседних пэдов, маршрутизация входа в микшер, общие сочетания всех 35 эффектов, полный preload и USB. Host/ASan/UBSan/AArch64/QEMU. Физическое поведение новой сборки требует проверки на MPC.

После установки: безопасно извлечь карту в Windows → B3 / Return на MPC → выключить и включить устройство. Копирование обновления не меняет уже работающую в RAM версию.
