# Am MOD r30b-usb17

- Duck: DATA теперь обрабатывается явно, а не передаётся в штатный экран без привязки. Клик выбирает следующую из трёх колонок, Shift+клик — предыдущую. Вращение меняет Attack / Release / Amount; при Shift третья колонка меняет In Boost. Подписи значений берутся из самого штатного процессора, выделенная колонка подсвечивается. K1–K3 остаются штатными.
- Переход в микшер из компрессора отключён по просьбе пользователя. Промежуточного перехода в Sample по KNOB FX / Shift+KNOB FX больше нет. Переход из Song не изменён.
- Send To и Sidechain Key: при выборе источника/назначения через DATA или K пропускается собственный трек; список и шкалы обновлены. Для группового Send To исключаются все выбранные исходные треки. Сохранённые значения совместимы. Проверка настоящих петель между разными треками сохранена.
- Сохранены исправления Project, OptoCat, takeover, Original waveform и Soft Clipper из usb16.

Проверки: Duck DATA меняет параметры реального native Colour, Shift-клик и Shift In Boost, сохранение остальных параметров; запрет входа в микшер из компрессора; полный preload и актуальные проверки пакета. Аппаратная проверка новой версии ещё требуется.

После установки: безопасно извлечь диск в Windows → B3 / Return на MPC → выключить и включить MPC.
