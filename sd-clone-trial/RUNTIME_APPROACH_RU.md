# Основа разработки — установленное штатное приложение

Извлечённая прошивка нужна для анализа; на устройстве используется его установленная версия 1.3.0.12. Её точный исполняемый файл копируется в RAM, сохраняет штатный путь внутри пространства монтирования и запускается со штатными библиотеками, драйверами и аппаратными интерфейсами. Будущие изменения функций будут вноситься в эту RAM-копию. Загрузчик, ядро и системные разделы при этом не требуется заменять.

Предыдущие ограничения окружения были строже необходимого для штатного приложения: отсутствовало право настройки графической консоли, затем оказался недоступен сокет системной шины. Это ограничения нашего запуска, а не доказательство запрета запуска копий со стороны прошивки. Пустая собственная D-Bus-шина также не воспроизводила бы штатные службы; подготовленный вариант с ней не был записан на карту.

Новая версия предоставляет настоящие службы через xdg-dbus-proxy. Используется официальный бинарник Debian 0.1.4-3+deb12u1, скачанный по HTTPS с проверкой SHA-256 по Debian Packages; исходные архивы и лицензия включены в пакет. ELF совместим со штатными библиотеками: запуск --version и обмен сообщениями проверены через QEMU с библиотеками MPC.

Политика proxy-policy.args разрешает чтение ObjectManager/Properties у edisksd и BlueZ, чтение свойств/списков ConnMan и временную регистрацию Bluetooth/сетевых агентов. Mount, Unmount, Properties.Set, подключение/настройка сети и управление systemd не разрешены. Прямой сокет хоста скрыт внутри частного /run, виден только сокет фильтра. Сверяются его dev/inode и идентификатор настоящей шины; дополнительно проверяется блокирование безопасного ListUnits к systemd до остановки оригинала.

Постоянные файловые системы остаются только для чтения для копии, узлы накопителей заменяются служебными объектами systemd, сеть отдельная. Внешние штатные службы продолжают свою обычную работу и могут записывать данные. Нельзя обещать нулевой риск аппаратных последствий.

Фильтр работает отдельной временной службой без capabilities, с собственными минимальными устройствами, только AF_UNIX и ограничениями памяти/времени. После восстановления оригинала служба останавливается. При отказе предварительной проверки она также останавливается; запасной лимит — 130 секунд. Сам механизм возврата оригинала сохраняет отдельный 75-секундный таймер.

Проверки на компьютере:

- Девять сценариев systemd, включая возврат после завершения копии, SIGKILL supervisor, независимый таймер, неправильный хеш proxy и намеренно ошибочную политику с доступом к systemd.
- ARM64-фильтр с реальными библиотеками прошивки читает состояние фиктивной службы накопителей; Mount и Properties.Set не доходят до неё. То же проверено на x86-64.
- Синтаксис launcher проверен ARM64 BusyBox из прошивки.

Новая версия ещё требует аппаратного испытания. Если запросы штатной инициализации будут отклонены, proxy.txt в отчёте покажет конкретные обращения. Функции, требующие записи данных и управления внешними устройствами, потребуют отдельного решения после успешного запуска GUI.
